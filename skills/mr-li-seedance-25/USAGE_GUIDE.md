# 李先生 Seedance 通用创作规则使用教程

适用版本：2.1.1

V2.1.1完善逐步引导：每阶段先给成果，再提出具体推荐或少量选择，按你的决定继续。已有决定和明确授权直接执行；创作、资产、返工与交付功能保留，减少重复工作而不减少成品细节。

## 调用

使用已安装的 `$mr-li-seedance-25`，直接说要做什么即可：

```text
先读这个剧本，不改写。
一步步带我完成，每阶段让我选择后继续。
出1-1。
继续下一段。
跳过资产，直接写提示词。
按已定方案连续完成1-1到1-3，不逐段等我。
把已有素材整理成总库和分场素材，文件夹我已在Finder打开。
只改屏幕朝向和对应视线，其他不变。
结束并审阅。
```

新项目会简短说明七阶段：锁定剧本、制作范围、创作基调、资产准备（可选）、分段提示词、结果返工、交付收束。每一步先得到可判断的成果，再决定尚未确定的事项；推荐方案不会自动采用。直接指定任务就进入对应阶段，只补必要缺口。只要求阅读、分析或等待拍板时按约定停下。

逐步引导偏好会随项目保留。换聊天或续作恢复当前阶段、已有选择和下一起点，不重问整套流程。“继续”在待确认阶段确认唯一已展示方案；如果还有多个影响本次执行的未选方案，先请你选择；提示词已交付且无此类待选事项才写下一段。跳过决定持续有效；“返回创作基调”只重开相关选择，其他决定和历史成果保留。各阶段成果与衔接见[分阶段引导](references/guided-production.md)。

## “出1-1”会得到什么

先读取当前权威1-1整场内容，估算总时长；默认本轮输出尚未完成起点的第一自然段，**最高30秒容量**。提示词外给整场预计时长、本段预计时长、结束点和下一起点；说“继续下一段”再推进。只列“1-1到1-3”是制作范围；明确要求按已定方案连续完成该范围时，会逐段执行、检查和交付，不逐段重新索权。

30秒不是必须填满。不截断对白、不加速硬塞、不添无意义动作。指定本段50秒只影响本段，下一段未指定则恢复30秒，不反复确认沿用。明确持续例外只在其范围内生效；切换模型不悄悄改变默认，实际平台不支持时另行说明。

默认逐字采用权威对白，不擅自改动作、关系或结果。要求改台词时先给独立修订稿，采用后才用于制作；只要求分析修改逻辑，就只分析。旧图、旧摘要不能覆盖新稿。

## 基调、写法与完整输出

首次正式生成前确认画面质感、光色、构图/镜头倾向、表演尺度和画幅。可以直接描述、发照片/剧照/作品或旧结果，也可以说“不确定”再选少量候选。作品/导演名仅用于沟通，正式提示词使用确认后的可执行特征；已有基调完整继承。

文戏保留焦段、人物关系、过肩和正反打，常规倾向50mm及以上，但不禁用有功能的广角与特殊视角。关系镜头固定句式不变，一个镜头只让一位角色连续说话，换说话人切镜；不是一句话一镜。动作戏按因果、空间、速度与重量组织，不强制焦段开头；混合戏默认在功能边界拆分，明确要求一整条且容量允许时在条内换写法。收尾自然，不固定追加一秒全景。

每条正式提示词及修正版都完整交付：全局画面与声音、有实际素材才有完整绑定、镜头正文。默认镜头自然段间两个空行，无栏目标题/子段/校对话术，时间码仅在明确要求时出现。要求排成一条连续段落时按你的载体排版；排版段落不等于独立生成条，不能因此改变时长拆分与绑定。

交付采用你指定的聊天、文件或两者；未指定时在聊天完整显示。只要求文件时，正文完整写入并核实可用，聊天提供入口；修正版同样完整交付。四项状态和分镜安排按需在正文外简报，只要正文/文件或状态不变的小修不强加说明和菜单。

详细格式和示例见[提示词写作](references/prompt-writing.md)及[格式样例](references/format-samples.md)。

## 声音与素材

每段全局声音逐字为：

```text
无 BGM，仅保留人物对白、环境音和动作音。只保留人物对白，其他声音全部关闭。
```

原句不改写，执行以后一句为准：仅人物对白，无对白全静音。首次会提示音色有助跨段一致，有实际素材才绑定；无对白段不会为未来角色的音色停工。已有音色不漏绑，已确认没有不反复问，也不写“暂无音色”。原剧本不因声音过滤被改写。

每段独立绑定实际需要的正式编号，不用“同上”，不绑定全场/全队/全目录。人物图、场景图、站位图、道具图和音频各按对应用途生效，综合图不等于整张剧情授权；动态道具不能被“全程保持”冻结。无素材则省略绑定段，不造编号，清理@UUID乱码但保留有效映射。

全局保留“不出现字幕，不出现包装”。真实场内文字按依据保留，后期身份条、时间地点条、片名与包装用途不写进视频正文，不删除原剧本中的备注。

## 资产与分镜

资产准备可以整理、补做或跳过。整理已有素材随时可开始，不用先把全项目制作或采用完。只收照片不自动启动生成；按你说的查看、直接参考或补做执行，已有角色制作授权不重复询问。母资产、人物白底多视图、纯白站位模型、写实/所选媒介单幅定帧、分镜图按各自用途验收，不能相互冒充。

人物固定板式保留：左侧无表情正面半身，右侧正/侧/背全身，仅正面无头，侧背有头，底部服装配件；动物等按真实形态调整。环境保留结构、动线、固定文字，机械只保留有依据的部件，不套其他项目装备。

默认母资产16:9、3840×2160、PNG，用户设置优先；站位图不强制4K，实际尺寸与原生细节分别核对。插值放大不能说成原生4K或新增细节。每张图实际打开检查，生成成功不等于通过或采用。

固定场景文字并入环境母图，必要时作关联特写；可拆卸、跨场复用或独立操作才另建资产。角色任务覆盖当前授权范围内需连续角色，不只做刚发照片的一人，也不自动扩大全剧批次。

尚未决定且需要引导时，可在完整提示词后选择全部分镜、关键镜头或跳过；已确认安排直接继承，仅正文/文件和小修不重复菜单，未选分镜不阻断已授权续写。做图按实际切镜与授权范围，分镜仅“场次，分镜N”命名，存该场“分镜参考”；默认不视频绑定，明确要求时只在指定镜头引用现有分镜的构图/站位用途，不占母资产号、不改原绑定或剧情。

详细流程见[资产工作流](references/asset-workflow.md)、[图片规范](references/asset-image-standards.md)、[分镜参考制作](references/storyboard-reference-workflow.md)。

## 状态、返工与文件

纯聊天不强制建文件；长期项目沿用已授权的一份简短当前状态，记录当前阶段、待选项、引导偏好与已有决定，原文和素材索引仍保留。先核对权威内容、关联素材与最新要求有无变化，才能复用已检查结果；同名同版本也可能内容变动。变化后只复查受影响部分，不能省当前原文或新图验收。

“只改这一处，其他不变”限制返工范围；相互依赖问题可一起修，不机械拆轮，也不扩大重做。静态图不能证明完整节奏，技术失败不靠改稿掩盖。新稿待审、自检、用户采用分开，旧版可恢复；场景/造型变化只同步受影响关联。

本轮资产实际完成后，会提醒一次可选本地整理，并保留真实待审或采用状态；已要求整理或已经回答就不再问。来源位置未知时，你在Finder打开素材文件夹并告诉我即可；已知路径与已有项目目录直接复用，不默认另建桌面目录或审阅目录。

总素材库保留正式母版，分集/分场使用目录沿用准确场次和场名，例如“第01集/1-2_准确场名”。每场或明确分段只复制本段实际需要的素材，不混入无关图、候选、旧版或过程MD；正式提示词按需放文稿目录。原件和可恢复历史保留，分场使用副本不因重复而误删；清单内部核对，不默认输出说明MD、联系表或空分类目录。尚不确定的版本和用途单独说明，不冒充正式采用项。纯文件分类直接按[本地素材整理](references/local-asset-organization.md)执行，不先读全剧或整套做图规则。

“结束并审阅”按本轮任务简报完成范围、交付位置和遗留项；涉及续作时补准确下一起点。提示词交付、保存、视频生成、自检与采用分开记录；只有要求压缩时才打包并实际解包检查。

## 如何省token

日常只读当前任务模块，减少重复规则、重复全剧/全资产读取、过程菜单与日志；不删对白、必要镜头/表演细节、基调、完整绑定或审阅。规则曾读但已不在上下文中时须补读；不能借“缓存”猜规则。

质量与节省冲突时保质量。估算分开看“规则文本加载降幅”与“整个任务总量”；参考编码计数不等于账户额度实测。详见[运行效率](references/runtime-efficiency.md)。

单文件宿主使用[完整运行版](references/universal-runtime.md)，不要和模块版一起输入。所有功能仍保留，但整文件输入的节省比例另算。

## 维护检查

普通文字使用不需要Python。机械文件检查需对应依赖，使用技能外隔离环境，不改系统Python：

```sh
python scripts/build_runtime.py --check
python scripts/audit_skill_consistency.py
python -m unittest discover -s tests -v
```

从技能根目录执行；缺依赖如实报告，不能说文件损坏。新快照只在实际文本审阅后记录，不为消除报错自动刷新。维护日志见[CHANGELOG.md](CHANGELOG.md)，功能映射见[功能对照](references/function-coverage.md)，行为案例见[回归用例](references/full-flow-regression.md)。

归档审计、外置清单与正式母资产去重参数见[交付审阅](references/delivery-review.md)。结构校验、文本行为、独立评估、真实媒体质量分别报告，不互相替代。
