# 李先生 Seedance 通用创作规则

版本：2.1.1

## 核心边界

- 独立通用规则，不限定执行模型、Agent 或接口，不把项目案例变成跨项目事实。
- 用户最新确认的剧本及对应范围修订是唯一制作权威。可以审查，不借转换、精简、提速或电影感擅自改对白、动作、人物事实、场次顺序和结果。改稿需独立授权与采用。
- **未指定时默认每轮一个自然生成段、最高30秒容量。** 普通“出1-1”先估算整场，只交当前未完成起点的第一段；明确指定整条时长或连续完成范围时按该要求执行。整场估时本身不是批量授权。
- 30秒是上限而非填满目标；不截断对白、不加速硬塞、不加无意义内容凑时长。用户明确指定的其他时长只在指定范围有效；下一段未指定则恢复30秒，不重复询问是否沿用临时时长。模型切换不自动改默认，平台能力不匹配时先说明限制。
- 每个独立视频提示词都须自带本段全局画面与声音、实际需要的完整素材与音色绑定、镜头正文，不依赖上一段平台记忆。没有实际素材则省略绑定段，不虚构编号。
- 首次正式生成前确认视觉基调、表演与画幅；已有确认直接继承，换聊天不重置。会改变当前成图或表演的权威、技术、连续性冲突未解决时，不自行选答案，只暂停受影响部分。
- 正式提示词及修正版按用户指定载体完整交付，未指定时默认聊天中的独立可复制单元；只要文件时保存并核验可读即可。交付后登记下一起点，实际推进遵循阶段选择或连续执行授权；视频生成、验收与用户采用另记。
- 保留文戏/动作戏写法、既有镜头习惯、正式排版及所有资产和审阅功能。**节省token只针对重复工作与无关输入，不能降低成品必要细节密度、改变已确认创作味道或省略检查。质量冲突时保质量。**

## 跨项目统一声音规则

每个新写或修订的独立视频段，在全局声音位置逐字使用以下完整原文，空格和标点不改写、不缩写：

```text
无 BGM，仅保留人物对白、环境音和动作音。只保留人物对白，其他声音全部关闭。
```

原句保留范围有差异，但这是用户锁定的完整原文，不借去重或冲突清理改写。执行以后一句为最终范围：仅保留人物对白及对应真实音色；环境音、动作音、音乐、音效、声桥和非对白人声全部关闭。无对白段全静音，不新增台词填声；可见动作与原剧本文档不因此改变。旁白/画外音按其实际内容判断，不借名目补声效。只有用户后续明确修改声音要求才覆盖，旧稿、参考片、更换项目不构成覆盖。

## 任务路由：只加载当前需要的完整模块

先判断用户要阅读/审查、写提示词、做图、返工还是归档；不因为用了本Skill就自动推进全部流程。所选模块须完整读取，不能只读标题、摘要或命中句。已完整读取的同版本内容在当前可用上下文中可复用，不重复全文输出；上下文缺失或来源变化时重新读取必要模块。

| 当前任务 | 必读模块 | 条件性增加 |
| --- | --- | --- |
| 项目阅读、权威核对、续作或交接 | [项目上下文](references/context-protocol.md) | 新项目、主动逐步引导或方向不明时读[分阶段引导](references/guided-production.md) |
| 写提示词、出某场首段、继续下一段 | 项目上下文＋[时长与连续性](references/continuity-and-duration.md)＋[提示词写作](references/prompt-writing.md) | 需建立/修改视觉基调时读[视觉基调](references/visual-baseline-and-tags.md)；明确要求排版示例或确需校准时读[格式样例](references/format-samples.md) |
| 建立或修改视觉基调 | 项目上下文＋视觉基调 | 不确定时用少量候选和必要参考，不替用户默认选风格 |
| 资产清单或实际做图 | 项目上下文＋[资产工作流](references/asset-workflow.md) | 实际做图再读[图片规范](references/asset-image-standards.md)＋[清洁与重做](references/image-generation-clean-pass.md)；基调未明确再读视觉基调 |
| 已有文件夹分类、总库与分集分场整理 | [本地素材分类](references/local-asset-organization.md) | 只补选图需要的当前场次或绑定依据，不先读全剧、全套做图规则；制作正式交付包才增加交付审阅 |
| 制作分镜参考图 | 项目上下文＋[分镜参考制作](references/storyboard-reference-workflow.md)＋图片规范＋清洁与重做 | 只在用户授权的镜头范围执行；仅写视频提示词不加载整套做图流程 |
| 结果诊断、定向返工 | 项目上下文＋[结果返工](references/result-repair.md) | 改视频提示词再读时长与提示词写作；修图片再读对应做图模块；技术故障不靠改稿掩盖 |
| 结束审阅、正式文件归档 | 项目上下文＋[交付审阅](references/delivery-review.md) | 审阅具体产物时用其制作模块；普通分类走本地素材分类入口 |

新项目或用户要求逐步带领时，按[分阶段引导](references/guided-production.md)交当前成果、给具体建议和必要选项、采用用户选择后推进；不确定时先给方案。维护当前阶段、已选/待选项和授权范围，续作恢复位置，不重讲地图。明确任务直接执行，已有决定不重问；“继续”按当前阶段理解，多个未选方案不擅自代选。跳过持续有效，回退只重开受影响项；连续批量授权内完成工作，不逐项索权。引导偏好持续继承，细节在需要进入或改选阶段时读取。

需要优化运行或恢复交接上下文时，按需读[低token与输出保真](references/runtime-efficiency.md)，普通任务不另加载。文件整理、索引、哈希和计数优先用合适的后台工具；必要目视验收仍实际打开结果。没有本地文件、生成或播放能力时如实说明，提供可执行文本或目录方案；不伪称已生成、已保存或已验收，不让维护脚本成为普通文字使用的门槛。

## 维护与兼容

- 规则主要维护位置由上表确定；其他文件的摘要或样例不能覆盖主定义。运行组织细则见[低token与输出保真](references/runtime-efficiency.md)，仅在优化、交接缺失或维护时读取，普通任务执行上述短路由即可。
- 宿主只能接收一个规则文件时，使用自动生成的[完整单文件运行版](references/universal-runtime.md)，不再同时加载模块版。它保留全部功能，但整文件输入不能享受模块按需读取的全部节省。
- [引导样例](references/guidance-samples.md)只在需要问法时读；[失败模式](references/field-lessons.md)、[回归用例](references/full-flow-regression.md)、[功能对照](references/function-coverage.md)仅用于相应诊断或维护验收，不每段全量读。
- [使用教程](USAGE_GUIDE.md)面向用户；[版本日志](CHANGELOG.md)只记录历史，不参与当前规则执行。脚本与审阅快照只做维护/机械检查，不替代真实文本行为、目视验收或用户采用。
