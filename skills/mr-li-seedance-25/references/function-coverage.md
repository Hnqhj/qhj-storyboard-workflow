# V2.1.1 功能保真与升级对照

维护验收时使用，不属于日常必读。此表映射旧功能的现行主要位置，不以存在文件或命中关键词证明行为合格；具体行为案例见[完整回归](full-flow-regression.md)。表内“保留/调整”是设计范围，不是测试通过宣称。

## 核心功能覆盖

| 项 | 现行主要定义 | 验收重点 |
| --- | --- | --- |
| 01 时长、提交单元与范围 | [时长](continuity-and-duration.md) | 默认30秒自然段，明确120秒整条与连续范围优先；排版不拆生成；真实容量、四项内部状态与按需简报 |
| 02 状态与作用范围 | [上下文](context-protocol.md) | 当前阶段、已选方案、待选事项、授权范围、下一步；最新权威、局部例外、聊天/文件交付 |
| 03 必要信息、人物、基调 | 上下文＋[写作](prompt-writing.md) | 不漏人/信息/关系/情绪功能，已确认视觉特征不因精简丢失 |
| 04 连续性与技术知识 | 时长＋上下文 | 日夜/服装/设备/动作空间、已知信息、因果，未决冲突不自选 |
| 05 独立绑定 | 写作＋[分镜](storyboard-reference-workflow.md) | 当前实际素材/音色完整，旧图不覆盖新稿，分镜仅明确授权窄引用 |
| 06 图片类别与验收 | [图片规范](asset-image-standards.md)＋[清洁](image-generation-clean-pass.md) | 多视图/白模/单幅/分镜不混，身份/结构/朝向/尺度/真像素 |
| 07 关联同步与采用 | [资产](asset-workflow.md)＋上下文 | 只更新受影响关联，生成、自检、待确认、采用、历史分开 |
| 08 引导、授权、标签 | [引导](guided-production.md)＋上下文 | 七阶段成果/选择/采用/推进闭环，任务直达、跳过继承、返回只相关、批量不逐项重问；原图选用、标签准确 |
| 09 定向返工 | [返工](result-repair.md) | 其他不变；关联问题可一并修，独立问题按需分批，不扩范围 |
| 10 本地整理与能力 | [本地整理](local-asset-organization.md)＋[交付](delivery-review.md) | 总库＋必要分场素材；Finder实际路径、已知不重问、现有素材随时整理、干净使用层与母版保护；能力按证据 |
| 11 单份规则与冲突 | 主入口路由＋自动运行版 | 同一定义单处维护，样例不覆盖规则，固定原句不改写 |
| 12 回归与交付版本 | 完整回归＋交付＋快照 | 静态/文本/独立/真实媒体分层；旧版可恢复，不自动改历史 |
| 13 低token与保真 | [运行效率](runtime-efficiency.md) | 按需完整读取、有效复用、完整成品、可复算计数与诚实估算 |

## 未削减功能明细

| 功能组 | 保留内容与主要位置 |
| --- | --- |
| 权威与输入意图 | 上下文：当前采用稿优先、修订另行采用、分析不改稿、来源4分类、禁用/替代、局部范围 |
| 剧本审查 | 上下文＋时长：因果/人物知识/动机/常识/连续性，普通建议与新增剧情/功能空镜分开 |
| 前后文与范围 | 上下文：当前原文＋必要相邻，当前场估时、下一起点与在场名单；默认单段，明确批量在范围内连续完成 |
| 文戏 | 写作：50mm以上倾向非禁广角，过肩/腰/足固定句式、视线轴线、说话人切镜非一句一镜 |
| 动作与混合 | 写作：功能镜头组、因果空间速度重量、开放特殊镜头；功能边界换写法，用户指定整条不强拆 |
| 容量与收尾 | 时长：自然口语校准＋顺序动作/停顿等、预检/复核、不倒填、不凑时、可选状态镜头、黑场不返亮 |
| 空间连续 | 时长：人物不可凭特写离场，不冻结运动/穿墙拼房/强制同框，实际最终状态继承 |
| 声音 | 主入口完整原句逐字保留，后一句决定最终范围；无对白静音、可见动作/原稿保留 |
| 音色 | 写作：当前说话角色按需预检、已有继承、真实音频每段绑定；未答复可做不依赖音频的写作但不冒记选择，指定音色缺文件只标绑定待补，无对白不停工 |
| 正式格式 | 写作：一全局＋实际绑定＋镜头、双空行、无栏目/默认时间码；完整成品按约定交付，默认聊天、明确文件only则不重贴 |
| 正文清洁 | 写作：无内部校对话术、无自动审美堆砌、事实概括不换主体、不以删一层删必要内容 |
| 编号与输入噪声 | 写作：稳定编号不重排，未编号真实图才用图片N，忽略@UUID噪声保留语义 |
| 绑定范围 | 写作：当前实际必需项，各素材窄用途，动态状态不冻结；无实际素材不写状态段 |
| 包装与实体字 | 写作＋图片：不出现字幕/包装，不写后期用途；真实场内字按依据，不删除原剧本备注 |
| 视觉基调 | [视觉](visual-baseline-and-tags.md)：确认门槛、少量候选、参考用途、作品名转特征、媒介区别、母题只落实不新增 |
| 资产选择与来源 | 资产：可引用/跳过/整理/补做，原图直接选用有效，授权范围连续完成，实拍/官方考据，模型推断不自动采用 |
| 人物与服装 | 图片＋资产：制作多视图时保留白底规范；明确原图引用不强制重做，身份/风格适用性检查，板内服装与额外换装区分 |
| 非人角色 | 图片＋资产：动物完整头部、真实存在部件、人形用人物版式，状态与关联形态不混 |
| 场景与关联字 | 资产：无人母图默认非禁人群，真实结构/动线/光源；固定文字并入母图、特写父子关系 |
| 道具与机械 | 图片＋资产：多视图结构数量连接/支撑一致，普通车辆不套赛事，现实完成态推理须依据 |
| 手写与文字修复 | 资产：原手写尽量保字形/错别字/涂改，核对残字/合成边缘/透视，未知字不编造 |
| 清洁与质量 | 清洁：结构先于风格、材质物理差异、光影层次、少量当前排除、风格颗粒有范围 |
| 生成能力与放大 | 图片＋资产：实际调用与开图、真尺寸/格式、插值不冒称原生4K，可靠母图链 |
| 站位与分镜 | 图片＋分镜：纯白模型按明确选择、单幅成片、实际切镜张数/场内接续、返工同号、无烧字 |
| 分镜授权与归档 | 分镜：首次完整段按需给全部/关键/跳过选择，已定/已跳过/小修不重开；默认不绑定、明确引用例外；场次归档、自检不冒用采用 |
| 表演与返工 | 写作＋返工：确认基调内普通视线/停顿可设计，剧情变化交用户决定；诊断与实施分开，已授权相关修改完成复查，其他不变、旧版可恢复 |
| 文件与项目整理 | 本地整理：总母库/分集/分场、准确场名、只选必要素材，稳定母文件与分发副本；工作/候选/历史在外，过程MD与临时图不入使用层 |
| 整理引导与时机 | 本地整理＋引导：一批完成后可选整理，用户打开Finder提供位置；已有路径/授权不重问，现有素材随时整理，个别未知不拖全体 |
| 交付收束 | 交付：指定载体的完整成品与当前任务必要状态，提示词维护下一起点、纯整理不强加剧情落点；实际开图/播放/解包，不默认附赠清单/日志/审阅台 |
| 兼容与维护 | 主入口＋运行效率：单文件自动生成、无脚本如实降级、模式不双读、日志不当现行规则 |

发布前逐项检查位置与行为，针对发生变化的环节实际运行用例；未做的媒体或独立流程不得写“通过”。旧版原始文件保留在升级任务的baseline备份，不混入当前Skill运行路由。

## V2.1.1 用户批准的12项映射

| 升级项 | 主要位置 | 可观察验收 |
| --- | --- | --- |
| 01 完整七阶段引导 | 引导 | 每步先有具体成果，后有当前选择与明确推进条件 |
| 02 用户逐步确定 | 引导＋上下文 | 未定创作选择供用户决定，已经确定的不重问 |
| 03 继续/跳过/返回 | 上下文＋引导 | 继续依据当前位置；跳过持续；回退仅影响相关成果 |
| 04 连续授权 | 上下文＋写作/资产 | 范围内逐项完成自检，不重新索要同一执行许可 |
| 05 时长与排版 | 时长＋写作 | 120秒一条仍是一个提交单元，文字分段不强拆 |
| 06 减少无效阻拦 | 写作＋资产/返工 | 原图可直接用、音色不挡无对白、普通表演可设计、已授权修改完成 |
| 07 总库＋分集/分场 | 本地整理 | 总库母版和按场必要副本均在正确位置 |
| 08 准确命名与选图 | 本地整理 | 真实集/场号及剧情名，分场只含绑定或连续性需要的版本 |
| 09 文件夹位置引导 | 本地整理＋引导 | 能读取用户打开的Finder路径；已知路径/授权不重问 |
| 10 干净使用目录 | 本地整理＋交付 | 无失败图、无关图、过程MD和临时拼图；正式文稿按需保留 |
| 11 随时整理已有素材 | 主入口＋本地整理 | 直接进入文件任务，个别待定单列，不要求先全项目采用 |
| 12 保护与同步验证 | 全部相关模块＋完整回归 | 对白/剧情、固定声音、绑定、真实容量、视觉检查与历史保留；行为结果有证据 |

“文件存在、链接可达、规则字句出现”只能证明相应机械条件。完整回归中的 v2.1.1 案例以输入、应交成果、应问选择、推进时机与不应重复问的内容验收，不用关键词测试代替。
