# 图片清洁生成与失败重做

开始前先按 [asset-image-standards.md](asset-image-standards.md) 区分白底多视图母资产、纯白站位模型、写实定帧/所选媒介单幅图与分镜参考，再选对应版式。纯白站位模型仅在用户明确选择时使用。本文件负责清洁与重做，不得把白底多视图套到分镜画面上，也不得覆盖身份、结构和事实要求。

以下物理材质与摄影清洁样本只适用于写实方向。二维赛璐璐改用稳定线条、完整色块、清楚的前后遮挡和一致分层阴影；不要求摄影景深、远景虚化、自然空气透视或真实反射。其他媒介按已确认风格选择，不能把清洁层当成统一写实滤镜。

本文件用于实际生成、编辑或修复人物、场景、道具和实体文字图片。它只增加一轮做图纪律，不改变 Seedance 2.5 正文格式，也不把某个模型、Agent、API、画幅、导演或项目风格设成默认值。

## 启用条件

仅在本轮确实要制作、编辑、修复或验收图片时读取。只做剧本分析、提示词转换、资产清单或文件整理时不启用。只读取当前授权集/场、对象及受影响图像所必需的依据；收到照片或发现问题不自动扩大制作和返工范围。

## 一轮清洁生成

### 1. 锁定画面事务

全新生成先写清本轮完整目标、来源事实和构图/结构边界；失败返工或局部编辑先列明授权修改。同一原因或互相依赖的问题可以一并修正，独立问题根据风险与依赖分批，不硬性限定每轮只修一项；同时列出必须保留的内容与需要重建的区域：

```text
本轮授权改动：
（要修正的问题及关联原因；说明需要一起修正的相互依赖项）

必须保留：
（人物身份、数量、构图、透视、结构、文字、位置、比例、颜色或其他来源事实）

需要重建：
（新暴露表面、遮挡关系、边缘、接触阴影、反射和背景衔接）
```

“其他不变”指保留未受修改影响的事实与画面内容；如果改变机位、构图、姿态、结构、遮挡或空间关系，应明确重建受影响区域，不得一边要求旧像素完全不变，一边要求模型完成互相冲突的新画面。需要逐像素准确的文字、标志、版式或局部内容时，优先使用遮罩、合成、排版或确定性修复。

先标明参考图的用途。`身份事实` 和 `结构事实` 可以锁定人物、物件或空间；`造型/构图/光色参考` 只提取相应风格特征；`反例` 只用于判断不希望出现的属性。不得把审美参考中的人物、服装、道具、地点或剧情自动复制到当前项目。

### 2. 先写结构，再写风格

- 场景先锁定地平线、透视、固定地标、道路与出入口、前中后景、大中型块面和真实空间动线。
- 人物先锁定身份、人数、脸型、发型、姿态、服装结构和手脚关系。
- 道具与机械先锁定轮廓、数量、连接、支撑、厚度、重心、接地和可见开口。
- 真实参考存在时，只清理杂物和非必要干扰，不借风格化改变来源事实。

重量、尺度和空间感必须来自体积、厚度、遮挡、支撑、接地和材质响应，不能用压黑、浓雾、全局颗粒或满屏微纹理代替。

### 3. 补足材质与光线

指出主要可见材质及其物理表现：哑光、缎面、粗糙、透明、吸光、反射、干燥、潮湿或磨损。相近颜色的表面通过明度、色温、粗糙度、反光宽度、边缘响应、接触阴影和深度对比分开，不随机增加新颜色或轮廓线。

亮部保留材质纹理并平滑过渡，暗部保留结构；接触阴影只出现在真实接缝、重叠、褶皱、支撑和接地区域。反射遵守距离与粗糙度，不制造全局镜面或塑料亮光。

### 4. 加入清洁渲染层

可复用资产母图默认使用：

```text
大中型结构块面连续完整，材质类别清楚分离，亮部纹理受保护，暗部结构可读，接触阴影局部且有物理依据，远景细节自然衰减；细节只集中在焦点、真实接缝、合理磨损点和关键叙事物件；背景形状有秩序，渐变干净，反射克制，不以全画面颗粒、灰尘、裂纹或过度锐化制造电影感。
```

“干净”不等于塑料、磨皮或删除所有真实纹理。皮肤、布料、金属、木材、混凝土和旧物仍要保留镜头尺度下可见且符合物理逻辑的纹理；只是不能让随机噪点和重复微纹理接管画面。

### 5. 使用少量当前风险排除项

优先把要求写成正向可见状态。只有平台提供排除栏，或当前失败类型确实高风险时，才使用简短排除块。每次从当前风险中选择 2–4 项，不机械复制下面的类别：

```text
避免：（只填写本轮最高风险的 2–4 项，例如随机微纹理、碎裂表面、泥状暗部或生成残影）
```

不要把旧失败图中的具体人物、道具、地点、颜色、动作或风格写进排除块。排除词不是历史失败档案；冗长、具体而生动的否定描述可能反过来污染当前画面。

用户明确要求胶片颗粒、旧化、尘土、破损或粗粝媒介时，不把相应概念列为禁止项，而是写清强度、区域、物理来源和适用阶段。结构、脸、文字和主体边界始终优先。

### 6. 调用设置与提示词分离

尺寸、质量、保真度、参考权重、种子、输出格式和压缩率优先放入平台调用设置，不作为画面内容堆进提示词。工具无对应设置时才用最短规格句补充，且必须核对实际输出；记录真实值，不把参数文字当作分辨率证明。

直接生成超高分辨率出现不稳定、碎裂或伪细节时，先在该平台可靠尺寸生成并验收干净母图，再使用当前工具已验证且尽量不改变内容的放大方法。不要通过多轮生成式放大制造虚假纹理。

## 生成后目视验收

必须打开实际成图，逐项记录通过或失败：

1. 构图、透视、主体数量、固定地标和来源事实是否正确；
2. 墙体、道路、地面、玻璃、设备外壳等大面积表面是否连续，没有鱼鳞状、瓦片状或碎裂微纹理；
3. 支撑、重叠、厚度、接地和重心是否可信；
4. 材质是否通过物理响应分离，没有统一塑料亮光、贴图感或脏阴影光晕；
5. 亮部是否保留纹理、暗部是否仍可读、远景是否自然衰减；
6. 是否存在随机颗粒、漂浮碎屑、隐藏文字、水印状痕迹、重复图案、噪点散景或生成残影；
7. 人物身份、文字、标志、道具数量和用户指定的不变量是否保持。

接口返回成功、文件存在或分辨率达标，都不能代替目视验收。自检通过只说明画面验收状态，不等于用户采用；候选图及其派生副本不自动晋升为正式资产。纯白站位模型按人数、比例、朝向、空间与屏幕方向等实际用途验收，不以写实材质细节要求改变其已选表现方式。

## 失败重做

1. 记录具体失败证据及可能的共同原因，不泛泛写“画面不好”。
2. 冻结已经通过且不受本轮修改影响的构图、结构、身份、色调和其他设置，明确需随修改重建的区域。
3. 优先从原始参考或最早通过验收的清洁母图重新开始；若遮罩、合成或确定性局部修复能更可靠地保留正确内容，也可使用。不在带有噪点、残影或结构漂移的失败图上继续叠加生成式修补。
4. 在已有返工授权内，可以一起修复同一原因或相互依赖的连续表面、暗部层次、材质反光、接地、文字、身份等问题；独立问题按需要分批，不用“一轮一个变量”阻碍必要的关联修复。
5. 重新打开实际结果，重复验收；达到用户要求后停止，不为了追求无依据的“更精致”继续重绘。
6. 新结果保留历史版本；已确认的结构、服装或场景变化，只同步当前授权范围内受影响的站位图和分镜工作副本，沿用原编号，分别记录原稿采用状态与新稿待审状态，不波及无关图像或自动替换正式稿。

## 通用场景样本

以下样本只演示结构。括号内容必须替换为当前任务事实；画幅、地点、色调、导演和是否无人都不能从样本继承。

```text
正向画面：
（当前场景、主体、构图和用户已确认的风格；只写可执行的色彩、光线、构图和材质描述，不写导演或作品名。）

保持（来源明确的建筑结构、道路、门窗、固定标志和空间关系）。清理（用户要求删除的非必要杂物），不改变真实动线、比例和透视。大中型墙面、道路和地面连续完整；混凝土、金属、玻璃、木材和织物通过粗糙度、反光宽度、色温、边缘响应与局部接触阴影清楚分离。亮部保留材质纹理，暗部保留结构，远景细节自然衰减。电影感由当前项目确认的光比、空气透视、镜头扩散、构图和克制色彩形成，不依赖全局颗粒或满屏微纹理。

少量排除：
只从当前最高风险中填写 2–4 项；例如当前问题是墙面破碎时，可写“随机微纹理、碎裂或平铺表面、生成残影”，不要把所有历史失败类别照抄一遍。
```

这一清洁层只用于图片生成或修复调用，不得作为新标题复制进既定 Seedance 正式提示词。
