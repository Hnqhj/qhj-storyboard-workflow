# 视觉基调、标签与生成后质检

## 两层流程

1. **项目级视觉基调**：从权威剧本和用户要求提取候选标签，标明来源；用户确认后成为可复用的项目资料。
2. **场次级提示词执行**：读取已确认基调，再从当前场原文补入时代、地点、天气、内外景、日夜、动作、声音和必要连续性，完成提示词与真实表演容量拆分。

第一层不改剧本，第二层也不重写剧本。每个新项目在第一次正式生成 Seedance 提示词前必须通过视觉基调门槛；没有已确认基调时，不得直接进入正式提示词，也不得根据题材自行选择默认电影风格。

## 首次正式生成的硬门槛

在输出项目的第一份正式 Seedance 提示词前，检查以下项目是否已由用户明确给出或确认：

- 整体画面质感；
- 色彩与光线方向；
- 构图或镜头倾向；
- 表演尺度；
- 声音策略直接继承 SKILL.md 的跨项目统一声音规则，无需逐项目重新确认；
- 本次画幅。

不要求专业术语或六项分别作答。作品、剧照、认可的旧提示词或具体描述可同时覆盖多项；提取可执行特征后，只请用户确定尚未明确的继承内容与范围，用户已明确选用的部分直接记录。

若信息仍不足以决定成片方向，只询问当前必要的 1—3 项；用户说“不确定”时给出 2—3 个有剧本依据的候选。基调未确认前，可以阅读、解析剧本和整理资产，但不得交付正式 Seedance 提示词。

已经确认过基调的连续项目直接继承；只在相关修订实际影响基调、用户改选或出现冲突时处理受影响部分，不因剧本版本号变化重问整套方向。

## 用户说不清风格时

不要要求用户先学会摄影术语。允许用户用以下任一种方式表达，效力相同：

1. 直接说感觉，例如“冷一点、真实一点、别太商业”；
2. 说一部作品、一个导演、一个广告或一段视频作为沟通参考；
3. 发送一张或多张剧照、照片、概念图、满意/失败的已有成片或旧提示词；
4. 直接说“不确定”，由执行者根据权威剧本提出 2–3 个差异清楚的候选方向。

收到参考后提取可观察的光色、构图、镜头、空间、材质、运动和声音特征；明确选用决定直接继承，未明确用途才简短确认。旧提示词只提取用户认可的结果，不继承旧项目事实；多份参考冲突时只提出最关键的1—2项，不擅自折中。

每份参考先标明用途：`身份事实`、`结构事实`、`造型参考`、`构图参考`、`光色参考`、`节奏/声音参考` 或 `反例`。简短确认时只记录“希望继承什么、不应继承什么、适用到哪里、还有什么待确认”。审美参考中的人物、服装、道具、地点和剧情不会自动变成当前项目事实；只有用户明确确认的修订文本才可更新权威剧本。

候选方向必须有剧本依据，并说明差别会落在哪些可见结果上。用户确认前标记为候选，不写入项目稳定基调。用户只确认其中一部分时，只固化确认部分，其余保持待确认。候选说明保持短：每个方向只列 3—5 个最有辨识度的可见特征和一句成片效果，不展开成长篇摄影分析。

## 稳定基调与动态信息

高规格图片和分镜参考继承用户确认的媒介，不把写实摄影词当作跨项目通用滤镜：

- 写实：按已确认方向选择电影级打光、真实环境光影、镜头景深、空气层次及适量颗粒；光比、IMAX质感和丁达尔效应均不是强制项。
- 二维赛璐璐：强调线条稳定、色块干净、角色比例、分层阴影和背景美术；不默认自然景深虚化、空气透视、胶片颗粒或体积光。
- 三维动画：按所选美术确定模型、材质、渲染和虚拟摄影机；景深与体积光按项目选择。
- 水墨、绘本、定格等：采用各自笔触、造型、层次、材料与照明语言，不强套前述媒介效果。

50mm及以上优先是常规镜头倾向；二维项目可将焦段转成对应取景和透视关系，不因此添加摄影模糊。POV、鱼眼、蚁视、极端特写、航拍或GoPro等由镜头功能决定；同镜不要混入矛盾视角。分镜参考的具体规格见 [分镜参考制作](storyboard-reference-workflow.md)。

适合在项目中稳定保存：

- 媒介和整体质感；
- 主色关系、反差、暗部保留和动态范围；
- 颗粒、清晰度、景深倾向；
- 光线原则、构图原则、空间秩序和美术质感；
- 镜头组织原则与整体声音策略；
- 用户已确认的视觉母题。

每场重新从权威文本或本轮设置读取：

- 具体时代、地区、地点、天气、内外景和日夜；
- 当前光源、场景状态、人物状态和现场声源；
- 本次画幅、片段时长、镜头运动和需要继承的前一分段状态。

画幅由本次生成设置决定，不与媒介质感合并成永久项目常量。

“颗粒”必须区分资产母图与最终风格层：可复用人物、场景和道具母图默认使用干净渲染，不以全画面颗粒、灰尘或噪点制造电影感；用户确认需要胶片颗粒、旧化或破损时，记录其强度、作用区域和适用阶段，不能让风格纹理覆盖结构、面孔、文字或材质边界。

## 结构化标签

标签按用途分开记录。没有来源或不适用的栏目直接省略。

### 图片可用标签

- 场景基底：时代、地区、天气、地点、内外景、日夜；不得保留占位符。
- 视觉定调词：可选，最多 2–3 个；每个抽象词都要由后面的可执行描述支撑。
- 媒介质感；
- 色调；
- 反差、暗部细节和动态范围；
- 颗粒、清晰度和景深；
- 光线；
- 构图和空间；
- 美术和环境质感。

### 视频可用标签

- 镜头运动；
- 镜头组织；
- 人物、物件或环境的动态表现。

动态只能来自权威动作、自然物理结果或用户明确要求，不能借“动态材质”添加剧情行为。

### 音频可用标签

- 同期声；
- 环境声；
- 静默；
- 画内声源。

声音策略统一执行 SKILL.md 的“跨项目统一声音规则”：全局原文逐字保留，最终仅输出人物对白，无对白段全静音。上方音频标签只用于理解参考资料，环境声和画内声源不因此获得成片发声授权。只有用户后续明确更改要求才覆盖。人物身份、地点、时间、片名等后期包装字幕不属于视频生成提示词的声音或画面基线。

### 约束

- 优先写正向、可执行约束；只保留少量确有必要的排除项。
- 用户列出的“不得增加”内容仍只作为内部过滤条件，不复制进正式提示词充当负面描述。
- 标签是项目资料，不是正式输出标题。正式提示词中的相关内容合并写入第一个全局画面与声音自然段，不得输出标签名或栏目名。

## 相似作品与导演只用于选方向

- 用户不确定画面方向、明确要求找参考，或样张能显著减少理解偏差时，可以在创作基调阶段上网检索少量相似作品、导演和剧照。通常给 2—3 个方向即可，优先使用官方剧照、片方页面或其他可靠画面来源，并向用户展示可核对的样张或链接。
- 推荐时可以写作品或导演名，但名字只存在于用户选择阶段和参考记录中。每个候选必须拆成 3—5 个可观察特征，例如色彩、光比、光源、构图、镜头运动、空间密度、材质、表演或声音。
- 用户选定方向后，将名字翻译为可执行特征并保存；正式图片提示词、视频提示词和稳定执行模板中不得出现任何导演或作品名，也不得写“风格相似参考”。
- 删除名字后仍无法执行的方向不合格。参考名与可执行描述冲突时，以用户明确要求和可执行描述为准，并把冲突交给用户确认。
- 用户发来剧照但不知道作品名或导演名时，不追问名称；直接从画面提取可执行特征。参考名不是确认风格的门槛。

## 标签冲突检查

生成前后都检查：

- 项目稳定基调与当前场次事实是否冲突；
- 图片、视频和音频标签是否彼此支持；
- 构图原则与镜头运动是否互相破坏；
- 色调、光线、天气和日夜是否一致；
- 景深、清晰度、画面密度和空间表达是否互相抵消；
- 本次画幅是否与用户当前选择一致；
- 是否混入其他项目示例、具体年代、场景、声画策略或导演参考名。
- 成片质感是否来自已确认媒介的造型、构图、色彩、光影和材质，而非无依据噪点或锐化；二维方向未被强行套入写实景深、空气透视与丁达尔效应。

发现冲突时，优先保留权威剧本、本轮用户要求和已确认项目资料；不能确定时标记待确认，不自行拼接折中方案。

## 四项生成后质检

### 一、表演容量

- 检查每段对白能否自然说完、已有动作能否清楚演完、镜头数量是否适合时长。
- 情绪重场可以把剧本已有动作拆到多个提示词分段；简单连续动作可以放在同一分段。
- 依[项目上下文](context-protocol.md)区分表演实现与剧情变动：可将已有情绪具体化为适度视线、停顿和表情，不新增事件、道具操作或删除权威动作。

### 二、台词与时长

- 台词逐字保持权威版本，角色、专名和语气词均不得改变。剧本中的画内实体文字按依据保留；后期包装字幕从生成提示词中剥离，不在此阶段改写。
- 内容过密时按[时长规则](continuity-and-duration.md)选择自然边界；用户指定一整条而确实装不下时给具体取舍，不靠改词、口吃、重复或虚假计时硬塞。
- 可以选择剪辑点，但不能借调整断句修改台词文字。

### 三、画面功能

- 每个镜头应至少承担剧情、情绪、空间、线索、气氛或剪辑接点中的一项明确功能。
- 删除的是模型额外生成且没有功能的冗余镜头，不是删除剧本内容。
- 可以为同一权威事实选择更合适的景别、构图和镜头组织；不得用更有冲击力的画面替换剧本真实动作。
- 新剧情动作、影响事实的环境细节和新增空镜须有依据或用户确认；中性表演细节按项目上下文设计，建议空镜保持既定标记。

### 四、已确认视觉母题

- 只继承用户已经确认的视觉母题，记录其适用范围、首次出现、再次出现及对应人物或场景状态。
- 当前任务只负责在不改变剧情的镜头层落实已确认母题，不重新设计母题。
- 母题需要新增动作、人物、道具、情节或改写剧本时停止执行，改为单独建议并等待确认。

## 严格禁止

- 不改变任何权威戏剧动作，不仅是不改变“核心动作”。
- 不改变人物弧光方向；发现结构问题只能指出，不能自动修复。
- 不新增任何角色、情节线、因果、关系或结果，不仅是不新增主要人物和主要情节线。
- 在提示词转换和生成后质检中，不延长、缩短、删减、改写或替换权威台词。用户明确下达独立的台词修订任务时，先把用户确认的修订保存为新的权威版本，再按新版本逐字执行。
- 特效的可见动作按权威依据保留；声音统一只保留人物对白，旁白、画外音是否属于人物对白按其实际内容判断，不能借此补入非对白声效。字幕须先区分：场内真实文字按权威依据保留；人物身份、地点、时间、片名等后期包装不进入视频生成提示词，可在后期交付阶段单独处理。
- 不把任何示例中的时代、地点、画幅、色调、导演、镜头运动、音乐或声音策略固化成默认值。
