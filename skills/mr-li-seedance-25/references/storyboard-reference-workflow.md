# 分镜参考制作

本文件负责用户选择后的分镜图制作，选择引导主定义在[提示词写作](prompt-writing.md)。分镜参考图实现已交付镜头，生成图片不自动改写原剧本或视频提示词。

## 每段后的引导

生成单元与时长按[连续性与时长](continuity-and-duration.md)，正文排版自然段不另拆生成任务。四项状态简报和分镜选择按[提示词写作](prompt-writing.md)执行：尚未选择且本轮需引导时给选项，已选安排、小修、只要正文/文件不重复菜单。

示例：是否把本段分镜提前制作成符合当前制作方向、可直接使用的高规格分镜参考图？可选全部分镜、关键镜头，或跳过并继续下一段。

- 全部分镜：按本段实际切镜逐张制作。一个自然段包含多次快切时分开计数，不把几个瞬间拼成一张联系表。
- 关键镜头：优先选必要空间、显著站位变化、动作或情绪转折和收尾，不额外创造剧情。
- 选择未确定时仅引导，不自动做图。用户已明确本段范围时，列出简短镜头对应与张数后直接执行，不重复审批。仅说“做分镜”且范围不明时，再让用户选择全部或关键。
- 用户已给出持续制作或跳过指令时继承其选择，需报告时简述本段安排，不反复询问同一授权或强制附加说明。
- 未选择做图不阻塞已完成的提示词交付和下一段写作。引导替代常规下一步菜单，不重复出现两套引导。

## 图像类别与视频引用边界

| 类型 | 用途与版式 | 编号与视频绑定 |
| --- | --- | --- |
| 母资产图 | 可复用身份、造型、道具或环境；白底人物多视图保持固定版式，道具和环境按各自规范 | 沿用原C/S/P等正式编号及已有绑定规则 |
| 纯白站位模型 | 仅在用户明确选择时，以白色人物及必要空间/道具简模交代人数、比例、位置、朝向、视线和屏幕方向；用户样张优先，不强制4K | 沿用已有站位编号与绑定方式，不自动转换旧站位图 |
| 写实定帧/所选媒介单幅图 | 呈现完整身份、服装、场景、状态及对应媒介的单幅画面，不能由纯白模型冒充 | 按已有项目类别和编号规则管理，不为新分类改旧编号 |
| 分镜参考图 | 按一个具体镜头的一个瞬间管理，默认依已选媒介制作完整单幅画面；明确选择纯白模型时标明站位/构图用途 | 默认不参与视频绑定；用户明确要求时以现有场次分镜名或明确对象名引用授权镜头用途 |

分镜可以读取当前授权镜头需要的原人物、环境、道具和站位图作为图像生成依据；这些内部参考关系不自动写回视频提示词。用户明确要求视频引用分镜时，仅在其授权的具体镜头中使用现有“场次，分镜N”或明确对象名，并写明对应的构图/站位用途。例如：`本镜头人物左右位置与屏幕朝向参考“3-1，分镜2”`。引用只提供所注明的画面依据，不改变原剧情、对白、镜头行为或既有人物/场景/道具绑定。

已有实际分镜与平台对象映射时，可使用【分镜N】或【场次，分镜N】；多场重号时写明场次，不虚构对象。引用放在固定“焦段＋过肩/过腰/过足＋人物关系镜头”句式的逗号后，不把编号或标签插进句式内部。

不自动给分镜分配K/C/P/S号，不把分镜重排成【图片N】，不更改旧项目编号。旧站位图绑定照旧，不批量改名或迁移既有项目文件；已有明确对象名也不因引用而改名。纯白模型和单幅定帧的详细标准见 [图片资产规范](asset-image-standards.md)。

## 制作与影像规格

1. 锁定最新交付的提示词、对应权威场次、用户选择的镜头范围与已确认媒介。列出简短“分镜号—对应镜头—本批张数”；已有明确选择后无需再次等待。
2. 只读取当前授权集/场、镜头必要的母图和对应原文；需要连续性依据时补读少量相邻原文或相关状态，不为当前分镜重读全剧、全资产。保持空间结构、人数、面貌、服装、眼镜、设备位置、道具尺度和当时状态；不得为构图增加桌椅、柜子或剧情行为。视角变化不等于场景结构变化。
3. 常规人物镜头优先50mm、85mm和必要的105mm；依据已写提示词实现机位，不擅自改焦段。POV、蚁视、鱼眼、极端特写、航拍、GoPro等保持其叙事用途。运动镜头选一个关键瞬间，不用一张静帧伪称呈现完整运动；需要起止两张时先纳入当前制作范围。
4. 默认按用户已确认的媒介制作可直接使用的成片级单幅图，不交草图或多图联系表。用户明确选择纯白站位模型时，按其样张或已确认要求制作并标明模型用途，不冒充成片级定帧。成片级单幅图默认16:9、3840×2160、PNG，用户设置优先；模型站位图不强制4K。实际输出尺寸与细节能力如实核对，不能把插值放大称作原生4K。
5. 写实方向可选电影级打光、真实环境光影、景深及空气层次；二维赛璐璐强调稳定线条、干净色块、分层阴影和构图，不默认摄影虚化、自然空气透视、胶片和丁达尔效应。三维、水墨、定格等同样只用符合已选方向的质感。详细基调见 [视觉规则](visual-baseline-and-tags.md)。
6. 保留有依据的实体文字，核对内容、字形、比例与透视；不添加字幕、包装、镜号或说明文字。以具体照片为事实依据时保留无法恢复的模糊，不编造文本。
7. 原尺寸打开每张图，按所选类别核对身份、肢体、站位、视线、场景结构、屏幕朝向、物件尺度、文字和媒介质感；纯白模型重点核对人物数量、比例和空间方向，不要求补写实身份细节。问题图修复后再复查；已授权范围内同一原因或相互依赖的问题可以一起修，独立问题按需要分批。每次从可靠母图处理，明确“其他不变”与受影响区域，避免连续重绘积累劣化。具体清洁规范见 [图片清洁生成](image-generation-clean-pass.md)。

## 提示词范式

下例只供图片生成，括号内容替换为当前镜头事实；不携带导演、作品名、镜号或文件名进入成图。不擅自改变视频中已经确定的镜头。

写实示例：

```text
依据【必要母图】呈现【本镜头的主体、动作和站位】，保持人物身份、服装、设备朝向与场景结构。采用【已写焦段、景别、机位】的取景，只呈现一个明确瞬间，不增加设施或人物。


电影级打光，真实环境光影，按【当前场次】保持光源、光比与色调；景深按当前镜头主体与距离设置，空气层次和轻微胶片质感仅在已选基调需要时使用。主体结构与实体文字清晰可信，无字幕、包装和分镜编号。
```

二维赛璐璐示例：

```text
依据【必要母图】呈现【本镜头主体、动作与站位】，保持角色比例、服装、物件与场景位置。取景为【已写景别、机位】，完整单幅二维赛璐璐画面。


线条稳定，色块干净，分层阴影与已确认光源一致；用遮挡和色彩层次区分前后景，保持【当前配色】。无字幕、包装和分镜编号。
```

## 命名与归档

新制完成图按“剧本场次＋分镜编号”命名，例如 `3-1，分镜1.png`、`3-1，分镜2.png`。名称写在文件名和聊天标注中，不烧进图像；不加K号、人物名、镜头说明或版本后缀。已有项目文件沿用原名称，不因本规则或视频引用而批量改名。

- 同一场次跨多段接续分镜编号，换场重新从分镜1开始，避免每段从1覆盖前一段。只做关键镜头时保留其对应的场内镜号，可留缺号，不为连续编号改动原镜头对应。
- 返工保留同一分镜号；旧版放独立恢复目录或版本子目录，工作文件可带版本。审核后的场次目录只保留当前版本，不直接覆盖唯一可恢复源。
- 归档到对应场次的 `分镜参考` 文件夹，例如 `第03集/3-1_区域赛小组赛/分镜参考/3-1，分镜1.png`。项目层级已存在则继承；没有本地项目目录时按已授权位置安排，不强制建立全套资产目录。
- 分镜图自审完成后按上述路径归档并交付用户查看，不走“采用后分配K号”的流程。自审与用户反馈分别记录，不把自审写成用户已采用。
- 不混入人物、场景、道具或“镜头定帧”文件夹，不强制新建清单MD。内部记录场次、提示词版本、镜号、输出路径和审核状态；默认不进入供视频提示词读取的素材绑定表。用户已明确要求引用时，只补充已授权的具体镜头、现有分镜名/对象名及构图/站位用途，不改原绑定。
- 用户后来改了镜头、剧本、结构、服装或场景时，只核对当前授权范围内受影响分镜与站位图，并对受影响工作副本作对应修订；不把旧分镜反过来当剧本依据。改写导致镜头增删时先明确对应，保留历史，不静默重排已交付图。修订结果仍分别记录自审与采用状态，候选图不自动替换已采用稿；超出当前授权的受影响项只报告待同步范围。

## 简短交付

显示图片或可点击文件，说明本场分镜范围、图像类别、实际分辨率、目录和自审结论。有失败或未完成项就明确指出，不把已提交生成视为完成。自审不等于用户采用；不自动重写视频提示词或绑定这些分镜。用户已要求引用时，说明已落实的具体镜头及构图/站位用途，保留原剧情和原绑定。
