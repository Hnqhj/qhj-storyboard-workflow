# 图片资产硬性规范与提示词范式

实际制作、编辑或修复任何图片资产时启用，包括已授权角色任务中收到参考照片后的资产化。照片资产化仅在当前制作授权内执行，收到照片本身不扩大范围；任务启动边界统一见 [资产工作流](asset-workflow.md)，已有授权不要求重复确认。用户要求仅查看、等待或不生成时不做图；清洁流程见 [image-generation-clean-pass.md](image-generation-clean-pass.md)。

## 通用设置与事实边界

- 先区分白底人物多视图、纯白站位模型、写实定帧/所选媒介单幅图，以及按具体镜头管理的分镜参考。下列人物/道具白底多视图仅适用于对应母资产；站位用途不强制4K，也不默认采用纯白模型。分镜默认不参与视频绑定，用户明确要求时可在授权的具体镜头中以现有“场次，分镜N”或明确对象名引用构图/站位用途，不自动分配K/C/P/S、不重排图片号或更改旧项目编号。详细引用、生成、验收和归档按 [分镜参考制作](storyboard-reference-workflow.md) 执行。

- 默认交付 16:9、3840×2160、PNG；用户指定其他规格时从其要求。比例、像素和格式放在工具设置或生产备注，不作为画面内文字。工具没有对应参数时才用最短规格句补充；核对实际输出像素，不能把提示词写了4K当作已达标。
- 来源统一为 `剧本明确`、`用户确认`、`实拍或官方依据`、`模型推断待确认`。前三者只在证据覆盖范围内有效；记录来源及未知部分，不把推理说成实拍。
- 先按项目已确认媒介选择写实、二维动画、三维动画或其他风格。以下版式不强制写实；身份、结构、文字和跨视图一致性不随风格丢失。没有确认风格时补最少确认，不套用旧项目。
- 高规格随媒介定义：写实可选摄影光影和适用景深；二维赛璐璐采用稳定线条、干净色块和分层阴影，不强制自然景深、空气透视、胶片或丁达尔效应。其他媒介依已确认方向选择，详见 [视觉基调](visual-baseline-and-tags.md)。
- 母图是可复用资产，不是海报、联系表或说明页。仅保留实体本身有依据的文字、品牌和标志，不新增栏目、注释、尺寸线或水印。
- 白底资产采用均匀影棚柔光、无明显硬阴影、正常曝光；浅色不溢出，深色有层次。动画媒介按同等可读性执行。
- 范式中的【依据】【设计】等须替换或删除不适用项；实际提示词用短句。额外排除词只选当前最高风险的2—4项，不复制历史负面清单，不否定本来需要的多视图重复、旧化、破损或动画风格。
- 每张成图打开原尺寸核对身份、数量、各视图结构、文字、材质、曝光、比例、边缘和残影。实际像素、文件格式与目视验收分别记录。

## 纯白站位模型与单幅画面

纯白站位模型只在用户明确选择这种表现方式时使用。白色人物与必要的空间、桌椅、屏幕及道具简模只负责表现人数、相对比例、位置、朝向、视线、遮挡和屏幕方向，不制作身份设定板，不自动增加写实脸部、服装纹理、装饰或设施。用户提供的样张优先决定表现和取景；在不改变事实关系的前提下，用明暗和局部接触阴影保证白色形体可辨。

```text
按【用户明确选择或所给样张】制作【当前镜头/站位状态】的纯白站位模型。画面使用【准确人数】个白色人物简模及【关系表达必需的空间、屏幕与道具简模】，保持【相对比例、站位、朝向、视线、屏幕正反面和遮挡关系】。


仅表达空间与人物关系，白色形体清楚可辨，不增加无依据设施或动作。表现方式、机位和取景依【确认样张或当前要求】。
```

写实定帧或其他已选媒介的单幅图则必须呈现对应的完整画面：人物身份、服装、场景结构、道具状态和光线/媒介表现都按当前依据落实。它与纯白模型的交付目的不同，不能以模型图冒充写实定帧、二维成片或其他成片级单幅画面。人物白底多视图的固定版式继续仅用于身份与造型资产。

分镜参考是按具体镜头和瞬间管理的类别，默认采用所选媒介的完整单幅画面；若用户明确选择纯白模型分镜，记录其站位/构图用途并按模型标准验收。项目已有站位图不自动转换为纯白模型，既有表现形式、编号和绑定继续沿用。

## 人物资产

左侧约三分之一为正面直视、无表情半身近景，完整呈现头发、面部、颈肩与上装。右上依次为正、侧、背全身：仅正面从颈部裁去头部，侧面和背面保留完整头部及发型。底部一排服装材质、领口、袖口、下装、鞋履与必要配件。各视图是同一人物、同一服装发型和配件状态。多次展示同一角色是规定版式，不是错误重复。

```text
制作【角色与身份】的纯白底多视角角色资产板，采用【已确认媒介与风格】。面貌依据【身份参考】，服装、发型和配件按【已确认设计】。


左侧为正面直视镜头、无表情半身近景，头部和上装完整。右上依次是正、侧、背全身：正面从颈部裁去头部，侧面和背面保留头部。底部一排展示【必要服装材质及配件】。


所有视图保持同一身份、比例和造型。均匀影棚柔光，无明显阴影，正常曝光。画面只呈现规定视图及细节，不出现规定视图之外的额外人物。
```

## 动物、拟人及变身角色资产

先判断当前形态，再选版式，不以角色来源一概分类：

- 真实结构动物：左侧身份近景，右上完整正、侧、背全身，底部只展示实际存在的辨识结构或配件；四足动物保持其自然姿态，所有视图均保留头部。
- 人形角色或人形变身：使用人物版式，允许设定中的人类姿态和服装；不因原身是狗就添加爪垫或禁止直立。
- 非人形幻想角色：采用完整主体正、侧、背视图及其实际设定部件细节；没有耳朵、尾巴、毛发或爪垫就不列。变体与原角色共享哪些识别特征由已确认设定决定。

```text
制作【角色与当前形态】的纯白底多视角资产板，风格采用【已确认媒介】。外形依据【来源或已确认设定】，保留【实际存在的身份特征与状态】。


左侧身份近景，右侧完整正、侧、背全身，底部展示【确实存在的辨识结构与关键配件】。各视图身份、体型、颜色和状态一致。均匀柔光，正常曝光，轮廓清楚，白底干净。
```

上例用于动物或非人形；人形变体直接使用人物范式。

## 环境资产

默认无人基准图；用户或剧本要求有人群的场景版、站位图时依其要求，不把无人母图限制扩展到视频。以实拍或官方资料为基底的场景，保留建筑体量、门窗柱网、道路动线、固定设备及关键文字，仅清理授权杂物。不得擅自改新建筑或添加无依据设备。无实拍的虚构场景按已确认设定制作，标记推理，继承项目基调。

固定悬挂、粘贴、书写或显示在场景内的书法、标语、装饰画和屏幕内容先并入完整环境母图，保持位置、尺度、透视、安装、遮挡与光线；需要辨认时追加同源关联特写，不另建白底主资产。可拆卸、会更换、跨场复用、需单独印刷或被人物独立操作的物件才单列。

```text
依据【实拍或官方资料／已确认虚构设定】制作【场景名称】环境母图，采用【已确认光线、色调与媒介】。保持【空间结构、动线与固定设备】，把【固定文字或装饰】置于其准确位置，文字为“【核实文本】”。


【按任务写无人基准或有依据的人群状态】。仅清理【授权杂物】。主要材质层次清楚，光源、透视和遮挡合理，结构连续完整，暗部可读。
```

关联文字特写范式：

```text
从已验收的【场景母图编号】拉近至【固定文字或装饰】，完整保留字形、材质、装裱、透视与环境光，周围留少量墙面作为空间依据。只改变取景距离，不重新设计。这是母图的关联特写，不是白底孤立物料。
```

## 普通道具资产

白底多视角；主视图说明外形，辅助视图按实际需要选择侧、背、底部、接口、连接或开启状态。同一状态跨视图一致；不同开启或损坏状态需明确分版，不能在一组视图中无说明地变化。尺度不明不编造精确数字。

```text
制作【道具与状态】的纯白底多视角资产板，依据【实拍、官方资料或已确认设定】，采用【已确认媒介】。左侧三分之四主视图，右侧【必要正侧背底视图】，底部【接口、连接或材质细节】。


各视图部件数量、位置、颜色、文字和状态一致，连接与支撑可信。均匀柔光，正常曝光，材质清楚，仅保留实物必要文字。
```

## 机器人、车辆与机械设备资产

使用工程多视角版式：左侧三分之四主视图，右侧正、侧、背视图，底部为实际功能部件。按对象筛选底盘、轮组、履带、传感器、接口等，不把所有设备写成竞技机器人。

- 普通车辆及生产设备：只锁定其实际结构、编号和真实工作逻辑，不凭空增加阵营灯、装甲、云台或发射机构。
- 赛事设备：只有实拍、适用赛事规则或用户确认设定支持时，才加入相应阵营灯及比赛部件；不能混用不同赛事或赛季规则。
- 现实半成品推理完成态：只补齐现有结构、同系列实物或官方资料支持的部分，明确推理范围。
- 虚构机械：遵循已确认设定和媒介，注明虚构或推理，不伪称现实官方装备；保留自洽的支撑、运动和功能关系。

```text
制作【设备名称与状态】的纯白底多视角资产板，依据【已核对来源或已确认虚构设定】，采用【已确认媒介】。锁定【实际存在的主体、行走或工作机构、传感器、接口及标识】。


左侧三分之四主视图，右侧正、侧、背视图，底部展示【关键功能部件】。各视图比例、数量、连接、颜色和状态一致，支撑与使用逻辑清楚。均匀柔光，无明显阴影，正常曝光。
```

## 实体文字与赛事物料

图片制作先确定“依据要求保留、用户指定去除、无依据生成需清理”的文字范围，再检查文字内容、字体字形、标点、换行、朝向与透视；证据不清时报告，不猜补。不要把“视频不出现字幕，不出现包装”解释为清空图中的实体文字。

固定属于单一场景的文字按环境资产处理。本节适用于独立旗帜、工牌、奖杯、展架、队服印字等；逐字核对来源的文字、数字、标点与换行。用户要求去年份或无标点时只在指定范围执行，不推广到所有物料。不能辨认时报告缺口，不用乱码代替；官方图是依据，不冒充正式资产。

```text
制作【物料与状态】的白底多视角资产，轮廓、版式、颜色、徽标位置依据【来源】。准确保留“【已核实且按用户要求处理的文本】”。正面完整平视展示，补充【必要背面、侧面、安装和材质细节】。


各视图文字和结构一致，采用【已确认媒介】。均匀柔光，正常曝光，仅保留物料本身的图文，边缘干净。
```
