# 情绪表演导演

把情绪设计成可观察的时间过程，而不是单帧表情。每个情绪都必须有触发、身体证据、对方/环境反馈、强度变化和末帧余波；同一场戏允许克制、迟疑、错位和反向行为。

## 职责边界（表演三技能）

本技能只管**情绪弧线与强度**：触发 → 压制 → 泄露 → 升级 → 释放/转向 → 余波，以及强度变化的可观察变量清单（呼吸速度、眨眼频率、下颌力度、指尖压力、重心、距离、语速、动作幅度）。

- 可演目标、行动动词、聆听行为、身体物理连续性 → `$live-action-performance-direction`
- 情绪画像库（怒/哭/哀/喜/乐）、5 层强度刻度、镜头距离与光色 → `$performance-scene-director`

本技能不做表演方法教学，也不选情绪画像。

## 情绪弧线

使用：

`刚刚发生 → 角色先压住什么 → 身体先泄露什么 → 外部压力如何升级 → 何时释放/转向 → 结尾留下什么未完成`

默认从低强度开始，除非剧本明确要求瞬间爆发。强度变化必须至少改变一个可见变量：呼吸速度、眼神目标、眨眼频率、下颌力度、肩背张力、手指压力、重心、身体距离、语速或动作幅度。

## 五类可见证据

1. **呼吸**：吸气被截断、呼气变浅、屏息后释放；不把“呼吸急促”当作全程背景状态。
2. **视线**：锁定、回避、偷看、先看物再看人；视线必须有目标。
3. **姿态与重心**：前倾逼近、后撤防御、肩背塌下、脚底重新找支撑；情绪变化带来重量变化。
4. **手部与道具**：握紧、松开、停在半空、反复触碰已有道具；不凭空增加新动作或道具。
5. **声音与台词**：音量、停顿、吞咽、句尾下沉或突然截断；普通对白平均3字/秒，情绪停顿另加时间，不抢读。

## 情绪类型的表演方向

- **愤怒/对峙**：先控制再泄露；冷怒可用更少动作和更稳定视线，爆怒必须有重心、距离、声音或道具后果。
- **悲伤/哭戏**：优先写忍住、吞咽、呼吸破裂、视线失焦和迟到的眼泪；不要从第一秒持续哭喊。
- **恐惧/震惊**：先定住注意力，再出现退缩、寻找出口、保护性手势或声音失常；不能只瞪大眼睛。
- **羞耻/隐瞒**：视线避开、手部忙于已有物件、回答过快或过慢、身体转半步但没有离场。
- **喜悦/惊喜**：眼神先确认，嘴角和呼吸后到，身体才放松或靠近；避免所有人同步大笑。
- **冷漠/权力展示**：动作更少但更准确，用停顿、距离、视线和对方反应制造压制；“装逼”特写只放在真正的能力/权力峰值。

## 反应与切镜

短句不强制切反应。只有当听者反应能改变信息、关系、权力、距离、下一步行动或悬念时，才安排反应镜头；长台词或关键转折可在自然半句后切到听者。反应可以同镜前后景、过肩、声音先行或独立镜头完成。

## AI生成稳定性

- 每镜只设一个主情绪和一个次情绪，写明起始强度、触发、可见变化和末帧。
- 保留眼睛正常瞳孔与自然反光；禁止用发光眼、面部变形或粒子替代表演。
- 让表情、呼吸、肩背、手部、衣料和发丝有不同步的滞后，避免整个人同时启动或停止。
- 特写只承载不可替代的情绪证据；常规情绪用全景、中景、近景和关系调度完成。

## 输出模板

```text
情绪目标：
触发事件：
起始强度 -> 中段变化 -> 末帧强度：
身体证据：
台词节拍与停顿：
听者/环境反馈：
镜头承载与切镜理由：
下一镜承接状态：
```
