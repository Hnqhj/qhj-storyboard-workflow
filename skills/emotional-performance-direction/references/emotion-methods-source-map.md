# 情绪表演方法来源与迁移

情绪表演的可生成版本必须落在身体和时间上。以下公开方法用于建立分析框架，不用于复制演员身份。

| 方法 | 关注点 | 可生成写法 |
|---|---|---|
| Stanislavski | 情境、目标、行动、潜台词 | “她想让对方退让，因此先压低声音、挡住出口、等对方视线回避后再逼近” |
| Meisner | 当下聆听与真实回应 | “对方说完后延迟半拍，先看手里的物件，再抬眼确认，改变原本准备好的回答” |
| Chekhov | 心理手势与身体想象 | “力量从胸口向前推出，肩背保持开放，动作结束后手臂因惯性回收” |
| Laban | 动作的重量、时间、空间和流动 | “重而突然的下压；直线逼近；接触后短暂停顿，再以受控减速收势” |

公开入口：

- https://en.wikipedia.org/wiki/Stanislavski%27s_system
- https://en.wikipedia.org/wiki/Meisner_technique
- https://en.wikipedia.org/wiki/Michael_Chekhov_(actor)
- https://en.wikipedia.org/wiki/Laban_movement_analysis

交付边界：最终提示词只写可拍行为、可听台词/呼吸和物理拟声；不写“演员使用某某体系”作为模型指令，也不把抽象情绪当作动作结果。
