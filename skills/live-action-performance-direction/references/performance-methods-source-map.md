# 真人表演方法来源与迁移

以下是公开方法的可核验入口与可迁移到 AI 视频的机制摘要。它们不是要求复制某位演员或导演的风格，而是帮助把表演拆成可执行行为。

| 方法 | 核心机制 | AI 视频迁移 |
|---|---|---|
| Stanislavski system | given circumstances、objective、actions、subtext、physical actions | 先写刚刚发生的事实、当下目标和行动动词，再写表情；情绪由行动结果证明 |
| Meisner technique | truthful response、repetition、listening、moment-to-moment behavior | 先设计听者接收和延迟反应；避免两人同时表演、提前预设表情 |
| Michael Chekhov technique | psychological gesture、imaginary body、atmosphere | 将角色的力量方向、身体质感和姿态倾向转成可见重心、手臂路径和空间距离，不写玄虚形容词 |
| Laban movement analysis | weight、time、space、flow、effort qualities | 用轻/重、快/慢、直/曲、收/放描述动作动力；为动作补足惯性、制动和恢复 |

公开入口：

- https://en.wikipedia.org/wiki/Stanislavski%27s_system
- https://en.wikipedia.org/wiki/Meisner_technique
- https://en.wikipedia.org/wiki/Michael_Chekhov_(actor)

迁移边界：不把方法名直接塞进最终 Seedance 提示词；只保留可见的目标、行为、听觉/视觉反应、重心、呼吸、视线和动作连续性。
