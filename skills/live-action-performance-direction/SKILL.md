# 真人表演导演

将抽象情绪转成演员可以执行、镜头可以捕捉、模型可以生成的行为。核心不是让角色“表现得很生气/很悲伤”，而是明确此刻发生了什么、角色想从对方得到什么、正在采取什么行动、对方如何接收，以及关系在镜头末发生了什么变化。

## 职责边界（表演三技能）

本技能只管**行为与物理**：给定情境、可演目标、行动动词、聆听与潜台词、身体连续性、末帧状态。

- 情绪弧线与强度刻度 → `$emotional-performance-direction`
- 情绪画像库（怒/哭/哀/喜/乐）、镜头距离与光色编排 → `$performance-scene-director`

三者可同时在场，但各有唯一职责；本技能不重复输出情绪强度刻度和情绪画像。

## 表演工作流

1. **给定情境**：锁定刚刚发生的事件、当前环境压力、角色掌握的信息、身体状态和与对方的距离。
2. **可玩目标**：为每个角色写一个当下目标（逼退、试探、安抚、隐瞒、确认、夺回控制、拖延等），避免只写情绪名词。
3. **行动动词**：把目标变成可见策略；每个台词节拍只选一个主动作，如压低、回避、诱导、截断、逼近、挡住、承认、反击。
4. **聆听与反应**：先写听者如何接收，再决定是否切反应镜头。关注延迟、误解、吞咽、换气、视线落点、手部停顿、重心变化和策略改变。
5. **身体连续性**：记录脚底支撑、重心、肩背、手臂、下颌、呼吸、视线、道具和距离；动作必须经过预备、发力、惯性、减速和恢复。
6. **台词节拍**：普通中文对白平均约3字/秒；在完整句或自然半句的语义落点优先切镜，不抢读，不为切反应而拆碎短句。
7. **镜头承载**：优先用全景/中景/近景呈现关系和身体行为；特写只在强烈动作、能力峰值、决定性眼神、关键受力或道具证据处使用。
8. **末帧状态**：写清角色说完/做完后的新姿态、距离、控制权和未完成意图，供下一镜承接。

## 真人自然性硬约束

- 说话不是静态播报：开口前有换气或准备，关键词处有轻微身体信号，句尾保留姿态变化或听者接收。
- 听者不做镜像表演；反应有延迟、有选择，可能先看道具再看人，先稳住手再回答。
- 动作不瞬移：起势、重心转移、接触、回弹、惯性和收势必须可见；衣料、发丝和道具只跟随物理运动产生次级滞后。
- 不要求每句话都换姿势；同一姿态可以通过呼吸、视线、指尖、下颌或重心微调持续表演。
- 禁止木偶式站定、机械点头、同步转头、连续重复手势、无理由换手换脚、面部冻结、突然满格情绪和无动机哭喊。

## 风格选择

- **生活化写实**：小幅度、低重心、停顿和未完成动作多，情绪藏在行为选择里。
- **短剧写实强化**：仍保留真实呼吸和重心，但放大关键视线、距离、停顿和动作结果，保证信息快速可读。
- **类型化/仙侠/玄幻**：允许更明确的姿态和力量线，但身体支撑、衣料受力、视线目标和反作用必须真实。
- **喜剧/轻松**：节奏和反应可以夸张，仍需有明确触发与回收，避免所有人同时做同一表情。

## 输出要求

返回：`给定情境 → 角色目标 → 行动动词 → 台词节拍 → 听者反应 → 身体/道具连续性 → 镜头承载 → 末帧状态`。在最终视频提示词中写可见行为，不写演员无法执行的抽象评价。

需要方法来源或培训框架时，读取 `references/performance-methods-source-map.md`；只迁移其中的可见机制，不把理论名称当作模型指令。
