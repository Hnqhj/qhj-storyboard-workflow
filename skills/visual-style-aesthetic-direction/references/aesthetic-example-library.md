# Aesthetic Example Library

Use this as a practical sample bank. Examples are not exact templates to copy blindly. Extract the rule, then adapt it to the user's subject, story, and model.

## 1. How To Use The Examples

For each task:

1. Choose one matching example.
2. Keep the art-direction logic.
3. Replace subject, color ownership, and material details.
4. Add audiovisual grammar from `$cinematic-audiovisual-language` before final video packaging.
5. Add material/light realism from `$ai-material-realism` after the style scaffold.

Never use all examples at once. A高级 result usually comes from one strong constraint, not many styles.

## 2. High vs Cheap Pattern Pairs

### Example 01: "Stylized Fight"

Cheap:

```text
cool stylized anime fight, lots of red effects, cinematic, dynamic, ink splash, impact, high quality
```

Better:

```text
one controlled graphic fight language: black-white woodcut silhouettes with a single vermilion action accent. The fight is readable through clean body silhouettes, one diagonal weapon path, brief high-contrast impact frames, and calm negative space after each hit. Effects only appear where contact, tension, or recoil occurs.
```

### Example 02: "More高级"

Cheap:

```text
make it more premium, luxury, beautiful, detailed, 8K, masterpiece
```

Better:

```text
reduce the palette to ivory, black, brushed silver, and one cold cyan accent. Use large quiet negative space, controlled asymmetry, matte/gloss material contrast, and one decisive focal point. Details are concentrated only on the face, hand, and hero object; background stays restrained and architectural.
```

### Example 03: "Cyberpunk"

Cheap:

```text
cyberpunk neon city, blue purple lights, rain, holograms, futuristic signs everywhere
```

Better:

```text
not generic neon cyberpunk. The city is a pale ceramic surveillance system with overexposed white walkways and red inspection panels. The protagonist owns matte black fabric, scratched chrome, and one illegal cyan light. Neon appears only as reflected system signals, not decorative glow.
```

### Example 04: "Ink Wash"

Cheap:

```text
Chinese ink painting style, ink splashes everywhere, fantasy atmosphere
```

Better:

```text
ink wash is used as restraint: large unpainted paper space, dry-brush edges on architecture, wet ink only at emotional impact points, a few decisive black value masses, and one thin red seal-like accent. No generic fog, no busy brush decoration.
```

### Example 05: "Graphic Poster"

Cheap:

```text
poster style, cool typography, many design elements, modern layout
```

Better:

```text
poster logic comes from hierarchy: one oversized title or symbol, one supporting silhouette, one small secondary information zone, strict grid alignment, and 70 percent controlled negative space. Texture is subtle print grain, not random grunge.
```

### Example 06: "3D Background + Stylized Character"

Cheap:

```text
anime character in realistic 3D scene, cinematic lighting
```

Better:

```text
2.5D hybrid hierarchy: the character has clean cel-shaded planes, stable line accents, and stylized facial proportions; the environment has realistic 3D depth, contact shadows, volumetric light, and physical material reflections. The same key light touches both layers so the character does not look pasted in.
```

### Example 07: "Fashion Cover"

Cheap:

```text
fashion magazine cover, many texts, high-end, beautiful model, accessories
```

Better:

```text
editorial cover discipline: centered fashion silhouette, controlled face light, one strong masthead zone, sparse microtypography, restrained accessory density, fabric texture visible only where light grazes folds. Background is warm ivory paper with subtle print grain, not a busy collage.
```

### Example 08: "Action Speed"

Cheap:

```text
super fast, motion blur, speed lines, explosive action
```

Better:

```text
speed is built through contrast: a half-second still pose, sudden diagonal displacement, foreground parallax streaking past the lens, hero silhouette staying sharp, and one brief impact-frame hold. Blur is directional on the background and foreground only, not across the face or weapon.
```

### Example 09: "Mystical"

Cheap:

```text
mystical magical fantasy, glowing particles, fog, divine light
```

Better:

```text
mystery comes from withholding: a single narrow shaft of light, deep matte shadow, partial silhouette, slow dust movement, and one object reflecting a color that does not belong to the room. No particle shower, no generic magic fog.
```

### Example 10: "Minimal"

Cheap:

```text
minimal clean style, simple background
```

Better:

```text
minimalism with pressure: one subject placed off-center against a huge empty field, three value masses only, no decorative props, and one material detail that carries meaning. The empty space must feel intentional, not unfinished.
```

## 3. Style Blocks By Use Case

### Example 11: Character Reference Sheet, Cool Future Fashion

```text
Art direction: high-end cyber editorial character design, not game concept clutter. Character owns matte black technical fabric, scratched silver metal, and one electric cyan underlight. The background stays warm ivory with faint grid and print grain. Linework is sharp around face, hair, hands, and accessories; clothing uses realistic folds and material response. Avoid random armor panels, neon overload, and cheap idol-poster styling.
```

### Example 12: Motorcycle Reference, Tech And Luxury

```text
Art direction: minimal industrial futurism. The motorcycle has a long low black silhouette, clean aerodynamic surfaces, brushed gunmetal joints, tiny cyan running lights, and visible wear only on foot pegs, handle grips, tire edges, and lower panels. Design feels engineered and expensive, not overdecorated. Avoid random sci-fi greebles, glowing wheels everywhere, and toy-like proportions.
```

### Example 13: Urban Chase, Opposite-Color Background

```text
Art direction: character owns black, chrome, and cyan; city owns sun-bleached ivory, pale mint, and warm coral. The opposition is color-coded: the character is the moving dark mark inside a bright ordered city. Background architecture uses large ceramic slabs and horizontal transit bands. Do not let city colors contaminate the character outfit.
```

### Example 14: Blade Fight, Premium Graphic

```text
Art direction: brutal woodcut action with editorial restraint. Use black/white/gray value fields, carved shadows, crisp silhouettes, and one red slash accent. The red appears only at tension, contact, or consequence. No red decorative background, no random red floor line, no all-over particles.
```

### Example 15: Ritual Fantasy Without Cliche

```text
Art direction: ancient ritual minimalism. Stone, ash, linen, oxidized bronze, and one quiet mineral green accent. Lighting is low side firelight plus cool moon rim, revealing rough surfaces and hand-worn edges. No floating runes everywhere, no blue magic fog, no generic fantasy temple clutter.
```

### Example 16: Underwater Myth

```text
Art direction: naturalistic myth, not fantasy spectacle. Jade-green deep water, aged bronze, pearl, stone, algae, and suspended silt. Light enters as cathedral-like shafts from far above; the creature's scale is shown by tiny fish and buried vessels. Magic is suggested through material and time, not through glowing symbols.
```

### Example 17: Cute But Not Childish

```text
Art direction: warm handmade minimalism. Rounded shapes are balanced by controlled composition, tactile paper texture, soft ceramic highlights, and muted colors. Keep one clear focal gesture. Avoid babyish proportions, candy saturation, and random stickers.
```

### Example 18: Dark Luxury

```text
Art direction: black luxury through material contrast. Matte wool, polished black lacquer, smoked glass, cold silver edge highlights, and deep negative space. The image feels expensive because it is controlled and quiet. Avoid gold everywhere, glossy plastic, and nightclub lighting.
```

### Example 19: Retro-Future Interface

```text
Art direction: analog future, not neon sci-fi. Use off-white panels, amber monochrome displays, engraved labels, worn knobs, dust in seams, and utilitarian grid marks. Interface graphics are functional and sparse. Avoid hologram clutter, random code rain, and floating UI spam.
```

### Example 20: Horror Without Gore

```text
Art direction: negative-space dread. Use overlarge empty rooms, off-center subject placement, one impossible shadow, and quiet material detail like damp wallpaper or cracked enamel. The threat is suggested by framing and sound-image tension, not blood or monsters filling the frame.
```

### Example 21: Dream Sequence

```text
Art direction: memory print, not soft blur. Use faded color separation, paper grain, low-contrast edges, selective sharpness on one remembered object, and slow parallax between flat layers. Avoid generic haze, random bokeh, and everything equally soft.
```

### Example 22: Music Video Graphic

```text
Art direction: posterized performance space. One performer silhouette, two color fields, one repeating geometric motif, rhythm-synced hard cuts, and clean stage shadows. Do not add random background screens unless they change the beat or silhouette.
```

### Example 23: Food Or Product Premium

```text
Art direction: tactile product realism with editorial restraint. Use one controlled key light, matte table surface, crisp contact shadow, selective condensation or oil sheen, and clean negative space. No excessive garnish, no random steam everywhere, no fake glossy over-sharpening.
```

### Example 24: Children's Book But Sophisticated

```text
Art direction: layered paper theatre with restrained palette. Characters are simple but not crude; paper fibers, cut edges, and soft cast shadows create depth. Composition uses large shape rhythm and one emotional gesture. Avoid clipart symbols and over-bright colors.
```

## 4. AI Video Consistency Examples

### Example 25: Style Lock For 15s Action

```text
Across all 15 seconds, keep one base medium: black-white woodcut animation with limited red accent. Camera angles may change, but line thickness, shadow shape, paper texture, and color ownership stay identical. Impact frames are high-contrast red/black inversions for less than 0.15 seconds, then the video returns to the same woodcut world.
```

### Example 26: 2.5D Character In 3D Scene

```text
Across all shots, the character stays cel-shaded with clean line accents and semi-real fabric folds. The 3D environment keeps realistic perspective, contact shadows, reflections, and volumetric light. The same light direction must connect character and background. Do not switch to full cartoon, full live action, or game CG.
```

### Example 27: Manga Panel Cuts Without Style Drift

```text
Cuts feel like designed manga panels, but the world remains continuous. Each cut changes shot size or angle, not art medium. Use the same palette, same contour thickness, same shadow rule, and same screen direction. Abstract impact panels must return to the established space immediately after the hit.
```

### Example 28: Stylized Slow Scene

```text
The style remains a quiet risograph print across the whole clip: limited two-color ink, slight misregistration, paper grain, flat silhouettes, and slow parallax layers. Do not suddenly add glossy 3D lighting, particles, or cinematic lens flare.
```

### Example 29: Fashion Video Consistency

```text
Every shot obeys editorial magazine logic: clean silhouette, controlled accessory density, soft key light, subtle paper or studio background, and one accent panel. Do not rebuild the layout with random text blocks each cut. Do not let accessories multiply.
```

### Example 30: World Rule Consistency

```text
The world owns ivory ceramic, pale gold sunlight, and red authority marks. The protagonist owns black fabric and cyan illegal light. Across shots, no other saturated color appears. If a new object enters, it must inherit one of these color roles.
```

## 5. Graphic Element Anchor Examples

### Example 31: Red Thread

Weak:

```text
red thread across the bridge
```

Strong:

```text
The vermilion thread is physically anchored to the protagonist's left wrist and wrapped around the opponent's sword handle. It stays suspended at waist height through midair, taut under tension, briefly occluding the foreground body. It may reflect faintly on wet stone but must not lie flat on the ground like a painted stripe.
```

### Example 32: Energy Trail

Weak:

```text
blue energy trail behind the motorcycle
```

Strong:

```text
The cyan trail originates only from the motorcycle's rear light vents. It follows the vehicle's exact path as a short controlled light smear, fading within two meters. It never appears ahead of the bike, on the rider's body, or as random background lightning.
```

### Example 33: Ink Slash

Weak:

```text
black ink slash effect
```

Strong:

```text
The ink slash is the visual trace of the blade edge. It begins at the sword tip, follows the diagonal cut path, thickens only at the impact point, then breaks into dry-brush fibers. It does not appear before the sword moves.
```

### Example 34: Ribbon Movement

Weak:

```text
red ribbon flying dramatically
```

Strong:

```text
The ribbon is tied to the back of the weapon handle. It trails behind the weapon with delayed follow-through, wraps around foreground air only during the spin, and settles downward after the strike. It has cloth weight and does not behave like laser light.
```

### Example 35: UI Lines

Weak:

```text
futuristic UI lines around the character
```

Strong:

```text
UI lines belong only to the scanning gate in the background. They project from fixed wall emitters, align to the character's body as measurement marks, and disappear after the scan. They are not decorative overlays floating randomly across the frame.
```

## 6. Prompt Rewrite Examples

### Example 36: From Generic To Designed Fight

Before:


## 7. Negative Prompt Examples

### Example 43: General Advanced Style Negative

```text
Avoid name-salad style mixing, random decorative effects, oversaturated colors, generic AI gloss, plastic surfaces, cluttered background, weak focal point, inconsistent rendering style, and texture applied equally everywhere.
```

### Example 44: Stylized Video Negative

```text
No style drift between shots, no sudden switch to photoreal/live-action/cartoon/game-CG, no palette expansion, no random particles, no background rebuilding, no character becoming a different rendering level after a cut.
```

### Example 45: Graphic Line Negative

```text
The line must not detach from its source, become a floor stripe, turn into random speed lines, multiply into unrelated ribbons, pass through bodies without occlusion, or appear before the action that creates it.
```

### Example 46: Premium Character Negative

```text
No cheap idol-poster glow, no random accessories, no costume detail multiplication, no plastic skin, no low-end collage, no meaningless cyber panels, no text clutter stealing attention from the face and silhouette.
```

### Example 47: Premium Vehicle Negative

```text
No glowing wheels unless specified, no random greebles, no toy proportions, no melted silhouette, no extra exhausts appearing, no light strips changing color, no showroom-perfect plastic finish.
```

### Example 48: Ink / Paper Negative

```text
No gray muddy overpainting, no ink splash everywhere, no generic fog, no uncontrolled brush decoration, no paper texture covering focal details, no full-frame dirt.
```

### Example 49: 2.5D Hybrid Negative

```text
No live-action human face, no chibi cartoon simplification, no flat sticker character pasted on 3D background, no inconsistent light direction, no environment reflection ignoring the character.
```

### Example 50: Editorial Layout Negative

```text
No excessive typography, no random fake words, no decorative UI spam, no e-commerce product layout, no overly busy collage, no text covering the face or key silhouette.
```

## Compact Choice Cheatsheet

Use these fast mappings:

- "帅酷角色": editorial fashion illustration + 2.5D cel-real + restrained industrial material
- "高级打斗": woodcut/ink graphic action + one accent color + clear silhouette
- "科技载具": minimal industrial futurism + material wear + functional light
- "概念海报": Swiss grid or constructivist geometry + semantic object relation
- "诗意国风": ink wash restraint + large negative space + material evidence
- "高张力": composition first, effect second; diagonal force, foreground occlusion, brief impact frame
- "不想普通动漫": define rendering hierarchy: stylized character, physical lighting, restrained texture, no chibi
- "别AI味": reduce glow, reduce random details, add material logic, define one focal hierarchy
