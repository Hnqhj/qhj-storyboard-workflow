# Style Taxonomy

Use this when selecting or translating an aesthetic style. Pick one primary family and, at most, one secondary influence.

## Selection Rule

Choose style by function:

- action clarity: graphic cel-real, ink slash, woodcut, limited-palette anime impact
- luxury/fashion: editorial photo-illustration, art-book layout, restrained metallic detail
- memory/dream: watercolor wash, soft graphite, paper cut, aged print
- pressure/dread: noir, expressionist shadow, brutalist geometry
- ritual/myth: ink wash, woodblock, fresco, icon-like symmetry
- speed/tech: 2.5D cel-real, vector graphics, chrome/minimal industrial design
- conceptual poster: Swiss/modernist, constructivist, minimal editorial, risograph

## Style Families

### 1. 2.5D Cel-Real / NPR Hybrid

Use for stylish characters with believable light and material.

Prompt traits:
- cel-shaded character planes, clean line accents, realistic 3D lighting, physical fabric folds, sharp rim light, controlled reflections
- real depth and camera physics, but not live-action skin

Avoid:
- flat cartoon, plastic CG, chibi simplification, photoreal face drift

### 2. Editorial Fashion Illustration

Use for character covers, luxury attitude, magazine-like coolness.

Prompt traits:
- centered or asymmetric fashion portrait, elegant negative space, restrained typography or no text, polished skin/hair, fabric texture, controlled high-end lighting

Avoid:
- e-commerce layout, busy poster text, cheap beauty filter, random accessories

### 3. Swiss / International Typographic Poster

Use for clean conceptual posters and disciplined visual systems.

Prompt traits:
- grid, strong hierarchy, large simple shapes, strict alignment, limited palette, typography as structure

Avoid:
- decorative clutter, random grunge, effects without hierarchy

### 4. Constructivist / Geometric Propaganda

Use for power, revolution, urgency, industrial movement.

Prompt traits:
- diagonal force, red/black/cream palette, geometric blocks, simplified heroic silhouettes, bold poster composition

Avoid:
- fake historical copying, too many symbols, text overload

### 5. Brutalist Graphic Design

Use for raw authority, institutional pressure, anti-beauty edge.

Prompt traits:
- heavy blocks, harsh cropping, exposed grids, rough paper, utilitarian typography, asymmetric pressure

Avoid:
- accidental ugliness, unreadable hierarchy, random dirt

### 6. Risograph / Screenprint

Use for tactile graphic charm, music poster energy, controlled handmade imperfection.

Prompt traits:
- limited spot colors, visible paper grain, halftone texture, slight ink misregistration, flat shapes, crisp silhouette

Avoid:
- muddy colors, excessive noise, everything dirty

### 7. Woodcut / Linocut

Use for violent silhouettes, mythic action, hard graphic contrast.

Prompt traits:
- carved black shapes, thick contour lines, hard white cuts, rough ink edges, bold negative space, dramatic figure-ground contrast

Avoid:
- overly detailed soft shading, random triangle shards, weak silhouettes

### 8. Ink Wash / Xuan Paper

Use for restraint, poetic violence, emptiness, ritual, memory.

Prompt traits:
- ink bleed, dry-brush edges, wet/dry paper boundaries, large calm negative space, few decisive strokes

Avoid:
- filling the frame with brush effects, generic fantasy mist, uncontrolled gray mud

### 9. Ukiyo-e / Woodblock-Inspired

Use for graphic waves, wind, fabric, stylized motion, flat color elegance.

Prompt traits:
- flat color zones, elegant contour, patterned cloth, stylized water/wind lines, asymmetrical composition, paper texture

Avoid:
- copying a specific historical artwork, overdecorated patterns

### 10. Neo-Noir Graphic

Use for danger, secrecy, loneliness, urban tension.

Prompt traits:
- hard side light, black shadow fields, wet reflections, Venetian-blind or signage patterns, limited color accent

Avoid:
- generic cyberpunk neon, excessive lens flare, muddy darkness hiding action

### 11. Expressionist Shadow

Use for psychological distortion, fear, moral pressure.

Prompt traits:
- warped geometry, tall shadows, off-axis framing, sharp contrast, environment expressing mental state

Avoid:
- random surrealism without story function

### 12. Cut-Paper / Shadow-Box

Use for storybook abstraction, poetic motion, clear depth layers.

Prompt traits:
- layered paper planes, visible paper fiber, soft cast shadows between layers, limited palette, stop-motion-like movement

Avoid:
- flat sticker look, no depth, cheap classroom craft unless desired

### 13. Collage / Photomontage

Use for media critique, memory fragments, editorial shock.

Prompt traits:
- mixed print fragments, torn edges, scale contrast, deliberate seams, limited color system, one dominant focal object

Avoid:
- random scrapbook clutter, inconsistent perspective without intent

### 14. Bauhaus / De Stijl Modernism

Use for precise design systems, playful geometry, abstract order.

Prompt traits:
- circles, rectangles, primary colors, strong grid, clean geometric balance, minimal surface texture

Avoid:
- using it for emotional realism or complex fight choreography without simplification

### 15. Baroque Chiaroscuro

Use for sacred drama, luxury darkness, theatrical revelation.

Prompt traits:
- deep shadow, single strong warm key light, illuminated skin/fabric, diagonal body composition, rich material contrast

Avoid:
- mixing with flat cartoon unless clearly defined as 2.5D stage lighting

### 16. Minimal Industrial / Product-Design Futurism

Use for tech, vehicles, weapons, architecture, high-end hard-surface design.

Prompt traits:
- clean silhouettes, matte/gloss contrast, brushed metal, precise seams, restrained accent light, functional geometry

Avoid:
- random sci-fi panels, neon overload, meaningless greebles

## Style Hybrid Rules

Good hybrids:
- 2.5D cel-real character + realistic 3D environment
- ink wash world + hard red graphic action accent
- risograph texture + Swiss composition
- woodcut silhouettes + limited anime impact timing
- editorial fashion + cyber-industrial material design

Risky hybrids:
- photoreal human face + flat manga body
- oil painting + cyber UI + watercolor + 3D game CG
- ink wash + heavy neon cyberpunk without color ownership
- handmade paper style + glossy plastic effects
