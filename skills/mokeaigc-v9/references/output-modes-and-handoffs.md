# 输出模式与交接

## Planning-only

适用于方向尚待批准：

```text
世界名与世界承诺
连续性 Bible
方面矩阵
开放的创作选择
```

此模式不提前写平台提示词。

## Compact（默认）

```text
世界名 / 介质 / 比例 / 数量 / 重要假设
2–3 句世界概念
5–6 类连续性锚点
每个方面：一句视觉意图 + 一条完整平台中性提示词
下游交接
```

摄影、灯光已经写在完整提示词里时不重复拆字段。

## Production

仅在用户明确需要时输出：

```text
方面功能
Camera（机位、距离、视场、景深、构图）
Lighting（来源、方向、软硬、反差、色温、空气与材质作用）
English Prompt
中文提示词
平台编译副本（由当前 adapter 负责）
```

双语语义应等价。平台参数若只需执行一次，只显示一次，避免误触发重复任务。

## 子集

用户指定子集时严格输出该子集，并按九方面的规范顺序排列，除非用户要求其他顺序。不要为了“完整”补回九张。

## 平台交接

平台中性场景必须先冻结以下语义：主体、动作、空间关系、连续性锚点、光线、材料、空气和定向约束。Adapter 只能改变语法和当前有效参数，不改世界事实。

- Midjourney -> `$midjourney-generation-adapter`；
- GPT Image / IM2 -> `$im2-clean-image` 负责材质、干净度和负面卫生；
- 其他平台 -> 对应当前 adapter，无法核实时只交平台中性版本。

平台版本、参数、分辨率、成本和兼容性是时效事实，禁止从本参考固化。

## 生产交接

- 世界生产设计和最终图像包：`$world-visual-development-director`；
- 反复出现的实体：`$character-continuity-bible`；
- 视频：只交 3–6 条稳定世界法则，不交九段静帧全文；
- 九宫格拆格：用户明确确认后交 `$curate-image-grid`；
- 真正生成/下载媒体时进入 `$generation-asset-pipeline`。
