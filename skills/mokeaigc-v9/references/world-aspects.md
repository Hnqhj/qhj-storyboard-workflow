# 九个世界功能

把方面当作叙事功能，不是物品清单。默认九项全做；用户或上游指定子集/数量时严格服从。

## 1. 居民

通过角色、身体覆盖、姿态、行为和环境关系揭示谁生活在这里。禁止排排站、时装姿势、角色设定表和物种陈列。

## 2. 动物

通过劳作、照料、迁徙、捕猎、骑乘、巢穴、足迹、影子、呼吸或遗骸揭示与居民共享世界的生命。禁止生物图鉴和标本陈列。

## 3. 建筑

揭示人们怎样栖身、聚集、统治、隐藏、维修、祭祀或记忆。必须通过烟、脚步、织物、工具、食物、通行、损坏、守卫或仪式表现“使用中”的空间；禁止空设计效果图。

## 4. 地景

把地理、气候和地形当作塑造文明的力量。用路线、侵蚀、作物、船、废墟、远处身影、烟、脚印或天气证明尺度和后果。

## 5. 日常

表现反复发生的普通行动：劳作、做饭、清洗、修理、交易、家庭节奏、训练、玩耍、守火、备工具。不要把典礼、灾难、战斗或象征摆拍冒充日常。

## 6. 迁徙与交通

表现生命、货物或知识怎样穿过空间：步行、骑乘、划船、拖曳、攀爬、漂流、出发或抵达。必须让路线、地形、重量、节奏和力气可见。

## 7. 声音与文化

把声音、记忆、意义或表演变成可见事件：聆听、吟唱、钟、乐器、工具敲击、舞蹈、风驱动物件、寂静、口传、哀悼、仪式或歌唱。

## 8. 权力与压力

揭示什么在治理或考验世界：仪式权威、社会沉默、危险劳作、匮乏、热、风暴、洪水、惩罚、追逐、对峙或变化前一刻。不要默认成战争。

## 9. 私密肖像

用一个私人情绪节拍承载世界灵魂：反应、手势、目光、伤口、呼吸、脏手、半明的脸、隐藏表情或画外聆听。禁止默认居中正面肖像。

## 重叠裁决

- 例行行为 -> 日常；
- 跨空间移动 -> 迁徙交通；
- 声音、记忆、表演 -> 声音文化；
- 危机、权威、压力 -> 权力压力；
- 私人反应 -> 私密肖像；
- 土地作为力量 -> 地景；
- 建成空间通过使用被揭示 -> 建筑。
