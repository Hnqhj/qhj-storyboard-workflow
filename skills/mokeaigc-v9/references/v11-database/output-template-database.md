# V11 输出模板数据库

## Compact 源模板

```text
世界名
Platform / Aspect ratio / important assumptions
2–3 句世界概念
Environment / inhabitants / materials / ecology / palette / forbidden drift
每个方面：Visual intention + Prompt
```

默认用于直接可读的交付。

## Production 源模板

```text
方面
World note
Camera EN / 中文
Lighting EN / 中文
English Prompt
中文提示词
```

仅在用户要求双语、拆字段或生产包时使用。

## Planning-only 源模板

```text
World concept
Continuity bible
Nine-row / selected-row aspect matrix
Open creative decisions
```

方向未批准时使用，不提前写最终平台提示词。

## 子集规则

用户点名某几个方面时，只输出这些方面，并保持规范顺序；不为了模板完整补回九张。
