# V11 镜头变化启发式数据库

这些条目可以带，但不作为默认配额。

| 原包启发式 | 数据库状态 | 可用场景 | 不应使用 |
|---|---|---|---|
| 每帧至少三个连续性锚点 | optional | 多图漂移明显、世界元素多 | 极简画面被锚点挤满 |
| 同一焦段区间最多使用三次 | optional | 九张看起来像同一机位 | 统一镜头系统是明确美学 |
| 至少两张安静、一张高压 | optional | 整板情绪完全等强度 | 世界没有高压事件，或用户要单一冥想气质 |
| 覆盖建立、中景、近景、细节 | active candidate | 完整世界板需要信息尺度变化 | 用户只做特定方面/单一尺度研究 |
| 混合平视、低机位、高机位、俯视、遮挡、倒影、框景 | optional | 机位单调且缺叙事作用 | 为了凑角度随机变化 |
| 避免重复主地点、动作、构图装置 | active candidate | 多方面世界板 | 重复本身承担仪式、对照或时间变化 |

调用顺序：先诊断实际单调原因，再选一条启发式；不得一次把全部配额叠上。
