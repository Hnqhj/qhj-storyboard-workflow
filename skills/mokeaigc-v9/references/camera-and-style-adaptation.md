# 摄影与风格适配

## 可替换的成像配置

```yaml
camera_position:
camera_height:
subject_distance:
field_of_view_or_focal_intent:
depth_of_field_intent:
lens_character:
capture_medium_or_emulation:
framing_device:
motion_trace_in_still:
```

用户或上游摄影/风格 Skill 可以覆盖任意字段；删除冲突默认，而不是把两套配置叠在一起。

## 摄影因果

- 透视主要由相机位置和主体距离决定；
- 焦段主要控制视场；保持同样取景时改变焦段通常意味着相机移动，因此透视也会改变；
- 景深是光圈、对焦距离、焦段、画幅/传感器、输出条件共同结果；
- 只写真正帮助生成和验收的变量。

焦段范围只能作为起点：地理/建筑可考虑广角，日常观察可考虑常规视场，亲密反应可考虑中长焦，远距离层叠可考虑长焦。最终以相机在哪里、离主体多远、画面要读什么为准。

示例：

```text
相机在工人腰部高度、距离很近，以广视场同时保留其身体重量和周围机器
相机隔着山谷远距离观察，以压缩视场把旅人、山脊和风暴前沿叠在一起
平视亲密近景，浅焦停在聆听者刚刚变化的反应上
```

## 介质和风格

- 数字采集需要胶片响应时写 `film emulation` 或具体可见响应，不把数字相机与字面胶片拍摄混为一条物理事实；
- 风格拆成构图密度、相机距离、光源方向/软硬/反差/色温、颜色、材料、空气、颗粒和高光响应；
- 名字只能作检索锚点，执行正文必须脱离人名成立；
- 人类皮肤细节只用于近距离、能解析到面部的人；远景、背影、剪影、面具、非人和风格动画不加毛孔固定串。
