## 1. Information types

| Type | Viewer learns | Typical carrier |
|---|---|---|
| identity | who or what matters | face, silhouette, name, signature object |
| action | what is happening | body, object, mechanism, environment change |
| intention | what someone is trying to do | gaze, preparation, choice, withheld action |
| cause | why the state exists | target, evidence, past residue, trigger |
| consequence | what the action changed | reaction, damage, distance, silence, new blockage |
| geography | where things are and can move | wide relation, route, barrier, offscreen space |
| relationship | power, intimacy, threat, dependence | blocking, distance, eye line, shared object |
| rule | how the world/system behaves | repeatable response, mechanism, social behavior |
| time | what just happened/is happening/will happen | residue, present action, warning, irreversible state |
| emotion | how the viewer interprets the event | behavior plus context, timing, consequence, sound |

## 2. Valid shot-to-shot deltas

Use one or more:

```text
add -> answer -> reveal cause -> reveal target -> contradict -> reframe
-> escalate -> change relation -> show consequence -> withhold with pressure
```

Shot-size change, angle change, lens change, push-in, orbit, or light change are not deltas by themselves. They become meaningful only when they change what the viewer can know or feel.

## 3. Emotion carriers

Avoid naked emotion labels. Use carriers:

- behavior: jaw locks, hand stops, chair is not offered, message remains unread;
- context: everyone else celebrates while one person folds an empty coat;
- timing: reaction arrives late, sound cuts before the face changes;
- consequence: anger is followed by choosing not to strike;
- environment: two place settings but one cold meal, rain entering through a broken roof;
- relationship: one person stays in focus while another is excluded by blocking or depth.

For empty scenes, require at least two of:

- trace of prior human action;
- object state or displacement;
- directional light with a narrative source or expiry;
- sound implication;
- weather/material change;
- blocked or abandoned route;
- visible temporal residue.

## 4. Redundancy matrix

An adjacent shot is probably redundant when four columns remain unchanged:

| Carrier | Behavior/state | Implied meaning | Viewer knowledge | Result |
|---|---|---|---|---|
| same | same | same | same | delete or redesign |
| same | changes | same | slightly changes | keep only if change is causal |
| same | same | reframed | changes | may be a strong reaction/reveal |
| new | same event | reveals cause/target | changes | useful coverage |
| new | consequence | transforms meaning | changes strongly | strong progression |

Repetition is valid when its function is explicit: ritual, denial, obsession, pressure, comic timing, surveillance, or delayed recognition. State what intensifies.

## 5. Diagnostic examples

### Repeated emotion

```text
Shot 1: close push on an angry father.
Shot 2: medium shot of the same angry father.
```

The second shot does not change viewer knowledge. Replace it with the daughter, the evidence he sees, his restrained hand, or the room's reaction.

### Attractive empty atmosphere

```text
Sunbeams through blinds in an empty room.
```

This states light, not meaning. Add a carrier: a half-packed suitcase crossing the light, dust disturbed beside an open drawer, or two cups with only one still steaming. Now light reveals a temporal and emotional condition.

### Tool-driven collage

```text
drone wide -> dutch close-up -> orbit -> macro eye -> speed ramp
```

Without changing information, this is a technique reel. Rebuild as:

```text
route/geography -> behavior -> hidden target -> failed choice -> consequence
```

Then select only the camera operations that prove those functions.
