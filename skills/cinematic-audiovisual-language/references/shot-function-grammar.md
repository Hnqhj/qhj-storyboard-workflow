# Shot Function Grammar

Use this for any storyboard or AI video prompt. A shot is not a decoration; it is a sentence.

## Shot Sentence

Define every shot as:

```text
viewer sees [subject] doing [action] from [position] so that [new meaning] happens.
```

If the "so that" clause is weak, the shot is probably filler.

## Core Shot Functions

- Establish geography: show where the action lives and what scale controls the scene.
- Orient relation: clarify who/what is near, far, above, below, ahead, behind, pursuing, or escaping.
- Initiate action: make the first decisive movement readable.
- Escalate pressure: narrow space, increase speed, add obstacle, change camera height, or compress distance.
- Reveal information: show what a character sees, hides, notices, or fails to notice.
- Shift power: change dominance through height, scale, distance, framing, or blocking.
- Register emotion: move close enough for eyes, breath, hesitation, pain, or decision.
- Hide a cut: use action match, object wipe, foreground pass, sound bridge, or light flash.
- Compress time: montage, jump in geography, repeated motif, rhythmic fragments.
- Release tension: hold after the peak, widen the frame, or let the subject exit.

## Useful Progressions

These arrows are backstage shot functions, not final Liu prompt syntax. Compile the default camera grammar into `镜头语言总控` once. Paste-ready event beats inherit it; only a genuine special-camera beat adds its trigger, path, proof job, and concrete visible result.

Character entrance:

```text
world before subject -> trace/anomaly -> partial reveal -> full reveal -> identity close-up -> world reacts
```

High-speed traversal:

```text
map-scale wide shot -> low ground speed -> side tracking through obstacles -> top-down geography update -> near-camera pass -> release into distance
```

Confrontation:

```text
shared space -> relation angle -> first close-up -> reaction close-up -> insert of decisive object -> power-shift angle
```

Mystery or dread:

```text
empty space -> off-screen sound/motion -> point-of-view -> delayed reveal -> close-up response -> unresolved wide shot
```

Fashion/action reveal:

```text
silhouette -> material insert -> full-body pose in space -> movement beat -> face/eye close-up -> graphic exit
```

## Shot Size As Function

- Extreme wide: world scale, loneliness, danger, geography.
- Wide: full body action, vehicle path, fight readability, space relation.
- Medium: posture, hands, costume, decision, interpersonal tension.
- Close-up: identity, emotion, intention, sensory detail.
- Extreme close-up: trigger, blink, finger, wheel, blade, tiny cause of a big change.
- Insert: prop, hand, wheel, screen, sign, object clue. Use it when the object changes the scene.

## Angle As Function

- Low angle: power, threat, heroic launch, mass passing over the viewer.
- High angle: vulnerability, surveillance, tactical pattern, smallness in a system.
- Ground level: speed, impact, weight, vehicle danger.
- Overhead: route, maze, trap, choreography, urban geometry.
- Eye level: intimacy, neutrality, realism.
- Dutch angle: instability. Use lightly and intentionally.

## Cut Logic

Cut when one of these changes:

- new information
- new spatial relation
- new emotional state
- new physical obstacle
- new rhythm beat
- new scale
- new point of view

Avoid cutting just because time passed.
