随时说“这次详细展开”即可增加说明；说“这次不要按省 Token 模式”即可覆盖本次偏好。卸载 Skill 及其未修改的常驻规则时，运行安装器，保留相同的目标与自定义路径参数，改用 `--uninstall`，不要同时加 `--activate`。

这是工作方式优化，不是压缩算法、额度解锁或固定折扣。节省幅度取决于任务、上下文、模型和宿主；本包未给出受控对照下的节省比例。
