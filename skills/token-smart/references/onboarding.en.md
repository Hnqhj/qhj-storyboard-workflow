# Token Smart installed

Save avoidable work, not required work.

How it works: read only relevant files and skill branches, reuse evidence and implementations, prefer executable checks, stop repeating passed checks, and add reasoning, reviewers or subtasks only when they can change the result.

What feels different: fewer progress reports, result-first answers, lighter handling of small tasks, and continuity from verified progress in long tasks. Requested detail, complete code, and necessary tests remain intact.

Default: on-demand use. Invoke `$token-smart` in Codex or `/token-smart` in Claude Code, or ask to use Token Smart. Installing with `--activate` adds a short preference to the selected host's instruction file for later sessions. It does not change model or quota settings. Start a new session if the current one has not discovered the skill.

Ask for a detailed answer whenever you need one, or ask to skip Token Smart for this task. To uninstall the skill and its unchanged standing rules, run the installer with the same target and location options and `--uninstall`, without `--activate`.

This is a workflow preference, not a compression algorithm, quota unlock, or fixed discount. Savings depend on the task, context, model, and host; no controlled token-saving percentage is claimed.
