# Sophia Creative Workflows

Use this reference when helping with video, music, AIGC, prompt, storyboard, or content strategy tasks for the user.

## Creative Output Standard

Prefer outputs that can be used directly in production:

- clear structure
- concrete shots or steps
- visual language
- tool-ready prompts
- constraints and risks
- next action

Avoid generic advice unless the user explicitly wants brainstorming.

## Video Planning

For a video idea, structure the answer around:

1. Goal and audience
2. Hook
3. Narrative beat or three/four-act structure
4. Shot list
5. Visual style
6. Rhythm and sound
7. AI tool workflow
8. Risks and alternatives

For shot design, preserve the user's script. Do not invent additions unless asked. Use clear spatial language and include subject, environment, motion, lighting, color, mood, and technical constraints.

## AI Video Prompt Pattern

Positive prompt:

```text
[subject], [scene details], [camera movement], [lighting], [color style], [mood], [physical interaction], [render/quality parameters]
```

Negative prompt:

```text
text, watermark, blurry, low quality, distorted face, extra fingers, inconsistent character, unwanted style, unwanted lighting, unwanted mood
```

Adapt the negative prompt to the actual scene. Do not blindly reuse exclusions that contradict the user's requested style.

## Tool Selection

Use current official or primary sources when making claims about tool versions, pricing, availability, rankings, or model capabilities.

When choosing tools, compare:

- output quality
- character consistency
- audio/lip-sync needs
- shot length
- speed and cost
- editability
- local vs cloud constraints

For product/display videos, consider split pipelines: one tool for high-quality generation, another for editing, consistency, or sound. Verify current tool capabilities before recommending specific versions.

## Music Collaboration

When pairing AI music with video:

1. Identify emotional arc and pacing.
2. Choose style references.
3. Map beats to visual cuts.
4. Specify tempo, instrumentation, density, and transition points.
5. Include usage/licensing cautions when relevant.

## Content Strategy

For Xiaohongshu/short-video planning, include:

- target viewer
- hook
- visual promise
- structure
- title options
- cover direction
- retention risks
- test metric

Keep strategy practical. The user values actionable creative direction over broad platform theory.
