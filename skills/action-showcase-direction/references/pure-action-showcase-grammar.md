## 1. Showcase Versus Fight

A fight is organized by initiative and response between bodies. A showcase is organized by progressive proof of an action system.

Valid showcase consequences include:

- a new stance, route, elevation, facing, or support state;
- a weapon changing grip, function, scale, configuration, or energy state;
- a floor trace, displaced air, debris path, reflection change, or architectural response;
- a trajectory becoming a graphic field or transition;
- an action resolving into a stronger or quieter final silhouette.

No enemy is required. Empty movement is still weak when nothing changes.

## 2. Display Contract

Define these fields before storyboarding:

```text
identity promise: what viewers should recognize immediately
physical profile: actor strength, weapon length, balance, and support
movement signature: linear, circular, axial, flexible-delayed, braced, aerial, or modular
function ladder: 3-6 distinct things the system can do
escalation variable: scale, speed, function, depth, configuration, or spatial consequence
terminal icon: the final body/weapon/environment relationship
```

Good function ladders:

```text
heavy polearm:
carry -> preload -> broad orbit -> ground contact -> delayed brake

paired firearms:
alternating fire -> crossing travel -> recoil brake
-> synchronized charge -> trajectory-field finish

mechanical wings:
attached lift -> detached modules -> swarm control
-> shield/cocoon -> restored wing state

transforming blade:
compact precision -> staged deployment -> regrip
-> full-scale heavy use -> axial depth attack -> terminal configuration
```

## 3. Macro Structures

### 10-15 Seconds

```text
0-2s identity hook and first decisive motion
2-5s full-body handling and displacement proof
5-8s second function, level change, or direction change
8-11.5s dominant escalation or transformation
11.5-15s final peak, inertia resolution, and icon
```

Use fewer peaks when the weapon is extreme mass. Use more peaks only when each action remains readable.

### 20-30 Seconds

```text
identity hook
-> first physical phrase
-> pause or mechanism bridge
-> second phrase with a new function and spatial relation
-> ultimate
-> 2-4 second closure
```

### 30-60 Seconds

Use three to five chapters:

```text
chapter 1: establish the original handling contract
chapter 2: change function, support, or configuration
chapter 3: change scale, elevation, or depth relation
chapter 4: strongest integrated phrase
chapter 5: consequence and final icon
```

Each chapter ends in a stable state that becomes the next chapter's starting fact.

## 4. Shot-Function Escalation

Build tension by changing what the camera proves.

| Function | Useful framing | What it must prove |
| --- | --- | --- |
| identity | extreme close-up / insert | grip, guard, edge, core, release, surface language |
| handling | wide / full body | stance, support, weapon length, body route |
| scale | strong foreground perspective | actor-to-weapon ratio and reach |
| trajectory | lateral or three-quarter wide | line, arc, plane, follow-through |
| geography | extreme wide / overhead | displacement, route, field, chapter consequence |
| depth | axial lens / toward-camera pass | reach, vanishing point, speed, danger |
| mechanism | ordered inserts plus full-body proof | source, deployment, lock, regrip |
| ultimate | stable wide or controlled perspective rupture | irreversible spatial or functional change |
| closure | medium-to-wide | body, weapon, support, and environment settled together |

Rules:

- A close-up is not automatically sophisticated. It must reveal new functional information.
- Extreme perspective proves size but not weight. Add delayed startup, body commitment, support, and braking.
- Axial shots create depth but often hide grip and support. Establish those before entering the axis.
- Return to a readable body-and-weapon relation after abstract spectacle.

## 5. Weapon-Family Integrity

Preserve a family's movement signature before fantasy amplification.

### Precision Blade / Katana-Coded

```text
compressed stillness -> clean line -> hip/foot commitment
-> controlled follow-through -> deliberate finish
```

Avoid replacing every cut with large circular trails. If the blade expands into a heavy form, name the mode change and alter the handling contract.

### Head-Heavy Polearm Or Scythe

```text
visible load -> delayed outer head -> large orbit
-> body follows -> ground, wide stance, or circular continuation brakes
```

### Paired Weapons

Give left and right different jobs:

```text
lead/follow, attack/guard, fire/recoil-control, anchor/free, near/far
```

Avoid mirrored windmilling throughout.

### Shield

Differentiate:

```text
carry -> brace -> redirect -> ground anchor -> release/autonomous state
```

If the shield becomes autonomous, show the release or mode cue.

### Modular Or Transforming System

Every new state needs:

```text
part source -> deployment path -> lock proof
-> mass or balance change -> regrip -> new movement behavior
```

## 6. Long-Form Anti-Repetition

Create an internal chapter ledger:

```text
chapter / function / silhouette / support / body level / route
/ weapon path / trajectory plane / shot-scale family / camera height
/ tempo / effect behavior / sound envelope / stable end state
```

Change at least four columns between chapters.

Common contrast pairs:

- asymmetric load -> symmetric load;
- grounded brace -> mobile flow;
- horizontal field -> vertical axis;
- compact precision -> broad committed mass;
- attached system -> detached modules;
- visible mechanics -> abstract ultimate;
- loud action -> quiet recovery.

Do not count a color flash, bigger trail, or faster cut as a new chapter by itself.

## 7. Effects And Transitions

### Effect Causality

Use:

```text
source -> trajectory -> interaction/state change -> decay
```

Examples:

- blade edge emits a narrow trail that follows the exact edge plane;
- shield rim produces a broad low arc tied to its outer radius;
- flexible cable creates delayed curves between fixed anchors;
- propulsion exhaust begins at a named port and changes body acceleration;
- floor trace starts at contact and remains after the weapon passes;
- core activation travels through visible channels before the new form unlocks.

### Transition Causality

Use:

```text
outgoing action covers, matches, or transforms the frame
-> incoming shot inherits vector, contour, material, brightness, or sound
```

Useful transitions:

- weapon/cloth/body foreground wipe;
- match cut from circular core to circular trajectory;
- red line extends into the next shot's horizon or weapon edge;
- impact white reveals a new scale only when the hit or release causes it;
- mechanism sound begins before the insert;
- debris, smoke, water, shadow, or reflective flare bridges shots;
- an ultimate trajectory expands into the environment or graphic space.

Avoid:

- unrelated flash transitions;
- particles without a source;
- repeated glitch cuts that hide action;
- trails that contradict blade direction;
- transition effects stronger than the state change they represent.

## 8. Action Closure

Closure is not simply posing. Resolve:

```text
weapon inertia
body balance
support pressure
environmental response
sound decay
new configuration or relation
```

Strong terminal states:

- weapon planted and body stabilized;
- modules re-dock and wings settle;
- paired weapons lock into distinct guards;
- shield remains as an independent anchor;
- a large trajectory collapses into one clean axis;
- abstract effects clear to reveal a readable hero silhouette;
- the first image returns with a changed weapon or body state.

Keep the post-peak beauty section proportional:

```text
15s film: roughly 1.5-3s
30s film: roughly 2-4s
60s film: roughly 3-6s
```

Extend it only when fashion, character portraiture, or product detail is a primary objective.

## 9. Timing And Sound

Use contrast, not constant intensity.

```text
still identity detail
-> sharp first proof
-> readable full-body phrase
-> quieter mechanism or state bridge
-> broader second phrase
-> brief silence or tonal vacuum
-> dominant peak
-> decay and settle
```

Sound should distinguish functions:

- grip and preload: leather, chain, servo, cloth tension, breath;
- launch: short air cut, motor engagement, string or cable tension;
- mass: low-mid body resonance, floor pressure, delayed debris;
- mechanism: staged clicks, rails, gears, latches, locks;
- trajectory: narrow hiss, broad pressure wave, flexible delayed snap;
- recovery: scrape, vibration, armor settling, cable return, breath release;
- ultimate: selective silence before the main transient;
- closure: long but controlled decay, then quiet material detail.

Do not synchronize every cut. Synchronize state changes and major peaks.

## 10. Failure Diagnosis

| Symptom | Likely cause | Next controlled change |
| --- | --- | --- |
| looks like disconnected cool shots | no chapter state chain | make each chapter end state the next starting fact |
| feels repetitive despite many cuts | shot angle changes but action contract does not | change function, support, route, plane, and recovery |
| weapon identity disappears | fantasy effects override family grammar | restore one signature line and recovery behavior |
| giant weapon feels light | scale shown without inertia | add preload, blade lag, body commitment, and long brake |
| transformation feels like replacement | no source or lock proof | show release, deployment, lock, regrip, settling |
| close-ups feel like filler | no new functional proof | assign one mechanism or decision per insert |
| trails look generic | effects lack source and edge plane | attach them to a named emitter and trajectory |
| transition feels random | incoming shot inherits nothing | match vector, contour, material, brightness, or sound |
| action has no result without enemy | peaks do not alter state | change route, support, configuration, environment, or scale |
| climax is only brighter | no consequence escalation | make the trajectory alter space or configuration |
| ending drags | beauty epilogue exceeds payoff | shorten to one material detail and one final relation |
| character PV becomes all attacks | showcase grammar used when identity/expression should lead | switch to PV structure: entrance, attitude, signature prop proof, short icon |
| final pose starts too early | terminal icon placed before the last action budget is spent | move final icon to the last 1-1.5s and add one more mid-late state change |
| action showcase becomes portrait posing | display contract has no function ladder or state changes | add 3-6 distinct function proofs and require route/support/environment changes |

## 11. Prompt Skeleton

```text
Create a [duration] pure action showcase with no opponent required.

Global visual master:
[medium and realism level], [primary aesthetic family],
[palette ownership], [line/shape/silhouette language],
[material-light system], [rendering hierarchy and optics],
[forbidden style drift].

Display contract:
[subject], [weapon/ability family], [actor/load relation],
[movement signature], [functions to prove], [terminal icon].

Chapter structure:
[chapter 1 function and end state].
[chapter 2 contrast and end state].
[chapter 3 strongest integration and consequence].
[recovery and final icon].

Shot grammar:
Use identity inserts only to prove [grip/release/core/lock].
Use full-body wides to show [support, route, weapon length, braking].
Use foreground perspective for scale, an axial shot for depth,
and reserve the strongest spatial transformation for the final peak.

Action physics:
[support -> body force chain -> weapon path -> follow-through -> brake].

Effects and transitions:
Every effect has a visible source and follows the weapon/body path.
Transitions inherit direction, contour, material, brightness, or sound
from the outgoing action.

Sound:
[chapter contrast, mechanism cues, silence, impact, decay].

Materials and image quality:
[material, lighting, AO/contact shadow, optical and motion realism].

Negative constraints:
No opponent invented; no repeated identical attacks; no decorative
close-ups; no camera movement replacing body displacement; no effect
detached from the action source; no giant weapon moving like a baton;
no transformation without source, lock, regrip, and settling; no
random flash transitions; no climax based only on brightness; no
long empty pose after the payoff.
```

## 12. Visual-Master And Duration Priority

The final prompt has a control hierarchy:

```text
global visual master
-> identity/world/prop locks
-> chapter and action-state progression
-> shot function and camera
-> local effects and transitions
```

Do not allow detailed shots to redefine the medium, palette, material system, or rendering style.

Separate three different meanings of time:

```text
total duration: hard delivery requirement
structural timing: approximate location of hook, turn, peak, and closure
physical timing: preload, acceleration, consequence, braking, and recovery
shot duration: optional editorial choice, not automatically a generation command
```

Default final-prompt language:

```text
开场立刻...，随即...；中段...；临近高潮...；最后...
```

Use exact macro-segment intervals when timing confidence is high and:

- the total sums correctly;
- no gaps or overlaps are accidental;
- each interval contains enough visual/action content;
- heavy or transforming actions have room for preload, deployment, lock, and braking;
- simple gestures are not stretched into idle holds;
- the strongest peak is neither premature nor crowded against the ending.

Timing evidence may include:

- reviewed reference footage or successful previous output;
- animatic, storyboard timing, or edit map;
- physical phase budget for preload, action, consequence, braking, and recovery;
- music downbeat or silence break;
- dialogue or lip-sync cue;
- first/last-frame alignment;
- transition into another generated or edited clip;
- product/message reveal at a required delivery point;
- platform or broadcast timing requirement.

If evidence is medium, use approximate ranges. If evidence is low, omit segment times. In every case, avoid hard-timing every internal camera cut.

Common timing failures:

| Symptom | Likely timing error |
| --- | --- |
| character stands or repeats | interval longer than action content |
| everything becomes slow motion | too little action assigned to a long segment |
| transformation snaps or skips locks | interval too short for mechanism stages |
| climax arrives too early | peak anchor placed before sufficient build |
| recovery disappears | ending interval consumed by the peak |
| camera feels stupid despite good ideas | hard duration forces a shot to stay after its function is complete |
