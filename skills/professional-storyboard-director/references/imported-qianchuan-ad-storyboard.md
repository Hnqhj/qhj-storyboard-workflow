# Imported Qianchuan And Ad Storyboard Patterns

Use this reference for 千川素材, vertical performance ads, product/ecommerce demos, hand close-ups, scene demonstrations, SaaS/software motion-design ads, launch videos, feature demos, and ad storyboards that must become Seedance-ready segments with synchronized image and sound.

This distills supplied local files `分镜策划师（千川-广告的）.md`, `SKILL_vYZJJu.md`, the title-font workbook preview in `400+即梦AI字体提示词模板.xlsx`, and ad-related material from `3.4分镜设计（优化）(1).zip`.

## 1. Ad storyboard contract

Commercial storyboards should prove a product, benefit, or behavior. Use beauty only when it proves:

- need/context;
- product silhouette or brand recognition;
- scale and hand/body relation;
- material, mechanism, texture, or performance;
- emotional/user result;
- CTA or memory frame.

Do not hide a product behind abstract mood unless mystery is the explicit creative strategy.

## 2. Source-material analysis table

When the user supplies an existing ad/video/material, first classify every beat:

```text
| Time | Picture type | Shot/lens | Composition | Light | Dialogue copy | Sound |
|---|---|---|---|---|---|---|
| 0-3s | human / product / hand / scene | close / medium / wide, lens feel, move | subject, action, background | key/rim/bounce/practical | exact words | music/SFX/voice |
```

Describe all picture types through "frame construction", not only performance:

- human: age/gender/style only when needed; posture, expression, hand business, relation to product;
- pure product: surface, angle, scale, background, contact shadow, material response;
- hand close-up: hand state, grip, touch pressure, product contact, background defocus;
- scene: location type, depth, atmosphere, product placement or use path.

## 3. Duration and segment defaults

- <=15s: one complete segment if it has one hook/action spine.
- 15-30s: usually two segments: Hook + pain / Proof + CTA.
- 30-60s: three or four segments: Hook -> pain -> proof -> CTA.
- 60-90s: five or six segments only if it is a long narrative or testimonial.

For Seedance packaging, keep generated clips 4-15s and preserve complete dialogue lines inside one segment.

## 4. Image-sound synchronization

For ad copy, every line must own a visible moment:

```text
spoken keyword = product action / hand touch / camera arrival / expression shift / metric reveal
```

Keep original wording when optimizing an existing material. Do not add subtitles unless requested. If text is needed, keep it short and stage it as title/slogan/CTA with clear timing, position, and visual style.

## 5. Product / hand / scene prompt blocks

Use these as building blocks in a storyboard, not as rigid forms:

### Product-only beat

```text
product reference and silhouette
surface/background
camera angle and shot size
material response: reflection, roughness, transparency, fabric, metal, liquid, texture
contact shadow / scale object
one proof action: rotate, open, press, pour, unfold, display result
sound: touch, click, fabric, glass, water, packaging
```

### Hand-use beat

```text
hand type only when relevant
grip/touch pressure/finger motion
product contact point
camera focus and depth of field
the product remains readable while the hand proves scale and use
```

### Scene-use beat

```text
who is using it, under what task or pressure
where the product sits in the frame
what changes after use
final memory frame / CTA
```

## 6. Software / SaaS motion-design ads

Use for apps, SaaS, UI demos, dashboards, AI tools, fintech, health-tech, and startup launch videos.

First two seconds must give a reason to keep watching. Choose one hook:

- data visualization burst;
- UI morph / button becomes progress/result;
- device materializes from dark/blur;
- code turns into finished product;
- metric counter climbs;
- glitch/noise resolves into clear UI;
- hand touches device and UI responds;
- neon activation line lights the feature;
- isometric zoom to show product ecosystem;
- logo particles become interface;
- split-screen feature stack;
- scanning light reveals details.

After the hook, run:

```text
product/device reveal -> 2-3 real UI functions -> benefit/proof -> CTA / brand memory
```

## 7. Software ad visual hierarchy

- Benefit first: the opening visual should imply what problem is solved.
- Device and UI are main actors; show real interface behavior, not only abstract particles.
- Keep negative space for readability.
- Use brand color every few seconds or at key state changes.
- Keep text readable for at least about two seconds when text matters.
- One or two device types per ad are usually enough.
- Motion transitions communicate the story: morph = smooth progress, zoom = focus/immersion, dissolve = concept shift, sharp cut + SFX = energy.

Style lanes:

- dark premium: black/navy, white text, electric blue/gold/cyan accent, subtle particles;
- clean minimal: white/light gray, charcoal text, single soft accent, whitespace and fine lines;
- neon cyber: black/dark gray, electric purple/cyan/pink, glow and controlled glitch;
- fresh modern: light blue/purple, soft gradients, rounded UI;
- orange energy: dark base with orange/yellow/red accents, bold fast transitions;
- glassmorphism: frosted blur, translucent cards, subtle gradients, soft highlights.

## 8. Reusable ad sequence patterns

### Feature demo, 6-8s

```text
device enters with motion blur;
screen wakes;
feature A animates;
brief label or voice line explains benefit;
transition to feature B;
final hint of more capability or CTA.
```

### Metric proof, 4-6s

```text
single number appears on dark/gradient background;
counter climbs with SFX;
supporting text or graph enters;
brand color reinforces;
space opens for CTA.
```

### Problem to solution, 6-8s

```text
show messy/slow/broken state;
brief glitch or pressure cue;
transition into clean solved interface;
show final organized result;
prepare CTA.
```

## 9. Title / typography prompt notes

Only use title-design language when the ad actually needs on-screen title, slogan, promotional text, or designed Chinese characters.

Title prompt formula:

```text
background and text color
exact title text
font/style identity
stroke details
material / 3D / glow / paper / brush / glass
commercial atmosphere
supporting props or subtitle if required
```

Keep generated text short, common, and easy to render. If typography is not the visual subject, avoid making the model generate complex text.

## 10. Common ad failures and fixes

| Failure | Fix |
|---|---|
| static screenshot | animate one UI element or camera relation |
| too many features | pick 3-4 and give each a separate proof moment |
| no product recognition | show product/brand/shape in the first seconds |
| unclear scale | add hand, device, desk, body, or use environment |
| weak material proof | add reflection, contact shadow, roughness, fold, click, opening, pressure |
| tiny or fast text | enlarge, increase contrast, hold longer, reduce words |
| no human relation | add hand, user gesture, face reaction, or simple use context |
| monotone rhythm | contrast fast hook, calmer proof, short CTA |
| too many devices | use one hero device or two complementary devices |
| sound feels pasted on | sync SFX to touch, UI response, metric hit, or transition |

## 11. Ad storyboard quality gate

Before finalizing:

- Is the commercial objective clear: attention, consideration, conversion, memory?
- Is the first 1-3 seconds specific, not generic beauty?
- Does every shot prove a benefit, feature, material, scale, use, or emotion?
- Are voice/copy and picture synchronized?
- Is product identity visible enough?
- Are UI/text/slogan readable within platform framing?
- Is the CTA or memory frame concrete?
- If turning into Seedance, is each segment 4-15s with one main action and one dominant camera move?
