# 有界的批量探索—选择—回灌

## R — 原文（Reading）

> “它是可以生成一百个的，但是我建议最多不要超过十个，因为我也选不过来……AI 生成的东西太多了，会影响咱们的感官。”
>
> — MokeLMa，视频 01，00:38:23–00:38:28；视频 02，01:11:35–01:11:58

---

## I — 方法论骨架（Interpretation）

批量生成的价值不是“数量自动换来审美”，而是把一个昂贵的开放题变成可比较、可淘汰的有限选择题。
一次循环只探索一个尚未解决的变量；身份、叙事、连续性等已批准条件保持不变。
发散前先定义预算、候选上限、评分维度和停止条件，避免先看结果再临时改变标准。
收敛时先过硬门槛，再做加权比较；每个淘汰项都要留下可复用的理由，而不是只写“感觉不对”。
下一轮只接收上一轮暴露出的单一缺口，不能把所有候选混合成更长、更模糊的提示词。
当最佳分数不再改善、预算耗尽、已有方案达标，或问题需要更强的参考/layout/资产约束时，必须停止继续生成。
复刻参考可以作为训练分支，但训练收益来自“比较—归因—写出规则”，而不是复刻次数。

## A1 — 课程中的应用（Past Application）

### 案例 1：从多机位候选收敛成可剪分镜

- **问题**：在时间和预算压力下，恋爱场景与战争场景需要足够的机位、景别和补镜覆盖，直接进入昂贵视频生成会放大返工。
- **方法论的使用**：讲者批量生成多个角度，把候选放回剪辑线，检查轴线、表情和覆盖缺口，再选出近景、手部、武器和空镜；缺什么才补什么。
- **结论**：候选批次的目的不是“多看图”，而是完成镜头覆盖、比较与补缺。
- **结果**：现场完成了批量候选—选镜—补镜—粗剪的闭环。课程提到的效率倍数没有对照实验，不能作为此方法的承诺。
- **出处**：视频 01，00:25:30–00:40:28；视频 02，00:28:09–00:34:59；对应案例池 `c07`。

### 案例 2：四百多张图只留下两种颜色方向

- **问题**：讲者希望找到一种特殊的油画感色彩方向。
- **方法论的使用**：他生成四百多张图，最后只保留两种认为有意思的方向。
- **结论**：大量发散有时能发现边缘方案，但如果缺少预设量表、淘汰记录和小样本对照，就不能证明数量训练了审美。
- **结果**：得到了两个方向，却没有可审计的成本、评分或审美增益证据；下游流程因此必须补上预算与选择账本。
- **出处**：视频 01，00:47:30–00:47:53；对应案例池 `c08`，证据强度为弱。

## A2 — 触发场景（Future Trigger）

### 用户会在什么情境下需要这个 skill？

1. 已生成几十到上百个图、镜头、海报或文案版本，团队仍无法做出选择。
2. 需要在固定时间、额度或制作成本内，为一个镜头补足机位、景别、表演或构图方案。
3. 想使用“九九归一”、九宫格、contact sheet、variant generation 或 design exploration，但还没有收敛机制。
4. 希望训练镜头或审美判断，并愿意通过复刻、并排比较、差异归因和规则复盘来练习。
5. 每轮生成都在继续加词、加参考、加变量，结果越来越多，却说不清究竟要解决什么。

### 语言信号

- “再多出几十个，我总能挑到一个吧。”
- “做一轮九九归一 / 九宫格，然后帮我收敛。”
- “We have too many variants; help us shortlist and converge.”
- “Set a generation budget, scoring rubric, rejection log, and stop rule.”
- “我想复刻这个镜头来练审美，怎么比较才不是只看感觉？”

### 与相邻 Skill 的区分

- `visual-calibration-loop` 提供获批视觉锚点；本 Skill 依据这些锚点管理候选预算、评分、淘汰和回灌。
- `invariant-exploration-director` 先决定什么必须固定、什么允许探索；本 Skill 随后执行有限批次的发散与收敛。
- `agent-harness-review-loop` 治理谁生成、谁评审、谁批准；本 Skill 只治理候选集与停止条件。

## E — 可执行步骤（Execution）

激活后，agent 必须输出一份可审计的“探索账本”，并按以下顺序执行。

### 1. 定义本轮唯一决策单元

- 写清交付物、使用场景、受众、已批准锚点，以及本轮唯一允许探索的变量，例如“只变景别”“只变手势”“只变次要纹理”。
- 列出不得改变的条件；若创作方向、身份或叙事目标尚未确定，暂停生成并转到 `creative-north-star`、`minimum-visual-bible` 或 `invariant-exploration-director`。
- **完成标准**：形成一页探索简报，包含 `目标 / 不变量 / 本轮变量 / 交付格式 / 决策人`，且本轮变量只有一个主项。

### 2. 先设预算、硬上限与停止条件

- 明确 `每批候选上限 / 最大轮数 / 总候选上限 / 时间或费用上限`。默认只采用人能一次并排比较的有限批次；课程中的“最多十个”是经验提示，不是永久阈值。
- 至少预设四类停止条件：已有候选达标；预算耗尽；连续两轮最佳分数提升低于预设最小增益；剩余缺口需要更强输入而不是更多样本。
- **完成标准**：所有数值在第一张候选出现前写入账本，后续若修改必须记录修改人和理由。

### 3. 建立评分表与淘汰理由码

- 先设硬门槛：身份/商品识别、叙事事实、连续性、交付规格、版权或品牌禁区。任何一项失败即淘汰，不用高“惊艳分”抵消。
- 再设 3–6 个加权维度，例如叙事清晰、情绪表演、构图、风格匹配、可制作性；权重总和必须为 100，并给出并列时的决胜规则。
- 建立理由码，例如 `I-身份失败 / N-叙事不清 / C-构图失衡 / L-光线不符 / D-重复无新增 / P-制作代价过高`。
- **完成标准**：每个维度都有可观察定义、分值范围、最低通过线和权重；不存在“整体感觉”这一未定义维度。

### 4. 生成并编号有限批次

- 固定不变量，只改变步骤 1 指定的主变量；每个候选保存唯一 ID、输入、模型/工具版本、参考资产和生成时间。
- 当前批次未全部评分前，不得启动下一批；不得通过换工具掩盖尚未分析的失败。
- **完成标准**：候选数量未超过批次上限，且每个候选都能追溯到输入与变量变化。

### 5. 硬门槛淘汰，再并排评分

- 先移除违反不变量的候选；对剩余候选以同一尺寸、色彩管理和展示条件做 contact sheet 或时间线比较。
- 每个候选必须留下分数、淘汰理由和一句可观察证据；保留 1 个主选、最多 2 个备选以及“没有候选达标”的合法结论。
- **完成标准**：入选和淘汰均能用评分表复算，决策人签字或明确确认；不能只给星标而无理由。

### 6. 只回灌一个差距

- 汇总落选原因，找出当前最高优先级、可被下一轮解决的一个缺口；把它转写成新的变量或更强的控制输入。
- 若问题是空间、动作、身份或真实光照，转到 `constraint-input-router` 或 `entity-continuity-system`，不要继续随机扩量。
- **完成标准**：下一轮简报只新增一个可验证变化，并保留上一轮的入选锚点与不变量。

### 7. 执行停止判定并交付

- 满足任一预设停止条件即停止；输出主选、备选、评分表、淘汰日志、未解决风险和停止原因。
- 若连续两轮没有达到预设最小增益，必须结束抽卡，改用更强约束、人工设计或重新定义问题。
- **完成标准**：账本中存在明确的 `STOP / CONTINUE / ESCALATE` 决定及证据，而不是以“再试一轮”结尾。

### Midjourney Personalization / Moodboard 偏好校准

当用户说“练 P / 炼风格 / 训练 Personalization / Moodboard”时，读取 `references/midjourney-preference-calibration.md`。本 Skill 只拥有目标分布、分层筛选、单缺口回灌和停止；当前平台参数、入口与冲突交给 `midjourney-generation-adapter`。

### 训练模式：复刻—比较—归因

1. 选一个参考镜头，只声明一项训练目标，例如光向、构图层次或表演节奏。
2. 用小批次复刻，并把结果与参考同尺度并排；逐项标记可见差异。
3. 把差异归因到具体决策，写出一条下次可复用的规则，再用一个新例子验证。
4. **停止条件**：未形成“差异证据—原因假设—可迁移规则”前，不以生成数量声称审美提升；形成并验证一条规则后即完成本轮训练。

### 最小输出契约

- 探索简报
- 预算与硬上限
- 评分表和理由码
- 候选账本与 contact sheet/时间线
- 主选、备选及淘汰理由
- 下一轮唯一回灌项或升级路由
- `STOP / CONTINUE / ESCALATE` 决定

## B — 边界（Boundary）

### 不要在以下情况使用此 skill

- 还没有作品目标、批准锚点或最低验收尺度：先建立北极星和 Visual Bible，否则评分只能事后合理化。
- 已选定的镜头只是放在一起风格漂移：应使用 `cross-shot-consistency-audit`，不是再生更多候选。
- 关键问题是复杂空间、多人调度、动作保真或物理光照：应升级参考/layout/3D/实拍证据，不用数量替代控制。
- 任务只有唯一、可验证答案，或生成错误会造成高代价事实风险：优先确定性流程。

### 课程警告的失败模式

- **把数量当审美捷径**：这是不可绕过的硬边界。没有评分表、对照标准、淘汰理由和复盘，生成再多也不能证明审美提高。
- 候选超过人的有效比较能力，导致选择疲劳、差异钝化和“这个也好、那个也好”。
- 一轮同时改变角色、构图、光线和材质，最终无法知道哪个变化有效。
- 只收藏入选项、不记录失败原因，下一轮重复制造同一种错误。

### 讲者盲点与时代局限

- “9×9”“最多十个”和效率倍数来自个人工作流与当时工具，不是普适科学阈值；应按决策复杂度、预算和比较能力重设。
- 四百多张图炼出两个方向只能证明发生过筛选，不能证明大样本优于小样本，也不能证明审美被训练。
- 不同平台的随机性、价格和批量能力会变化；Skill 保留决策系统，不绑定生成器。
- 参考复刻需要记录来源、授权和转化边界，不能把模仿名义当成方法。

### 容易混淆的邻近方法论

- “发散”不是无限扩量；“收敛”也不是只挑最漂亮的一张。
- 评分表不是把审美伪装成精确科学，而是让团队看到偏好、权重与分歧，最终仍由具名的人承担裁决。
- 若候选始终违反同一不变量，问题通常在输入约束或资产，而非样本不够。
