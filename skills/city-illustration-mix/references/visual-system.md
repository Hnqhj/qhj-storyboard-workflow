# 视觉配方

公开版使用项目生成的效果示例作为视觉辅助；它们呈现不同场景中的插画语言，不是每张新图都要照搬的模板。照片与平面图形应有遮挡和互动，不把整幅照片变成插画。示例中的文字、人物、品牌与活动不自动继承。

## 示例选择

- 街道与商业场景：优先查看 [水果小店](images/fruit-shop.png) 或 [街头伙伴](images/street-companions.png)。
- 自然与休闲场景：优先查看 [湖畔奇想](images/lakeside.png) 或 [夏日花园](images/summer-garden.png)。
- 室内、交通与狭长空间：优先查看 [花园列车](images/garden-train.png) 或 [秋日阶梯](images/autumn-stairs.png)。
- 巨人入城分支没有专门随附示例，优先使用用户提供的相应参考；没有参考时按以下文字配方设计。

每次只选择最适合的一张作为画法辅助。照片题材不同，角色类型、布局、动作和道具应相应变化。

## 巨人入城

适合有完整地面与高楼的竖版街景。此分支以文字配方为基础，不将其他分支的植物示例强行当作巨人参考。

- 原照片全出血、真实光线与透视清晰，角色是画面唯一大焦点，可高至邻近建筑的一半以上。
- 角色长肢、宽松街头服装、鞋手夸张、五官简化、线条干净。纯色或简单几何纹样服装，黑色轮廓约为角色高度的 0.15–0.3%，按最终显示大小调整。
- 可用珊瑚橙、奶油、青绿、淡粉、蓝等 4–6 色；每次变换角色造型、配色组合和道具，不固定成蓝皮肤咖啡人物。
- 脚接道路、前后脚有透视关系，克制的地面投影确定位置。角色自身仍是平面色块，不随照片光线渲染成圆润 3D。
- 通常没有额外标题与围绕角色的满屏涂鸦。道路、楼顶和部分天空保持完整可读。

## 角色游街

可查看 [水果小店](images/fruit-shop.png) 或 [街头伙伴](images/street-companions.png)，学习角色与照片的大小对比、二维描边和前后关系。

- 4–6 个有足够视觉分量、不同外形但同画法的角色，可由圆、花瓣、水滴、食物、云或生活物品拟人化而来，选择与场景有关系的组合。
- 街角版：角色分别趴屋顶、坐墙沿、握路灯、站路口。每个有独立动作和明确的前后关系。不要都排在最前面。
- 队列版：道路与斑马线给出行进方向，角色沿前景分组走动；天空、两侧立面和树旁安排中型藤蔓、动物或生活物件呼应，保留街道中轴纵深；不要只有底部队列。
- 参考图可能包含的白边、巨大标题、商标与文案不是默认输出的一部分。只有用户要求海报才配置。
- 画法可用黑色描边，也可采用简洁无描边色块；一次作品选一套，不随机混搭。

## 城市奇想

植物构图可参考 [湖畔奇想](images/lakeside.png)、[夏日花园](images/summer-garden.png) 或 [花园列车](images/garden-train.png) 中最适合当前场景的一张；地标组合按实际照片与下述文字配方设计。

- 植物版：用 1 朵主花/1 组主叶做重心，多簇不同尺度的花、叶、昆虫、飘带连接前中后景，形成密集与舒展交替的节奏。主茎可以从建筑后伸出，再到栏杆前；路面上少量根部或小植物给出落点。
- 地标版：保留主塔、屋顶层次与立面，1–2 个大角色从楼后探身、坐在可见檐口或明确的二维云上；人物应是大色块而非底部小人。中型彩虹、花、云沿建筑轮廓组织，小型鸟、泡泡、星芒补足细节。避免把角色压在地标中心把建筑遮没。
- 扁平黑线、纯色花瓣、少量线性纹理与简单表情，有轻松的超现实感。可有轻微印刷颗粒，但原照片仍保留摄影细节。
- 密度呈簇状变化：主簇、中型陪衬、小点缀；不是每个空隙塞一朵同样大小的花。局部天空和建筑应有可读间隙，但不把整片天空闲置。
- 不复制示例中的建筑、车厢或人物；所有互动依据当前输入照片重新安排。

## 场景适配与留白

- 建筑铺满画面：用一两个探头/攀爬关系，不加大群人。
- 大天空：用角色、云、彩虹构成有分量的大形状和连接路径，在元素簇之间留出蓝天；丰富模式不默认保留一整块空天。
- 狭窄街道：沿道路消失点前大后小，优先不盖住远端地标。
- 近景立面：对齐真实窗沿与屋檐，避免把实际窗口位置改掉来适应角色。
- 夜景或低饱和环境：插画可跳色，背景不必跟着过饱和。白天参考仅提供形状与线条语言。

设计范围与素材权利分开：风格资料不等于原角色、品牌或照片的授权声明；新角色默认原创。保留用户输入中的实际标识作为场景细节，不人为制造新商标或背书。

## 丰富度配方

丰富构图应具有明确的大中小层次与跨区域动势。丰富来自主体尺度、元素种类、情节、遮挡和密度变化共同作用。不能仅增加同样大小的花或星星。

- 大形状先成立：人物动作、主花、彩虹至少有一项在缩略图中清楚抓眼。
- 中型元素承担场景故事，如音乐、阅读、散步、植物生长；同一画面围绕一个主题，不随机堆物。
- 小装饰串联节奏；避免平均散布的星星/圆点填空。
- 至少规划上、中、下三处互相呼应的元素簇；一条曲线可穿过多个簇，让视线绕着地标走。
- 真实层与插画层有前后交错，同时可用有意的幻想悬浮。不得用新建的写实石台解决没有落脚处的问题。
- 用户要求简洁或选择单巨人分支时，保留疏朗路线，不强制密集。
