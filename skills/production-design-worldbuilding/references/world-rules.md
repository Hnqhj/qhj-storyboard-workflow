# World Rules

Use this to make a fictional world visually coherent.

## Three Rule Stack

```text
Social rule: who has power, what is forbidden, what is valued?
Technology rule: what can machines do, what can they not do, what costs energy?
Material rule: what does this world build with, repair with, hide with, display with?
```

Every major visual choice should connect to at least one rule.

## Visual Causality

Instead of:

```text
cool futuristic city
```

Write:

```text
the city is built from white ceramic transit slabs because heat and surveillance sensors require bright reflective surfaces; citizens mark illegal routes with removable coral-red tags.
```

## World Pressure

A location should create pressure:

- surveillance city: open spaces, cameras, clean grids, no hiding
- luxury dystopia: perfect surfaces, expensive emptiness, human traces forbidden
- border zone: gates, scans, layered signs, temporary structures
- memory city: repeating monuments, archival screens, ghosted signage
- rebel district: repairs, patched materials, handwritten codes, inconsistent power

## Rule To Image

```text
Rule: no one owns private shadows.
Image: architecture overexposes every walkway; illegal characters wear matte black light-absorbing fabric.
```

```text
Rule: identity is charged like electricity.
Image: public gates drain blue ID light from bracelets; rebels carry analog metal tags.
```

## Forbidden Drift

Name what this world is not:

```text
not generic neon cyberpunk, not rainy alley, not medieval fantasy, not random sci-fi panels, not nightclub lighting, not cluttered junkyard unless specified
```
