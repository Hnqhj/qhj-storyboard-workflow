# Location, Prop, And Costume

Use this to make objects and places feel designed by the same world.

## Location As Function

Define each location by what it does to the story:

```text
Location:
Story pressure:
Scale:
Movement rules:
Dominant materials:
Color ownership:
Foreground objects:
Forbidden elements:
```

Examples:

- expressway: speed, exposure, no cover
- checkpoint: identity, authority, scanning, delay
- rooftop garden: false peace, surveillance from below
- repair market: rebellion, patched technology, analog texture

## Props

A prop should reveal:

- who made it
- who uses it
- what it costs
- how it is touched
- what status it carries

Prompt:

```text
The prop shows hand-worn edges, manufacturer marks, repair seams, and usage zones; it belongs to the same design language as the character's costume and vehicle.
```

## Vehicles And Weapons

Lock:

- silhouette
- propulsion/energy source
- control surfaces
- material family
- light color
- worn/contact zones
- forbidden transformations

Design relation:

```text
vehicle is an extension of the character, not a random prop
```

## Costume Logic

Costume should answer:

- protection from what?
- movement for what?
- status signal to whom?
- rebellion against which rule?
- material relation to vehicle/weapon?

## Environmental Storytelling

Add small details that imply rules:

- scratched-out QR gates
- illegal route marks
- missing citizen portraits
- charging scars on walls
- repeated inspection seals
- polished floors with forbidden footprints

Keep these details secondary; they should support the main visual action.
