# AI Worldbuilding Packaging

Use this to turn a world bible into image or video prompts.

## Prompt Order

1. World promise
2. Color ownership
3. Shape language
4. Material families
5. Location function
6. Character/prop relation
7. Environmental storytelling
8. Forbidden drift

## Compact Block

```text
World/art direction lock: [world promise]. Environment owns [colors], protagonist owns [colors]. Architecture follows [shape language]. Materials: [families]. Props and vehicles share [design logic]. Environmental storytelling includes [2-3 details]. Avoid [forbidden drift].
```

## Multi-Clip World Lock

```text
Across all clips, keep the same world rules, color ownership, architecture shape language, material families, signage system, and lighting logic. Locations may change, but they must feel built by the same society.
```

## Failure Fixes

If the scene feels generic:

- add a social rule and one visible consequence
- assign colors more strictly
- define shape language
- remove unrelated genre elements

If the scene feels cluttered:

- reduce motifs to 1-2
- define one hero location function
- remove decorative props

If the scene feels pasted together:

- tie costume/vehicle/architecture through material and shape repetition
- name forbidden elements
