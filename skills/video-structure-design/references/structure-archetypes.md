# Structure Archetypes

Use this when choosing the shape of the video.

## Character Entrance

```text
world without them -> anomaly/trace -> partial reveal -> ability/style reveal -> face/identity -> exit or challenge
```

Good for: heroes, villains, fashion characters, game characters, anime covers, AI character videos.

## Action Traversal

```text
route/world scale -> launch -> speed proof -> obstacle -> tactical shift -> near miss/peak -> release
```

Good for: riding, running, flying, chase, parkour, battle movement.

## Transformation

```text
ordinary form -> trigger -> mechanical/organic process -> instability -> completed form -> proof of new function
```

Good for: mecha, outfits, weapons, products, makeup, environments.

## Product Reveal

```text
desire/problem -> glimpse -> material/detail proof -> use in context -> result -> brand/CTA
```

Good for: commercial, fashion, tech, vehicle, fragrance, cosmetics.

## Tutorial / Explainer

```text
pain/result hook -> promise -> steps/chunks -> example -> result -> action
```

Good for: educational short video, creator content, product demo.

## Trailer / Teaser

```text
cold open -> world/premise -> character stakes -> montage escalation -> turn line/image -> title/button
```

Good for: film teaser, series teaser, game trailer, character trailer.

## Music Video / Mood Piece

```text
sonic/visual motif -> world texture -> variation -> contrast break -> motif returns stronger -> final icon
```

Good for: style reels, fashion films, atmospheric AI videos.

## Social Proof / UGC Ad

```text
relatable problem -> personal claim -> demo/proof -> objection handling -> result -> CTA
```

Good for: creator ads, product review style, TikTok/Reels.

## Series Episode Hook

```text
recap/instant conflict -> new problem -> failed strategy -> reveal -> cliffhanger / next action
```

Good for: serialized shorts, character worlds, daily episodes.

## Loop Video

```text
first-frame curiosity -> motion/process -> surprise -> final frame matches first frame with new meaning
```

Good for: short social loops, mesmerizing AI videos, visual experiments.
