# Duration Maps

Use this for timing structures.

These maps are editorial planning estimates. Promote them into exact macro-segment prompt ranges when references, previous outputs, animatics, edit maps, or action-phase analysis make the allocation high-confidence. Otherwise use approximate proportions or order only. Never treat macro-segment ranges as mandatory durations for every internal cut.

## 5 Seconds

Best for one transformation, one reveal, one punch, one product proof, one character entrance beat.

```text
0-1s: instant hook / impossible image
1-3s: action or transformation begins
3-4.5s: turn or reveal
4.5-5s: final image / loop point
```

## 8 Seconds

Best for a single idea with one small turn.

```text
0-1.5s: hook
1.5-3s: context
3-6s: escalation or process
6-7.5s: payoff
7.5-8s: button or loop
```

## 15 Seconds

Best for character reveal, short action, micro-story, product use, teaser.

```text
0-2s: first-frame promise and visual hook
2-4s: orientation / what is happening
4-7s: first action or proof
7-10s: obstacle, complication, or scale shift
10-13s: turn, climax, reveal, or strongest image
13-15s: payoff, exit, loop, CTA, or cliffhanger
```

Use 5-7 segments. Fewer can feel empty; too many can become unreadable.

## 30 Seconds

Best for ads, character trailers, teaser scenes, short story beats.

```text
0-3s: hook
3-6s: premise and context
6-12s: development / proof / pursuit
12-18s: complication or contrast
18-24s: turn and peak
24-28s: payoff
28-30s: CTA, end card, loop, or final image
```

## 60 Seconds

Best for short story, tutorial, product demo, brand film, miniature documentary.

```text
0-5s: hook and promise
5-12s: setup and stakes
12-25s: development or evidence
25-35s: escalation / midpoint shift
35-48s: decisive turn / climax
48-55s: consequence or proof
55-60s: final thought, CTA, loop, or next episode hook
```

## 90 Seconds

Best for trailer, explainer, campaign film, micro-documentary.

```text
0-7s: cold open / promise
7-15s: premise
15-30s: character/problem/world
30-50s: rising examples or complications
50-65s: turn / revelation / proof
65-80s: peak sequence
80-90s: payoff, title, CTA, or cliffhanger
```

## Rule Of Duration Fit

If the idea has only one change, make it 5-8 seconds. If it has one desire, one obstacle, and one turn, make it 15 seconds. If it needs context, proof, and emotional persuasion, make it 30-60 seconds.

## Hard Versus Soft Timing

Use:

```text
hard: total delivery duration
soft: opening / early build / middle turn / late peak / ending
physical: action phases sized to mass and complexity
optional: exact duration of each camera shot
```

Do not paste an internal duration map into a generation prompt without checking whether each interval contains enough action and whether the total, peak, and recovery remain compatible.
