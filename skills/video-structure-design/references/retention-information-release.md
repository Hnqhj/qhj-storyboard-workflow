# Retention And Information Release

Use this when a video feels flat, slow, repetitive, confusing, or empty.

## Retention Is Renewed Attention

The viewer should receive a reason to continue every few seconds:

- new visual information
- new question
- new obstacle
- new scale
- new emotion
- new proof
- new rhythm
- new contradiction

## First Frame

The first frame must work even without context. It should show one of:

- a person in a strong situation
- an impossible or unusual image
- a visible problem
- a before/after contrast
- a question embedded in the image
- a striking motion already underway
- a result before the explanation

Avoid:

- logos first
- slow empty establishing shot for short-form
- vague mood before promise
- text-only hook when the video is supposed to be visual

## Open Loop And Payoff

Open loop:

```text
pose a question the viewer wants answered
```

Payoff:

```text
answer the exact question or replace it with a stronger question
```

Bad: open with one promise, end with an unrelated cool shot.

## Information Ladder

Release information in steps:

```text
what is it? -> where is it? -> why does it matter? -> what blocks it? -> what changes? -> what remains?
```

For action:

```text
where is the route? -> how fast? -> what obstacle? -> how does the subject adapt? -> what is the cost/result?
```

For product:

```text
what problem/desire? -> what product? -> how is it used? -> what proof? -> why now?
```

## Retention Resets

Use resets without turning the video into random noise:

- scale reset: macro to wide, wide to close
- rhythm reset: silence, freeze, speed ramp, cut density change
- perspective reset: POV, overhead, reaction, insert
- stakes reset: obstacle appears, countdown, rule changes
- emotional reset: confidence to fear, confusion to control
- visual reset: color contrast, new texture, new environment layer

## Flatness Diagnosis

If a structure feels flat, ask:

- Is the first frame promising anything specific?
- Is the middle just repeating the opening?
- Is there a turn?
- Does each beat add pressure or knowledge?
- Is the ending a consequence or just a pose?
- Could the whole video be one still image? If yes, add change.
