# Commercial And Social Structures

Use this for ads, brand videos, creator-style videos, product videos, TikTok/Douyin/Reels/Shorts, and CTA-driven content.

## Platform-Agnostic Social Spine

```text
hook -> context -> value/proof -> turn/objection -> payoff -> CTA/loop
```

## Hook Types

- visual contradiction: something looks wrong or impossible
- result-first: show the outcome before explaining
- problem-first: name/show a pain point
- identity hook: "if you are this person, this is for you"
- danger hook: something is about to go wrong
- transformation hook: before state implies after state
- status hook: authority, taste, luxury, social proof
- challenge hook: a rule, dare, countdown, or constraint

## Commercial Structures

Problem-solution:

```text
problem -> failed old way -> product enters -> proof -> result -> CTA
```

Desire-proof:

```text
aspirational image -> product detail -> use context -> social/emotional proof -> CTA
```

Demo-first:

```text
result/demo in first frame -> how it works -> proof detail -> objection handling -> CTA
```

Before-after:

```text
before state -> friction -> intervention -> transformation -> after state
```

ABCD ad check:

```text
Attention: first seconds stop the viewer.
Branding: brand/product is present early enough to matter.
Connection: human, emotional, contextual, or desire-based relevance.
Direction: clear next action, memory cue, or end behavior.
```

## Creator/UGC Structure

```text
personal hook -> lived problem -> quick proof/demo -> honest friction/objection -> result -> soft CTA
```

Make it feel native:

- immediate human presence or POV
- imperfect but readable action
- direct claim
- quick proof
- low-friction ending

## CTA Rules

Use CTA only when the video has a commercial/social objective. It can be:

- explicit: buy, follow, comment, search, download
- implied: title card, logo, product memory, next episode hook
- loop-based: final frame makes the viewer rewatch

Do not add CTA to pure mood, cinematic concept, or story scenes unless requested.
