# Core Structure Principles

Use this for any video structure task.

## Video Structure Is A Promise Machine

A strong video makes a promise early, delays or complicates the answer, then pays it off.

Core loop:

```text
promise -> orientation -> escalation -> turn -> payoff -> aftertaste/loop
```

The promise can be:

- a visual question: "What is that?"
- a danger question: "Will they survive or escape?"
- a transformation question: "What will this become?"
- a status question: "Who has power here?"
- a value question: "What will I learn/get?"
- an emotional question: "Why does this feel wrong/beautiful/sad?"

## Segment Functions

- Hook: stops the viewer and defines the promise.
- Orientation: gives enough context to understand the next move.
- Build: increases information, pressure, proof, rhythm, or scale.
- Turn: changes the meaning, direction, method, power, or expectation.
- Payoff: answers the promise with a satisfying image, reveal, proof, or choice.
- Button: final line, visual snap, sound hit, CTA, loop, or cliffhanger.

## Structural Energy Curve

Not every second should be peak intensity. Use contrast:

```text
hook spike -> short clarity -> rising pressure -> rhythm reset -> peak -> release
```

For pure mood videos:

```text
sensory hook -> world expansion -> intimate detail -> tonal shift -> final mood image
```

For action videos:

```text
threat/path -> launch -> obstacle -> tactical change -> impact -> exit
```

For product/brand:

```text
problem/desire -> product in context -> proof/use -> emotional or practical payoff -> direction
```

## Structural Turn

A turn is the moment the video stops being more of the same.

Turns can be:

- scale turn: tiny detail becomes huge world
- power turn: hunted becomes hunter
- direction turn: escape route changes
- knowledge turn: viewer understands a hidden rule
- material turn: object transforms or reveals function
- emotion turn: confidence cracks or fear becomes control
- rhythm turn: silence, freeze, speed ramp, or hard cut changes tempo

## Ending Types

- Payoff ending: answers the question.
- Loop ending: returns visually or verbally to the first frame.
- Cliffhanger: creates a stronger next question.
- Proof ending: shows the result of the process.
- Button ending: final sharp image, line, sound, gesture, or pose.
- CTA ending: asks the viewer to act, only for commercial/social cases.

## Structure Before Shots

Do not start with "low angle, drone, close-up." Start with:

```text
what must change between the beginning and the end?
what does each segment add?
what makes the viewer continue?
```
