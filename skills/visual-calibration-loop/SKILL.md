# 视觉标定与色彩脚本闭环

## R — 原文（Reading）

> “我在做有一些项目的时候，就会先把整个故事的情绪版做出来……把这些所有的图先排到一个情绪版里面。”
>
> — MokeLMa，视频 01，00:11:13–00:12:49

---

## I — 方法论骨架（Interpretation）

视觉标定不是收集一组“好看的参考图”，而是把叙事情绪随时间的变化变成可见、可批准、可复位的控制系统。
先把故事拆成情绪节点与转折，再为每个节点定义亮度、色温、色相、饱和度、反差、光向、材质和空气感等可观察变量。
每个关键节点至少批准一张标定帧，并记录它为何成立、哪些特征必须保留、哪些特征可以探索。
生产中把镜头按叙事顺序并排审看，不只评价单张质量；漂移镜头回到最近的获批锚点校正。
形成“叙事曲线 → 标定帧 → 批量生产 → 序列审看 → 漂移复位 → 更新锚点”的闭环。
后期调色只负责精修和媒介适配，不替代上游的视觉方向决策。

## A1 — 课程中的应用（Past Application）

### 案例 1：把故事变化排成色彩情绪版
- **问题**：单张画面可以各自成立，但不能证明全片情绪会推进。
- **方法论的使用**：讲者先规划从明亮、深入环境、粉色光到夜晚的变化，用同一套文字 Bible 生成画面，再按故事顺序排列。
- **结论**：情绪方向必须在时间轴上比较，而不能只看孤立图片。
- **结果**：得到一组相互关联的方向样本；课程没有展示完整成片，因此只能把它视为有效的前期标定案例。

### 案例 2：用获批关键图修复漂移镜头
- **问题**：短片中的生成镜头出现色彩与光照偏移。
- **方法论的使用**：讲者把已经确认的关键图作为锚点，将其视觉特征迁移到漂移画面，再做局部清理与精修。
- **结论**：先指定“以谁为准”，再识别和修复偏移维度，比继续随机重抽更可控。
- **结果**：该方法被用于实际短片；课程只展示局部结果，没有全片对照或观众测试。

### 案例 3：《石托岭》的前置视觉标定
- **问题**：项目需要在正式制作前建立一致方向。
- **方法论的使用**：讲者收集插画、书与分镜等材料，提取视觉属性并建立影片基线。
- **结论**：参考的价值在于转译成可描述、可验收的属性，不在于只写作者或作品名。
- **结果**：形成视觉与音乐方向基线；课程没有完整说明授权和最终评价。

## A2 — 触发场景（Future Trigger）

### 用户会在什么情境下需要这个 skill？

1. 已有剧本、分场或镜头表，但缺少随叙事推进的色彩与光线计划。
2. 团队准备批量生成，希望在开工前批准少量关键帧作为共同验收基准。
3. 镜头单看都漂亮，按顺序排列后却出现情绪跳跃、色光漂移或像不同作品。
4. 需要把 moodboard 升级成可执行的 color script、标定帧计划和返修规则。
5. 品牌跨海报、视频和直播包装时，需要定义一条有变化但不丢身份的视觉曲线。

### 语言信号

- “先把全片的视觉和情绪走势定下来。”
- “每张都好看，但放在一起情绪不往前走。”
- “做一份色彩脚本 / color script / color keys。”
- “后面镜头的光和颜色跑掉了，怎么拉回统一？”
- “Build a visual calibration loop and fix look drift across the sequence.”

### 与相邻 Skill 的区分

- `creative-north-star` 确定叙事意图与不可让渡项；本 Skill 把它们翻译成时间轴上的情绪与色光变化。
- `minimum-visual-bible` 定义全项目视觉契约；本 Skill 与它组合，专门建立标定帧和漂移复位闭环。
- `bounded-explore-select` 负责候选的预算、评分和收敛；本 Skill 只提供情绪、色彩与光照基准。
- `cross-shot-consistency-audit` 诊断已有素材的综合漂移；本 Skill 优先在生产前建立锚点并在生产中复位。

## E — 可执行步骤（Execution）

激活后，按以下步骤执行：

1. **拆分叙事情绪节点**
   - 列出段落、时间范围、主导情绪、转折原因、前后承接和不可改变的叙事事实。
   - 完成标准：每个视觉变化都能指向一个叙事原因；删去只为“更好看”却不服务内容的变化。

2. **把情绪翻译成可观察变量**
   - 为每个节点定义亮度区间、色温/主色关系、饱和度、反差、主光方向、光比、材质响应、空气层和允许的局部变化。
   - 完成标准：团队能从画面判断“通过/不通过”，而不是只收到“高级、电影感、压抑”等抽象词。
   - 判停条件：若核心问题是角色身份、道具状态或空间关系，先转给 `entity-continuity-system` 或 `constraint-input-router`。

3. **制作并批准标定帧**
   - 为开场、主要转折、高潮和收束分别制作或选择关键帧；记录来源、授权、获批版本、必须保留项、允许探索项和审批人。
   - 完成标准：每个主要情绪节点至少有一个具名获批锚点，并能说明它为何服务该段叙事。
   - 判停条件：没有具名审批人或无法解释锚点与叙事的关系时，不进入批量生产。

4. **形成色彩脚本与校正规则**
   - 按时间轴排列标定帧，标注渐变、突变、回归和局部例外；为每段写出最近锚点、容许偏差与复位方法。
   - 完成标准：色彩脚本能回答“本镜头以哪个锚点为准、哪些维度可变、偏移后如何修复”。

5. **执行序列审看与漂移复位**
   - 把生成镜头按剪辑顺序做接触表或时间线；逐项比较身份之外的色彩、光向、反差、材质和空气感。
   - 将结果标为“通过、局部校正、返回生成、返回上游标定”，只修改失败维度。
   - 完成标准：相邻镜头的变化要么落在容许范围内，要么有明确叙事理由；所有返修都能追溯到锚点和判定项。

6. **沉淀可复用输出**
   - 输出情绪节点表、色彩脚本、标定帧册、漂移检查表、返修记录和当前获批版本。
   - 完成标准：新成员无需口头补充即可用这些材料判断一个镜头是否符合方向。

## B — 边界（Boundary）

### 不要在以下情况单独使用此 skill

- 只有一张一次性图片，且没有系列、品牌或叙事连续性要求；直接按单图目标执行更经济。
- 项目尚未确定受众、叙事意图和不可让渡项；先使用 `creative-north-star`。
- 问题主要是角色身份、服装、道具状态或空间错误；视觉标定不能替代实体连续性和布局控制。
- 已有大量成片只需要系统定位故障；优先使用 `cross-shot-consistency-audit`，再按审计结果回到本闭环。

### 课程中的失败模式

- **把视觉定调拖到后期抢救**：统一 LUT 或滤镜能修局部偏差，不能低成本修复上游方向冲突、光照逻辑冲突和身份漂移。
- **单镜头漂亮、全片漂移**：缺少时间轴并排审看时，人眼会逐渐适应偏移，局部惊艳反而破坏整体。

### 讲者的盲点 / 时代局限

- 课程以个人视觉工作流为主；团队项目还需要版本控制、素材来源、审批责任和审计记录。
- 参考图、电影与艺术家作品必须记录来源和授权；只提取可描述属性，不把作者名字当作风格许可。
- 课程偏摄影与 VFX，不能让色彩标定遮蔽剧作、表演、声音和剪辑叙事。
- 关键帧是人类批准的工作假设，不是客观真理；没有目标受众或实际测试时，不宣称它必然有效。

### 容易混淆的方法

- moodboard 负责探索方向；color script 负责组织时间变化；标定帧负责批准；一致性审计负责发现偏移。四者不能互相替代。
- 后期匹配是复位手段，不是延迟做前期决策的理由。
