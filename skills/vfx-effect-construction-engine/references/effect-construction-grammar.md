## 1. Causal Envelope

Use this as the default internal model:

```text
job -> owner/source -> trigger -> formation -> carrier/shape -> path/depth/speed ->
operation/contact -> receiver/world/light response -> peak -> decay/residue -> endpoint
```

The envelope is not a mandatory sentence order. Preserve only the phases visible in the shot, but never omit the causal link between source, operation, and result.

### State continuity wording

Use progressive states to improve continuity when useful:

```text
即将形成：pressure, precursor, attraction, crack, dim pulse
开始形成：first geometry or carrier appears at the source
正在推进：path, depth, velocity, and occlusion remain readable
发生作用：contact, binding, cutting, injection, purification, displacement
达到峰值：one selected maximum state
正在衰减：density, brightness, pressure, or motion falls
完成变化：a stable new state or residue remains
```

Do not use progressive words without specifying the visible geometry and state change.

## 2. Lifecycle Selection

Choose by the effect's function, not by spectacle:

| Function | Preferred lifecycle |
|---|---|
| Charge and release | convergence -> ignition -> peak -> radial or directional decay |
| Activate an object | flow -> wrap -> inject -> sequential activation -> stable pulse |
| Ultimate pressure | compression -> near-stillness -> release -> large residue |
| Aura or field | breathe -> pulse -> synchronize -> expand -> sustained boundary |
| Electricity | seed arc -> branching growth -> network -> target convergence -> discharge |
| Fluid transformation | emit/flow -> wrap -> merge -> contract/solidify -> droplets |
| Orbital energy | establish orbits -> vary radius/speed -> interleave -> contract -> core |
| Rift or portal | hairline fracture -> branching -> leakage -> opening -> transfer -> reseal |
| Ribbon/path effect | enter -> curve -> interweave -> accelerate -> converge/diverge -> trail decay |
| Sustained high-energy state | continuous emission -> convection/turbulence -> periodic pulse -> stable tail |

## 3. Ten Reusable Lifecycle Families

### A. Convergence Burst

```text
sparse carriers are drawn from defined regions -> spiral or radial acceleration ->
core ignition -> one directional or radial release -> afterglow and drifting residue
```

Use for charging, ultimates, reactor activation, or condensed magic. Bind the carrier to an attraction field and give the release a receiver or world consequence.

### B. Flow Injection

```text
stream enters from source -> splits into filaments -> wraps target ->
crosses a boundary or seam -> sequentially activates surfaces -> stable pulse
```

Use for enchantment, healing, corruption, data transfer, weapon awakening, or armor activation.

### C. Compression Silence Burst

```text
surrounding matter/light contracts -> pressure and darkness increase ->
brief near-stillness -> concentrated release -> delayed environment failure
```

The quiet beat exists to contrast the release. Keep it very short and reserve it for a hero event.

### D. Breathing Field

```text
core expands/contracts -> each pulse sends a bounded wave ->
nearby carriers synchronize -> amplitude or radius grows -> stable field boundary
```

Use for aura, barriers, domains, living energy, or sustained ritual spaces.

### E. Branching Discharge

```text
seed current appears at a conductive source -> branches seek paths ->
new areas illuminate at contact -> branches converge on target -> discharge -> residual arcs
```

Branching may look irregular, but conductivity, target attraction, and occlusion remain causal.

### F. Liquid-State Conversion

```text
fluid carrier emits -> stretches, merges, and breaks -> coats or penetrates target ->
contracts or crystallizes -> stable shell/state -> a few droplets or wet residue remain
```

Use for liquid energy, blood magic, metallic growth, slime, ink, or water-based transformation.

### G. Orbital Build

```text
orbit anchors appear -> carriers occupy different radii/heights ->
angular velocity changes -> paths interleave without collision -> orbits collapse into core
```

Use when ordered geometry, celestial systems, or technical precision is the primary read.

### H. Rift Release

```text
surface tension or seam becomes visible -> fracture propagates -> light/matter leaks ->
opening reaches usable geometry -> transfer/release occurs -> edges cool and reseal
```

Specify which plane is torn, what exists behind it, and whether material is displaced, reflected, or erased.

### I. Ribbon Transport

```text
ribbon emits from owner -> follows a controlled curve -> wraps or intersects layers ->
accelerates/converges -> performs transfer or impact -> separates and fades along the same path
```

Use for wind, sword aura, spiritual threads, memory lines, or graphic 2D motion. Preserve anchor points and tension.

### J. Sustained Burn or High-Energy State

```text
continuous source emission -> turbulent carrier motion -> heat/refraction/smoke response ->
periodic local peaks -> stable but changing state -> cooldown or cutoff
```

Sustained does not mean static. Different layers move at different speeds and densities.

## 4. Event Syntax by Effect Type

### Particle system

```text
emitter -> emission mode -> distribution/depth -> bulk motion -> speed curve ->
interaction/collision -> lifetime -> disappearance/residue
```

### Projectile or beam

```text
source alignment -> charge or immediate release -> path and width ->
occlusion/travel wake -> target contact -> penetration/deflection/absorption -> endpoint
```

### Slash or weapon trail

```text
body/weapon path -> moving edge source -> fleeting trail or smear -> exact contact ->
receiver cut/displacement -> delayed environmental line -> trail cutoff
```

### Shockwave

```text
pressure source -> wave geometry -> travel through a medium -> arrival times by distance ->
receiver/world response -> attenuation and reflected tail
```

### Ritual formation or seal

```text
activation protocol -> local anchor points -> geometry draws in causal order ->
boundary closes -> operation begins -> target resists or changes -> marks cool/remain
```

### Summoning

```text
contract/source -> portal or assembly boundary -> partial evidence ->
mass enters/assembles with occlusion -> contact with world -> portal/marks settle
```

### Transformation

```text
trigger -> active frontier -> local material change -> partial silhouette proof ->
completed form -> lock, weight, cloth, light, and residue settle
```

### Destruction

```text
contact/constraint failure -> fracture grows through actual material ->
large pieces move first -> smaller debris/dust follow -> collisions/settling -> persistent damage
```

## 5. Duration and Density Budgets

### Still image

- Freeze one phase with source, path or contact evidence, and a readable residue/state.
- Avoid describing an entire beginning-to-end animation.

### 4–8 seconds

- One lifecycle, one primary read, one peak.
- Use 3–5 visible phases.

### 10–15 seconds

- One dominant lifecycle.
- One hero peak plus at most two supporting beats.
- Keep a single causal axis even when the camera cuts.
- Reserve enough time for a changed ending state.

### 16–30 seconds

- At most two linked lifecycles.
- The second must inherit the first effect's owner, residue, or transformed state.
- Do not reset to an unrelated effect family between halves.

## 6. Repair Patterns

| Failure | Mechanism repair |
|---|---|
| Effect appears everywhere | assign one owner, exact emitter, and bounded propagation |
| Pretty but meaningless | define operation and changed receiver/world state |
| Random particles | define emitter, field, speed curve, collision, lifetime |
| Magic circle is a glowing sticker | define plane, drawing order, thickness, occlusion, operation, cooling marks |
| Impact is only a flash | show contact first, then receiver displacement and delayed material response |
| Energy beam has no weight | add source alignment, wake, occlusion, target resistance, spill light, endpoint |
| Transformation is a dissolve | add active frontier, partial changed state, material-specific assembly, lock/settle |
| Effect never ends | reduce density/brightness, stop emitter, show cooling/settling/residue |
| Weapon changes design | limit deformation to a brief smear and restore stable identity before/after |
| VFX hides geography | reduce tertiary layers, move carriers to depth/edges, preserve silhouettes and contact |
