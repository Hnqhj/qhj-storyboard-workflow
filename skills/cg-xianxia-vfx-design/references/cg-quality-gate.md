# CG仙侠特效质量门

## 通过条件

- 主形态在灰度和轮廓上可读，不依赖颜色。
- 发光影响邻近材质、阴影、反射和雾气。
- 粒子有发射源、速度曲线、遮挡、寿命和消散。
- 受体与环境产生方向一致的反馈。
- 镜头存在前中后景与尺度参照。
- 峰值后亮度、密度和运动都回落，末帧稳定。

## 廉价感来源

- 一层发光贴图覆盖画面；
- 单色Bloom过强、黑位和皮肤细节消失；
- 粒子均匀、同速、同尺寸；
- 特效不照亮人物或环境；
- 法阵贴在镜头平面，缺少透视与遮挡；
- 碎片材质错误、先于接触出现；
- 拖尾脱离兵器或人物运动；
- 每个动作都用同等规模爆炸；
- 缺少衰减，最终停留成发光噪点。
