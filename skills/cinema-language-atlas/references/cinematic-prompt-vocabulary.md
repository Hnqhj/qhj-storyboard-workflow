# 影视提示词词库：控制卡编译与媒介门控

## 用途

把影视术语从“可复制标签”改造成可执行、可检查的视听控制。适用于：

- 为一个镜头选择景别、机位、构图、灯光、运镜、剪辑或类型语言；
- 解释某个术语为什么适合当前叙事任务；
- 把电影参考、导演/影片名或胶片名称翻译成可观察机制；
- 检查一条提示词是否把静帧、时序与跨镜头要求混在一起。

不要把本词库当作：

- 当前平台参数手册；
- 摄影、镜头或胶片物理模拟器；
- 完整分镜、覆盖设计或项目级视觉 Bible；
- “加上术语/品牌名就会自动实现”的咒语库。

## 核心编译链

```text
叙事/观看任务
→ 选择一个主术语
→ 写清观众效果
→ 翻译成可观察机制
→ 通过媒介门控
→ 补时空前提与允许变量
→ 检查冲突
→ 写成平台中性的执行描述
→ 交给当前工具适配器
→ 用输出证据复核
```

### 术语控制卡

每个被采用的术语至少填完：

```text
术语：
本镜头的唯一工作：
观众应看到/知道/感觉到：
可观察机制：
媒介层级：单帧 / 时序 / 多镜头或项目级
空间前提：
时间前提：
允许变化：
禁止冲突：
模型中性表达：
验收证据：
```

完成标准：删掉术语、品牌和人名后，执行描述仍能说明画面或时间中发生什么，审稿者仍能判断是否实现。

## 三层媒介门控

### 1. 单帧可表达

可由一张画面直接验证：

- 景别、机位高度、视线方向、主体距离；
- 三分、对称、负空间、引导线、框中框、前景遮挡；
- 光源方向、软硬、明暗比、色温关系、剪影；
- 浅景深/深焦的可见状态、前中后景关系；
- 颗粒、色偏、反差、高光过渡、阴影密度等成像意图；
- 类型的可见生产设计、光色、材质与表演线索。

### 2. 必须有时间

单张图不能证明，必须写起点、变化、终点或剪辑关系：

- 推、拉、摇、移、跟、升降、环绕、甩镜；
- 变焦、焦点转移、慢动作、延时、倒放；
- 跳切、交叉剪辑、反应镜头、插入、溶解、淡入淡出；
- 蒙太奇、长镜头、形变和其他持续变化。

最小表达：

```text
初始构图/状态 → 谁或什么驱动变化 → 相机/焦点/剪辑如何变化 → 结束构图/信息
```

### 3. 必须跨镜头或项目成立

不能压进一条单镜头提示词：

- 母题、象征、伏笔、平行叙事、闪回/闪前、非线性结构；
- 类型契约、重复视觉语法、跨镜头色彩与胶片化一致性；
- 主镜头与覆盖、轴线、反应链、声画节奏。

这类要求应交给项目级视觉规则、分镜/镜头表或剪辑结构；单镜头只接收其中当前要执行的一小段。

## 七类词汇的正确用途

### 摄影机工作

- **景别/覆盖**：特写、极特写、中近景、中景、牛仔景、远景、极远景、建立镜头、主镜头、插入、双人/三人镜头。
- **机位/视点**：航拍、鸟瞰、正俯、虫视、高/低/平视、荷兰角、主观、过肩。
- **运动**：推拉轨道、摇、俯仰、跟拍、稳定器、升降、推近/拉远、甩镜、环绕、快速变焦。
- **持续/焦点/稳定性**：焦点转移、慢动作、手持、固定、长镜头。

选择顺序：镜头功能 → 主体距离与机位 → 空间关系 → 是否需要运动。不要先选设备名。

### 灯光

- **角色**：主光、辅光、背光、轮廓/边缘光、眼神光、环境光、实用光源；
- **质量**：硬/软、集中/扩散、包裹/切割；
- **结构**：三点、高调、低调、明暗对照、伦勃朗、剪影、图案投影、斑驳；
- **方向**：上照、侧光、交叉、宽面/短面、反弹；
- **时间/色彩**：黄金时刻、蓝调时刻、可用光、有动机的光、色温关系。

优先写“光从哪里来、打到什么、留下什么阴影/高光、为什么在场”，而不是只写灯光术语。

### 构图

- **几何**：三分、黄金分割、对称、居中、引导线、对角线、三角、重复；
- **画框与余量**：框中框、头顶空间、引导空间、负空间；
- **纵深与焦点**：前景锚点、浅景深、深焦、层次遮挡；
- **层级**：平衡、视觉重量、图底关系、反差、场面调度。

构图控制必须落到主体位置、目光/运动方向、遮挡和前中后景，不以“高级构图”收尾。

### 剪辑

- **相邻关系**：交叉剪辑、跳切、反应镜头、切出、切入、冲击切；
- **转场**：溶解、淡入淡出、擦除、光圈；
- **时长与时间**：蒙太奇、长镜头、定格、延时、快放、倒放；
- **并置**：分屏。

剪辑词必须指明 A 镜头、B 镜头、切点与信息变化。单张图片不承诺剪辑效果。

### 叙事

- **时间结构**：闪回、闪前、非线性、从事件中段开始、框架叙事；
- **信息释放**：平行叙事、伏笔、悬念结尾；
- **讲述位置**：打破第四墙、画外音；
- **语义组织**：母题、象征。

叙事术语首先属于剧本、镜头序列或剪辑，不应伪装成单帧质感标签。

### 可提示化的视觉效果

- **调色/表面**：去饱和、棕褐、颗粒；
- **镜头/焦外**：散景、畸变、眩光；
- **空间错觉**：强制透视；
- **时间/合成**：形变、溶解。

凡涉及尺度、遮挡、几何、接触或精确合成，纯文字不稳时升级到参考图、布局、深度、白模或可测量约束。

### 类型与风格

把类型/运动拆成生产机制：

```text
叙事契约 + 场面调度 + 光色 + 材质/服化道 + 表演 + 镜头/剪辑 + 声音
```

表现主义、电影真实、法国新浪潮、新现实主义、Dogme、慢电影、黑色电影、寻获影像、意大利西部片、铅黄、武侠、宇宙恐怖等名称只能作为检索或沟通锚点。真正执行时保留所需机制，不复制整套人设。

## 胶片名称的正确降级

胶片名称是来源锚点，不是物理准确保证。先判断其管线角色：

```text
拍摄负片 / 反转片 / 黑白拍摄材料
印片 / 中间片 / 复制材料
静态摄影材料
相纸 / 声轨片 / 即时材料 / 特殊光谱材料
```

只有拍摄材料才可能使用“拍摄于”一类表述；印片、中间片、相纸、声轨片不能统一套用 `shot on ...`。

### 胶片意图卡

```text
名称与来源：
管线角色：
静态/电影用途：
标称感光度与光源平衡（仅作资料）：
颗粒意图：细 / 中 / 粗，以及在什么区域可见
反差意图：低 / 中 / 高
高光意图：过渡、密度、偏色
阴影意图：细节、堵塞、偏色
色彩意图：饱和度、肤色、冷暖偏向
处理链意图：冲洗、印片、扫描、调色、推拉（如适用）
验收比较：与哪个中性基线比，哪些可见差异算成功
来源状态与核验日期：
```

规则：

1. 名称、ISO、焦段、机身或镜头品牌只表示创作意图，不能证明模型按真实物理链路模拟。
2. “仍在产/已停产”是时效字段；使用前查制造商当前目录和产品变更公告，不固化进长期方法。
3. 要求历史还原或精确匹配时，使用经授权的实拍样张、灰卡/色卡、扫描条件、LUT/调色链和 A/B 验收；纯文字不够。
4. 胶片选择应服务于叙事和曝光环境，不能作为每条提示词的装饰尾缀。

## 冲突检查

在合并控制卡前检查：

- 静帧要求是否声称实现运镜、剪辑或叙事时间；
- 同一镜头是否同时要求互斥的机位、景别、光质或景深；
- 运动是否破坏轴线、主体可读性或接触证据；
- 类型名称是否与具体场景机制矛盾；
- 设备、导演、影片或胶片名称是否替代了可观察描述；
- 是否把多个强技巧平均堆满，导致没有主次；
- 是否把当前平台参数写进永久方法层。

原则：每个控制层先保留一个主决策；次要术语只有在不争夺同一控制面时才加入。

## 交接

- 完整镜头、轴线、覆盖、运动和声画设计：交给 `cinematic-audiovisual-language`。
- 正式分镜与镜头表：交给 `professional-storyboard-director`。
- 模块化、工具中性的提示词编排：交给 `modular-text-bible` 或相应提示词导演。
- 当前模型参数和语法：交给对应平台 adapter；不要在本参考中长期保存。
- 文字难以稳定控制空间/物理关系：交给 `constraint-input-router` 升级约束介质。
- 生成结果复核：交给 `ai-video-output-review` 或对应目检流程。
