# Action Scenes

Last researched: 2026-06-28
Status: active reference, research-synthesized, not capsule-promoted

Use this file for action geography, contact proof, setup-impact-recovery, weapon weight, group combat hierarchy, rhythm, danger cues, constructive cutting, full-body readability, and impact sound.

## Research Questions

1. What makes a fight readable when cuts are fast, the camera is close, or the environment is crowded?
2. How can contact, near-miss, recoil, and environmental response prove causality instead of hiding behind shake and blur?
3. How should action rhythm vary between one-on-one fights, group fights, chases, and prop/weapon sequences?
4. What should AI video prompts lock so the model preserves geography, weight, and state change without over-choreographing every limb?

## Working Controls

- Give the audience a spatial roadmap before chaos: establish entrances, exits, levels, obstacles, weapon sources, and crowd zones.
- Treat action as state change: every beat should change distance, angle, balance, initiative, weapon line, elevation, route, or objective access.
- Prove contact or near-miss with at least one readable relation: hit/bind/jam, recoil, stagger, slide, impact mark, prop break, cloth/hair reaction, or sound-image accent.
- Prefer action-and-reaction in the same frame when the beat depends on credibility, comedy timing, or body cost; cut away only when the reaction/result remains unmistakable.
- Build beats as setup -> commitment -> contact/near miss -> receiver response -> recoil/environment response -> braking/recovery -> new state.
- Cut fast only when each shot has quick uptake: clear silhouette, simple screen direction, visible target, and a motivated match or reaction.
- Separate one-on-one and group logic: one-on-one can compress into proximity; group fights need zone management, incoming threat order, and readable crowd hierarchy.
- Give weapons material rules: grip, mass distribution, edge/point line, braking space, regrip/plant/catch, and recovery cost.
- Let camera participate only with a job: preserve geography, enter pressure, reveal danger, follow recoil, isolate tactic, or punctuate impact.
- Treat safety and stunt design as real production constraints. Fictional prompt design can imply danger, but real-world execution requires qualified stunt coordination.

## Action Function Tags

- `spatial_roadmap`: establishes the fighting arena, threat positions, exits, levels, and obstacles.
- `contact_proof`: shows the causal relation between attack, defense, hit, bind, near-miss, or displacement.
- `receiver_response`: shows how the struck, blocked, thrown, or threatened body absorbs, redirects, resists, or suffers the force.
- `environment_response`: lets walls, glass, dust, water, props, furniture, clothing, or sound prove force and direction.
- `pain_recovery`: holds or returns to the body cost after impact: breath, grimace, stagger, recoil, regrip, limp, or tactical reset.
- `state_change`: locks the result of a beat as changed angle, distance, balance, route, weapon line, or initiative.
- `rhythm_oscillation`: alternates intensity, recovery, surprise, humor, pain, or tactical pause.
- `zone_management`: groups threats into readable clusters, lanes, or levels.
- `weapon_logic`: makes the prop's mass, grip, reach, edge/point, ammunition, or reuse constrain the action.
- `camera_combat_role`: camera movement or framing carries a specific action function rather than generic excitement.
- `survival_emotion`: action expresses fear, rage, desperation, exhaustion, protectiveness, or objective pressure.

## Knowledge Entries

### David Bordwell On Lau Kar-leung -> Fast Cutting Can Still Be Spatially Clear

Source / film example -> David Bordwell, "Lau Kar-leung: The dragon still dances," with Dirty Ho, Challenge of the Masters, Executioners from Shaolin, and Golden Swallow examples.

Observation -> Bordwell argues that Hong Kong martial-arts films often use rapid cutting, but Lau keeps combat clear through strong composition, analytical cutting, constructive cutting, reaction inserts, matches on action, and narrowed action zones.

Mechanism -> Readability is not determined by shot length alone. Fast action stays clear when each shot has quick uptake and the cut preserves an intelligible spatial or tactical relation.

Executable action/camera/editing control -> Before fast cuts, define the arena and action zone. In each shot, preserve one readable target, vector, or contact point. Use closer cuts to isolate tactics, hands, weapon binds, reaction cost, or match-on-action continuity.

Applicable scenes -> Martial-arts fights, stair/temple fights, multi-zone combat, tabletop or tightly packed action, AI clips that need dynamic cuts without losing geography.

Misuse boundary -> Do not use "fast Hong Kong cutting" as permission for random fragmentation. Without compositional clarity and action matches, fast cutting becomes noise.

Validation status -> Strong scholarly source; candidate for future validation through scene breakdowns.

### Jackie Chan / Police Story -> Contact Proof Needs Action And Reaction Evidence

Source / film example -> David Bordwell's "Bond vs. Chan: Jackie shows how it's done," Every Frame a Painting's "Jackie Chan - How to Do Action Comedy," and No Film School's summary of the same principles.

Observation -> The sources emphasize clear shot design, action and reaction in the same frame, rhythm, environmental use, pain, and the visible fate of bodies after impact. Bordwell's Police Story analysis stresses readable composition, glass/environment consequences, slight pauses, repeated action beats, and reaction cost.

Mechanism -> A hit feels real when the viewer can connect force path to receiver response and changed state. The contact point alone is not enough; the result must register on the body, object, environment, sound, rhythm, or next tactical condition.

Executable action/camera/editing control -> For each beat, require at least three proof nodes: initiating motion -> contact/near-miss relation -> receiver/environment response. When possible, keep attacker and receiver in the same frame for the contact beat; after the impact, hold or return long enough to show recoil, pain, regrip, breath, fall, prop damage, or renewed threat.

Applicable scenes -> Martial-arts comedy, hard-hitting brawls, weapon binds, falls, thrown bodies, slapstick, AI video fights where motion often looks like floating or whiffing.

Misuse boundary -> Do not copy Jackie Chan's specific stunts, danger level, comic tone, or glass imagery. "Same frame" is a credibility tool, not a universal rule; extreme danger, subjectivity, or censorship may require offscreen impact, but the consequence still needs proof.

Validation status -> Strong scholarly + high-quality video-essay support; reference update, not capsule-promoted.

### Gareth Evans / The Raid -> Sell Impact Through Pullback, Materials, And Shot-Specific Design

Source / film example -> Gareth Evans interview with Vulture on The Raid and The Raid 2 action scenes.

Observation -> Evans describes planning action shot by shot, testing materials such as safe wall/prop substitutes, adding sound to sell effects, using wire work to control falls, and performers snapping back impact rather than following through dangerously.

Mechanism -> Contact proof is partly a safety illusion. The performer does not need real full-force contact; the camera needs a readable force path, a timed pullback, a reactive body, and a material/sound cue that completes the effect.

Executable action/camera/editing control -> In a prompt or breakdown, separate "visible force" from "real contact": name the attack vector, the pulled or snapped-back contact, the receiver's displacement, and the prop/environment response. Add a sound-image accent only after the visual relation is readable.

Applicable scenes -> Hard action, falls, head/body impacts, weapon clashes, glass/wall/table/furniture hits, AI video where force often lacks weight.

Misuse boundary -> Do not translate this into real stunt instructions. For real shoots, route to qualified stunt coordination and safety planning. For fictional/AI work, use the principle only as visual causality vocabulary.

Validation status -> Strong practitioner source; reference update, not capsule-promoted.

### Gareth Evans On The Raid / Havoc -> Spatial Roadmap Before Frenzy

Source / film example -> Gareth Evans interviews on The Raid and Havoc action scenes.

Observation -> Evans describes fight design as camera movement plus action movement, distinguishes mass brawls from one-on-one fights, and stresses giving viewers a subconscious roadmap of the geography before frenetic action. For Havoc, he describes designing action shot by shot and edit by edit rather than collecting generic wide coverage.

Mechanism -> Action geography can survive intensity if the audience has already mapped the space and every later shot is a specific puzzle piece.

Executable action/camera/editing control -> Start a large set piece with a route-establishing move or clear spatial pass: levels, exits, crowd clusters, obstacles, weapons, and objective. Then design each shot as a necessary "jigsaw piece": who is threatened, what changes, and why this angle is required.

Applicable scenes -> Group fights, club/stairwell/warehouse/corridor fights, chases through multi-level spaces, AI video action sequences with many threats.

Misuse boundary -> A wide master is not automatically a roadmap. It must teach useful geography. Conversely, close/kinetic shots can work after geography is embedded.

Validation status -> Strong practitioner source; not capsule-promoted.

### Don Lee Interview -> Action Is Emotional Storytelling, Not Move Inventory

Source / film example -> Script Magazine interview with stunt choreographer/action director Don Lee, including Cobra Kai and Casino Royale discussion.

Observation -> Lee describes reading for story first, asking about tonal references, treating action like emotional architecture, and valuing physical storytelling such as Bond's relentless old-school chase style versus parkour fluidity.

Mechanism -> Choreography should express character psychology and story pressure. The same kick, fall, chase, or weapon beat changes meaning depending on what the character is trying to survive, hide, protect, or prove.

Executable action/camera/editing control -> Before naming moves, write: action objective, emotional pressure, character movement grammar, and contrast with opponent. Example: "relentless linear pursuit versus fluid evasive parkour"; "exhausted survival brawl, not elegant duel."

Applicable scenes -> Character-driven fights, chases, rival styles, martial-arts drama, AI prompts that otherwise become generic combo reels.

Misuse boundary -> Do not make the action only symbolic. Emotional design still needs range, contact proof, receiver response, and recovery cost.

Validation status -> Strong contemporary practitioner interview; not capsule-promoted.

### Chad Stahelski / John Wick -> Rhythm Oscillation And Early Collaboration

Source / film example -> Backstage and KPBS interviews with Chad Stahelski on John Wick.

Observation -> Stahelski describes liking rhythm and oscillation in fights, linking levels of realism or stylization to emotional effect, and treating action as something developed early with stunt, actor, writer, director, editor, and cinematographer collaboration.

Mechanism -> Action scenes need rhythmic variation and pipeline ownership. They are not post-production rescue jobs; choreography, camera, performance, editing, and tone must be designed together.

Executable action/camera/editing control -> Build a beat graph: pressure rise -> recoil/pause -> surprise or humor -> renewed threat -> exhaustion or punctuation. In prompt planning, name whether the beat should feel realistic, playful, brutal, balletic, panicked, or tactical, then align camera distance and cut density to that tone.

Applicable scenes -> Gun-fu, melee fights, action comedy, long set pieces, AI video sequences that feel monotonously intense.

Misuse boundary -> Do not treat "John Wick style" as only wide shots and long takes. The transferable mechanism is trained performance, rhythm control, clear contact, and integrated camera/edit design.

Validation status -> Strong practitioner source; not capsule-promoted.

### ASC Normal Fight Scene -> Chaotic Effects Must Remain Readable

Source / film example -> American Cinematographer, "How This Fight Scene From Normal Avoids Action Fatigue."

Observation -> The article describes testing rain, strobes, practical effects, global shutter, handheld anticipation, and lighting cues so chaos remained readable, including flash frames that freeze mid-impact.

Mechanism -> Environmental chaos needs timing design. Rain, strobes, handheld camera, smoke, snow, or alarms should punctuate action and reveal impact, not simply add visual noise.

Executable action/camera/editing control -> Assign each environmental effect an action job: strobe freezes impact, rain reveals motion path, sparks mark contact, dust shows near-miss vector, handheld anticipates without spoiling the beat. Test density so the effect supports faces and contact points.

Applicable scenes -> Hardware-store fights, night fights, rain/snow fights, alarm-lit rooms, chaotic AI video action where particles and camera shake easily hide the action.

Misuse boundary -> Effects are secondary evidence. If geography, target, and contact are unclear, adding rain, sparks, blur, or shake will make it worse.

Validation status -> Strong ASC production source; not capsule-promoted.

### Bordwell On Run-And-Gun / Bourne -> Shaky Clarity Requires Information Discipline

Source / film example -> David Bordwell, "Unsteadicam chronicles" and "[insert your favorite Bourne pun here]."

Observation -> Bordwell treats Bourne-style handheld/run-and-gun as a roughened form of intensified continuity: shots may be brief, bumpy, blurred, or partly off-center, but they still need to deliver a simple unit of narrative information. He notes that the style works when long shots, point-of-view alternation, repetition, or familiar tokens keep the viewer oriented.

Mechanism -> Shaky camera and fast cutting are not automatically failure modes; they fail when the shot no longer yields a readable information token. A fight can be frantic if each shot still answers one question: where is the body, what force is moving, who reacts, what changed?

Executable action/camera/editing control -> Before accepting handheld blur or rapid cutting, write the intended information token for each shot: "incoming fist from screen left," "receiver staggers into table," "knife hand pinned," "exit blocked." If the token cannot be named, the shot is likely decorative confusion.

Applicable scenes -> Subjective panic, chase fragments, close-quarters fights, AI video retries where the model produces motion without readable causality.

Misuse boundary -> Do not use "subjective chaos" as a blanket excuse. If the scene still needs the viewer to understand threat, target, contact, or escape route, the information token must survive.

Validation status -> Strong scholarly source; diagnostic update, not capsule-promoted.

### Editing-Practice Sources -> Overcutting Diagnosis Must Map To A Missing Function

Source / film example -> Frame.io action-editing article and Film Editing Pro fight-scene editing article.

Observation -> The sources stress that action editing balances rhythm, clarity, geography, reaction, impact points, faces, and story. They also note that alternating angles can smooth choreography and show attacker/defender information, but cutting too much or cutting without geography can lose the viewer.

Mechanism -> A weak fight edit should not be diagnosed only as "too many cuts." The failure is which function went missing: attack vector, impact point, receiver reaction, spatial reset, rhythm breath, or emotional/story beat.

Executable action/camera/editing control -> When a beat feels fake, score it with the Contact Proof Ladder, then add only the missing function: a wider reset for geography, a reaction shot for force, an impact-point match for continuity, a sound accent for contact, or a pause/recovery frame for body cost.

Applicable scenes -> Edit diagnosis, AI video output review, action previz, prompt retries, rough-cut feedback.

Misuse boundary -> Do not assume more cuts can rescue bad choreography. Alternating angles can clarify or hide; if every cut hides the same missing contact, redesign the beat instead of adding more fragments.

Validation status -> Practical editing sources; diagnostic update, not capsule-promoted.

### SAG-AFTRA Stunt Safety / Academy Stunt Design -> Design Includes Safety And Specialized Labor

Source / film example -> SAG-AFTRA stunt safety resources and Academy announcement of Achievement in Stunt Design for the 100th Oscars.

Observation -> SAG-AFTRA frames stunt safety as a priority requiring tools, forms, and qualified practice; the Academy's new stunt design category recognizes stunt professionals inside the Production and Technology Branch.

Mechanism -> Stunt design is a creative-technical discipline, not a casual performance note. Safety, rehearsal, equipment, personnel, camera, edit, and story effect are inseparable in real production.

Executable action/camera/editing control -> For fictional/AI prompt work, describe visible danger without operational stunt instructions. For real shoots, route anything risky to qualified stunt coordination, safety review, rehearsal, pads/rigging, medics, and controlled set procedures.

Applicable scenes -> Any fall, hit, vehicle, weapon, fire, water, height, crowd, animal, wire, glass, or explosive action; also useful as a boundary note for AI action design.

Misuse boundary -> Do not turn creative analysis into real-world how-to harm instructions. Do not assume an actor can safely perform what looks simple on screen.

Validation status -> Strong official/industry safety and recognition sources; policy boundary, not capsule-promoted.

## Prompt Translation Template

### Contact Proof Ladder

```text
initiating action:
target / receiving zone:
contact or near-miss relation:
receiver response:
environment / prop / costume / sound proof:
pain or recovery beat:
changed end state:
```

Score each rung when diagnosing a beat:

```text
0 = absent or unreadable
1 = implied but weak, hidden, too fast, or dependent on prior knowledge
2 = clear on first viewing
```

Minimum useful pass for a credible impact:

```text
contact_or_near_miss_relation >= 1
receiver_response >= 1
changed_end_state >= 1
total_score >= 8 of 14
```

Use the ladder as a diagnosis tool:

- If the action floats, add receiver response or environmental proof.
- If the hit looks unsafe or too real, clarify it as stylized/fictional and avoid operational stunt details.
- If the cut hides too much, preserve attacker and receiver in one readable frame or add a clear result shot.
- If every hit has the same rhythm, vary pause, recoil, pain, surprise, and recovery.

Score separation:

- `film-language failure`: the clip could be technically stable but the staging, camera, edit, or action causality is unclear.
- `prompt overload`: too many actions, characters, locations, camera moves, or style demands compete inside the duration.
- `usable imperfection`: a flaw remains but the action objective, contact proof, and changed state are still clear enough for the use case.

Retry controls:

```text
if identity / prop drift -> reduce characters/props, lock first frame/reference role, repeat key identifiers only once
if temporal flicker / morphing -> shorten action beat, reduce camera motion, request stable silhouettes and continuous body path
if anatomy / physics violation -> simplify limb interactions, avoid complex grappling, add one clear receiving surface or prop
if prompt mismatch -> restate action objective before style; remove decorative style clauses
if weak geography -> start with route/arena cue or wider setup, then move into close action
if missing contact proof -> require receiver response and changed end state, not only impact words
if camera motion without information token -> assign one job per movement: reveal threat, follow recoil, reframe target, or reset space
```
