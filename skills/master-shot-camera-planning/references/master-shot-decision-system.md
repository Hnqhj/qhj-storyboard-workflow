# 主镜反推决策系统

## 一、主镜候选评分

每个候选画面按 0–2 分评分。总分低于 6 分，不应成为主镜。

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 必要信息 | 可删 | 补充信息 | 删除会损害理解 |
| 关系可见 | 不可读 | 需解释 | 一眼可读 |
| 状态变化 | 无变化 | 暗示变化 | 变化在画内发生或留下结果 |
| 记忆价值 | 通用覆盖 | 有特点 | 段落代表图像 |
| 连接能力 | 前后无锚 | 单向连接 | 同时提供进入与离开线索 |

评分不是审美排名。构图再漂亮，若不承担场景任务，也只是参考图。

## 二、关系几何

### 两人

先写：`A 看/逼近/回避 B`。主轴通常是两人之间的视线或行动线。确认：

- A 与 B 在相邻镜头中保持可读的左右与眼线关系；
- 单人镜头仍继承对方的画外位置；
- 侧面双人镜、过肩和单人镜承担不同关系任务，不平均使用。

### 三人及以上

同时存在多条轴线时，只选当前段落的主关系：

```text
当前冲突/观看核心 -> 被观看者 -> 关键反应者 -> 其余背景关系
```

检查机位是否通过重叠、朝向或同侧构图错误地制造“同一阵营”。需要更换关系时，用动作、视线、重新建立空间或有意跳轴完成交接。

### 道具与空间

门、锁、手机、武器、桌面、出口和距离都可以是关系节点。若故事变化依赖道具，轴线和焦点不能只围绕人脸建立。

## 三、从二维主镜反推六项约束

1. **站位**：谁在前/中/后景，谁遮挡谁，距离如何表达关系。
2. **朝向**：身体方向与视线方向分开记录。
3. **轴线**：主要观看线、行动线或道具关系线。
4. **机位区**：哪些位置保持关系，哪些位置会造成误读。
5. **焦点路径**：观众先看哪里，随后由动作、明暗、视线或构图被带到哪里。
6. **连接条件**：进入主镜前需要知道什么，离开主镜时什么动作/视线/声音可交棒。

## 四、景别六问

1. 这一镜必须包含多少空间与人物关系？
2. 观众要接近谁的感受，还是观察整体局势？
3. 与前镜相比，信息范围扩大还是收紧？
4. 是否需要插入道具、手部、脚步或接触点作为证明？
5. 连续渐紧/渐松是否形成有效节奏，而非机械抽屉式变化？
6. 突然改变景别能否指出明确的发现、冲击或关系变化？

## 五、视高六问

1. 正反关系是否需要相近或对应的视高？
2. 是否跟随某个角色的真实视线？
3. 观众处在旁观、同席、伏低、俯瞰还是被压迫的位置？
4. 哪个高度最能整理背景、地面、楼梯、人群或遮挡？
5. 与前后镜的眼线、焦点高度和画面重心是否顺畅？
6. 强俯、强仰或高度突变是否承担段落节奏和异常感？

## 六、焦点交接表

```text
镜头：
第一焦点：
焦点制造方式：运动 / 对比 / 脸 / 形状 / 亮度 / 视线 / 引导线
离开位置：左/中/右 + 上/中/下
下一镜进入位置：
允许的眼动跳跃：顺滑 / 有意刺激，原因：
最短可读时长：
```

镜头很短时只保留一个主要焦点。镜头较长时，必须有画内动作或关系变化继续控制注意力。

## 七、连接镜头判定

保留连接镜头需至少命中一项：

- 建立或重建空间；
- 交代观看对象与反应；
- 证明动作起点、路径、接触或后果；
- 承接眼动或运动方向；
- 压缩时间或桥接地点；
- 通过并置、对比、重复、冲突、呼应或声画对位产生新意义。

若只重复上一镜已知信息，删除或合并。

## 八、跳轴收益测试

只有以下收益大于连续性成本时才跳轴：

| 收益 | 可见结果 |
|---|---|
| 故事 | 新信息更快或更清楚 |
| 视角 | 观众明确进入另一角色体验 |
| 构图 | 关系、阻隔、环境压力变得可读 |
| 节奏 | 省去拖沓过渡并形成有效顿挫 |
| 心理 | 不适、错位、亲密或阵营突变被感知 |

不能写出可见结果时，不允许以“艺术感”作为理由。

## 九、最小交付对象

交给完整分镜前，至少提供：

- 场景契约；
- 1–3 个主镜及删除代价；
- 人物/道具位置、朝向、主关系轴、机位区；
- 景别与视高的观众任务；
- 焦点和动势交接；
- 必要连接镜头及功能；
- 允许的轴线突破及收益；
- 连续性风险和不可丢失约束。
