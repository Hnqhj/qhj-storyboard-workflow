# Reference Video Original-Remake Branch

Use this branch for “拆解、复刻效果、裂变、按这个逻辑重新做” requests. The target is effect/function transfer, not surface similarity.

## Evidence Sufficiency

State what was actually inspected: full video with sound; partial clip; representative frames/contact sheet plus audio or transcript; still frames only; or description only. The weaker the input, the less exact the claims. Label observations `verified`, `high-probability`, `low-confidence`, or `to-confirm`; the label names may be shortened, but confidence boundaries may not disappear.

## Five-Layer Breakdown

1. **purpose:** attention, emotion, narrative, proof, conversion or identity job;
2. **psychology:** curiosity, pressure, identification, desire, relief, trust or surprise mechanism;
3. **copy/information:** promise, question, proof, reveal and call to action;
4. **picture:** shot function, blocking, scale, movement, light, color, design and transition;
5. **sound:** speech, music structure, foley, silence, hit and mix focus.

Do not infer tool names, models or settings from appearance alone.

## Shot-Function Ledger

For each meaningful unit record:

```text
visible facts
audible facts
narrative function
emotional / conversion function
portable mechanism
expression that must be replaced
confidence and missing evidence
```

## Originality Gate

Preserve only the function and mechanism needed by the new brief. Replace the reference's distinctive expression across several surfaces: character and relationship; plot/event and dialogue/copy; composition, blocking and location; music, performance and edit signature; brand, graphic system and identifiable visual motif.

The success target is comparable **effect attainment**, not a similarity percentage. There is no viral or performance guarantee.

## Remake Compiler

```text
reference function
-> new-project objective and truth
-> mechanism retained
-> new character/event/space/sound expression
-> production constraints
-> storyboard or prompt handoff
-> observable review check
```

Use `$creative-casebook` for a durable inspected case, `$commercial-video-strategy` for purchase/claim decisions, and `$professional-storyboard-director` for the original shot plan.

## Failure Rewind

Diagnose by layer—purpose, psychology, information, picture, sound, or platform execution. Change one primary and at most one secondary layer per retry; preserve layers that already work.

Reject platform stereotypes, universal 3–5 second change rules, guaranteed “viral” claims, guessed toolchains, and mandatory giant outputs when the user only needs one stage.
