# 画法配方：安静大色块与选择性线条

本配方来自用户选定的黄泉和服静态图及其色块偏好，重点是可迁移的线与色形关系。静态图看不出动画时序；不要把这个配方称作已验证的高速动画画法。配方的当前实测状态见 `validation-scope.md`，不得从一张好图推断任意角色稳定。

## 基准的决定性特征

- **色块内部低变化，影形边界有决定性。** 宽袖先读成一整块颜色，少量宽窄不等的长影形从腋下、折回、腰带或衣褶延展。它不是绝对均匀矢量平涂，也不是每个隆起都以渐变渲染。允许极弱、缓慢的大尺度明度漂移。
- **影形疏密有层次。** 胸、宽袖、长衣片有完整安静区域；折线集中在实际收束处。不要把“图形化”翻译成全身铺满三角碎面。
- **线条选择结构。** 深线集中在眼睑、领口、抓握和前后遮挡。长轮廓相对完整，有轻重、转折与收笔；少量复线和线色错位是局部选择，不是全身毛边滤镜。
- **头发先分大组。** 组内少线、外缘长弯短折交替，大小疏密不均。不要以逐束亮带或大量饰品证明完成度。
- **用各自本色迁移。** 深衣以暗基色/更暗宽影成立，浅衣以浅基色/灰色宽影成立；不能给所有人物染成基准的紫色。
- **轻微软度服务边缘。** 脸手与结构核心清楚，浅色边缘轻轻融入底色。静姿不强加拖影或光晕，清晰也不算失败。

## 白底人设：通过本轮画风复测的 v2 母版

这是实际生成采用的 v2 共用正文。下方另接一个角色设计段：身份识别点、服装大类、主要色区、必要道具、当下姿势与表情。不要加入当前用户没有需要的任意微小约束；精确左右手、饰件数量等只有有实际用途时才锁定。保留用户明确要求，不能拿简化画法当作删设计的理由。

母版源自长发角色测试；用于新主体时必须按结构适配：短卷发改成大小错落的卷团及少量短折，短夹克改为胸背与袖筒的大色区，工装裤用连贯裤腿影形。不要照抄长发尖梢、长衣摆或腰间佩刀。原创无名人物直接给外观身份；母版中的“角色名字确定基本身份”只用于已有名字的角色。

```text
竖版9:16，纯白色背景，一位成年女性的完整上色二维手绘动画全身人设。头顶、双脚和随身道具完整入画，人物占画高约87%。采用适合逐帧重复绘制的简练造型，角色名字确定基本身份，服装与配件按后面的设计清单绘制。

画法与色块：每一主要衣片先是一整块安静的基色，只用少数连贯、宽大的深色影形交代转面和遮挡。胸口、袖面和长衣片保留大片低变化的颜色，褶皱集中在肘腰膝等真实收束点，阴影以长楔形、斜切面或宽弧形结束。大色面内部有极弱、跨度很大的明度变化，缩小看仍是一块完整颜色；影形的边界明确画出。浅色衣物同样用一块浅基色和几块灰色宽影成立。颜色哑光克制，亮暗变化安静，细节集中于脸和手。

脸由明亮肤色和一块明确的淡冷灰影组成，眼、鼻、口是简短有起落的炭灰笔线。头发归成几组不等大的色形与宽影，内部大面积留空；长弯、短折、尖细收束交替，发组轮廓大小疏密错落。细炭灰轮廓有天然提按与收笔，线在眼睑、领口、抓握、遮挡处收紧加重，大片衣料外缘放松；少数局部有一笔很近的复线和轻微线色错位。金属和硬壳只用一个概括的平面与一处窄亮面。身体承重、手指和道具连接清楚，完整的形状取舍贯彻全身。

整体只有轻柔的动画摄影观感，浅色边缘微微融入白底，五官和关键抓握清楚。不要精修游戏立绘的碎亮面、连续圆润塑形或额外花纹饰品；不添加纸纹、颗粒、全图毛边、文字或水印。
```

## 动作截帧：适配方法，尚未由本轮静姿回归验证

保留上述色形与线条机制，换成一个具体的受力瞬间：哪一段躯干压缩、近侧肢体如何放大、哪个衣发后缘仍滞后。实体拖形必须连接当前身体或衣物，颜色和方向属于它本身；别用离体发光带代替。选择接触或即将接触的姿态时，让眼神、关键握持与当前接触可读，把形变放在为运动服务的末梢。光源很小时才给邻近区域薄层溢光。用实际新图验证，不能把“动画单帧”字样当成结果证据。

## 只修一个主要缺口

若脸、衣、头发被连续圆润明暗塑体积，先重写其底色与宽影关系。若影形已经成立但装饰过多，只收紧信息密度与设计清单。若全部变成僵硬切纸，恢复宽缓的低幅色阶与轮廓轻重，不增加脏纹理。若仍有一类服装无法迁移，保留失败用例，不偷偷替换为容易的和服。
