# Wild Handdrawn Anime Image

目标是可迁移的作画语言，而非单张漂亮图。调用图像生成前，先确认当前用户的角色、画幅、用途、允许批次和本次可变项。用户已明确的选择继续有效；本 Skill 不授予额外生成、全局安装或外部修改权限。

## 画风与调用

先读 [style-recipe.md](references/style-recipe.md)，它包含可直接编译的白底人设母版、色块机制和有边界的动作截帧适配。查看 [validation-scope.md](references/validation-scope.md) 了解实际验证范围。当前任务已有用户选择的配方时以其为准；把稳定的线/形/色/成像核心与角色、服装、姿势、构图区分开，不能把基准的紫色、和服或站姿固定给所有主体。新请求默认只生成用户当前要的数量，批量回归仅在用户要求重复测试时启用。

用户要求纯提示词测试时，每一次调用都从完整文字重新生成。调用参数中不传底图、参考图、最近图片或编辑输入；先前图片仅供观察与评分。保留实际提交的完整提示词和调用参数，不能以“没有显式说编辑”代替输入证据。此约束是当前工作流核心，不以换工具或追加图像偷偷补偿。

在提供内置图像工具的 Codex 中，调用 `image_gen.imagegen`，实际参数只含当前完整 `prompt`。遵守宿主当前可调用工具与图像 skill；工具未公开底层模型、seed或精度控制时不杜撰。新生成失败不自动改用需密钥的 API/CLI。返回后复制原文件到当前项目交付目录，保存精确提示词与元数据，原图保留不调色、不磨皮、不加纹理。比较图可以并排展示，不能改完图再算纯文成功。

生成后查看实际原图，再判断画法是否成立。先看结构、轮廓选择、色面组织和局部完成度，再看柔化与溢光；不能仅靠“更糊、更亮、更脏”判定手绘。具体可观察标准及角色要求由获批配方/本任务量表提供，不把某个角色的服装或某一张图的偶然特征固化成全局规则。

## 有界回归

当用户要求重复优化或稳定性测试时，先读 [regression-protocol.md](references/regression-protocol.md)。首张出现前记录角色用例、预算、硬门槛、评分维度、冻结版本与停止条件。五角色是当前回归用例数量，不是本 Skill 永久要求。

1. 完整评审当前批次的每张原图，保留失败理由与定位证据。
2. 若修改配方，只解决一个已观察的主要缺口；新版本和变更理由入账。旧原图与提示词继续可访问。
3. 需要证明重现时，冻结配方及每个角色的完整提示词，用新调用重复；不可从前图编辑，也不可只保留最好结果。
4. 依预先规定的停止规则决定 `STOP / CONTINUE / ESCALATE`。决定继续不扩张用户授权预算。

原始返回图每张单独编号，差图照样占已使用输出槽。失败不删除、不替换、不从分母中消失；生成工具失败且未返回可读图片另记。工具未暴露模型版本、seed或参数时填未知，不能编造。

## 验证与交付

仅在批量回归任务中，用 `scripts/regression.py` 初始化、校验记录并生成全样本报告；脚本只检查记录、哈希、预算、评分完整性及预设稳定条件，不会生成图片、替人做审美判断或删除资产。普通单张请求无需创建回归账本。

交付原图、实际提示词、配方版本、所有样本的评审结果及停止理由。把“5个角色各一次的覆盖”“同词重复样本”“当前测试规则内稳定”分开陈述。报告用 `k/n` 与实际失败项；没有概率模型就不声称成功概率或百分之百稳定。若尚未达标，保留可复用部分并明确缺口，不降低标准凑通过。
