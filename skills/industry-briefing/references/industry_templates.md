# 行业模板配置

## 概览

本文档定义了7个预设行业的配置信息，包括行业名称、细分领域、行业特色和典型关注点。这些配置用于指导信息追踪和快报生成。

## 自定义行业

如果用户的行业不在上述7个预设行业中，可以按照以下结构定义自定义行业：

```json
{
  "industry_name": "行业名称",
  "sub_fields": ["细分领域1", "细分领域2", "细分领域3"],
  "characteristics": "行业特色描述",
  "focus_areas": ["关注点1", "关注点2", "关注点3"]
}
```

## 数据格式

### 内容数据格式（传递给脚本）

```json
{
  "industry": "AI/AIGC",
  "date_range": "2024-01-01 至 2024-01-07",
  "total_count": 10,
  "items": [
    {
      "title": "条目标题",
      "date": "2024-01-05",
      "category": "大模型",
      "importance": "高",
      "summary": "内容摘要",
      "source": "信息来源"
    }
  ]
}
```

### 主题配置格式

```json
["主题1", "主题2", "主题3"]
```

## 扩展指南

- 新增行业：在本文档中添加新的行业配置
- 修改细分领域：根据行业发展趋势更新细分领域
- 调整关注点：结合用户反馈优化关注点设置
- 数据验证：确保传递给脚本的数据格式正确完整
