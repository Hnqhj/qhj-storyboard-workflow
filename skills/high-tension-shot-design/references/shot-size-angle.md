# Shot Size And Angle

Use this when the user asks for 景别, 镜头角度, 镜头语言, or a more precise frame plan.

## Shot Size Library

Extreme wide shot / 大远景:

- Use for epic scale, loneliness, worldbuilding, danger from environment.
- Prompt: `extreme wide shot, the subject appears small against a massive environment, strong scale contrast`.

Wide shot / 全景:

- Use for body action, motorcycle/vehicle motion, spatial geography, character vs environment.
- Prompt: `wide shot showing full body and environment, clear movement path and spatial relationship`.

Full shot / 全身:

- Use for outfit, weapon, pose, silhouette, fashion/action reference.
- Prompt: `full-body shot, head-to-toe visible, clean silhouette, readable pose`.

Medium full / 膝上:

- Use for heroic stance, weapon draw, fashion power pose, action preparation.
- Prompt: `medium-full shot from knees up, subject dominates the frame while body action remains readable`.

Medium shot / 中景:

- Use for dialogue, confrontation, character attitude, hand/prop relation.
- Prompt: `medium shot, waist-up framing, hands and expression both visible`.

Medium close-up / 中近景:

- Use for emotional pressure, controlled anger, decision, subtle face movement.
- Prompt: `medium close-up, face and upper torso fill frame, eyes and micro-expression emphasized`.

Close-up / 近景:

- Use for eyes, mouth, hand, weapon, switch, tattoo, key object.
- Prompt: `close-up on [specific detail], shallow depth of field, background compressed into abstract pressure`.

Extreme close-up / 特写:

- Use for maximum tension, trigger, breath, eye twitch, finger tightening.
- Prompt: `extreme close-up of [eye/finger/trigger/lip], almost abstract, one emotional detail carries the scene`.

Insert shot / 插入镜头:

- Use for object clue, weapon detail, tech UI, key, wheel, hand.
- Prompt: `insert shot of [object], crisp detail, the object becomes the emotional turning point`.

POV shot / 主观镜头:

- Use for danger, pursuit, surveillance, being trapped, tactical view.
- Prompt: `POV shot from the subject's perspective, foreground edges suggest [helmet/window/weapon], viewer feels inside the action`.

Over-the-shoulder / 过肩镜头:

- Use for confrontation, threat relation, target lock, intimacy.
- Prompt: `over-the-shoulder framing, foreground shoulder partially blocks the frame, the opponent/target is visible beyond`.

## Camera Height And Angle

Eye-level:

- Neutral, intimate, realistic.
- Use when the viewer should feel equal to the subject.

Low angle:

- Power, threat, heroism, intimidation.
- Use with wide lens/strong silhouette for dramatic dominance.

High angle:

- Vulnerability, surveillance, smallness, tactical overview.
- Use for isolation or being watched.

Ground-level:

- Speed, impact, vehicle danger, footsteps, body motion.
- Use for motorcycle, running, fight impact, rain puddles.

Overhead / bird's-eye:

- Strategy, ritual, geography, entrapment.
- Use when patterns or spatial relation matter.

Dutch angle:

- Instability, danger, mental rupture.
- Use slightly. Too much becomes gimmick.

## Lens Feel

Wide-angle:

- Speed, aggression, foreground exaggeration, dynamic action.
- Risk: distort face/hands if too close.

Long-lens / telephoto:

- Compression, surveillance, pressure, background threat feels close.
- Risk: action may feel flattened if movement path is unclear.

Macro:

- Detail tension: eye, tattoo, ring, trigger, blade edge.
- Risk: loses spatial context, so pair with establishing shot if needed.

## Shot Progression Patterns

Classic escalation:

```text
wide shot establishes danger -> medium shot shows decision -> close-up reveals emotion/action trigger.
```

Speed sequence:

```text
ground-level wheel detail -> low wide tracking shot -> close-up on eyes/hands -> wide shot of the vehicle breaking through space.
```

Psychological pressure:

```text
locked medium close-up -> slow push-in to close-up -> extreme close-up on one tiny betrayal of emotion.
```
