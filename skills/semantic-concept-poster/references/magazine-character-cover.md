# Magazine Character Cover Mode

Use this reference for character-centric covers, anime fashion covers, futuristic editorial covers, luxury magazine covers, and the "NEO VANGUARD" style pattern.

## Core Direction

Create a premium fashion magazine cover where the character is the cover star, but the cover is still a designed editorial object:

- centered fashion portrait composition
- strong masthead/title
- refined editorial typography
- graphic panels, barcode details, grids, blueprint/UI elements, Japanese-inspired design marks when appropriate
- luxury streetwear or designer advertising energy
- anime linework blended with cinematic lighting and material detail
- high-end layout, not random decorative text

## Use With References

If the user provides a character image:

- Preserve face identity, hair, outfit essence, signature props, and attitude unless told otherwise.
- Upgrade styling only where allowed: fashion silhouette, accessories, cover lighting, graphic background, editorial layout.
- Do not erase the original character into a generic fashion model.

If the user provides only a text description:

- Generate a character concept from the description.
- Keep visual features specific and readable.

If the user also provides a core word/theme:

- Let the magazine title and editorial graphics express that theme.
- Do not let fashion details override the core word.

## Futuristic Anime Luxury Cover Pattern

Use this pattern as a reusable style, not as a fixed character:

- ultra-detailed luxury anime fashion cover illustration
- future trendsetter energy
- sharp anime linework plus realistic cinematic lighting
- smooth but not plastic skin rendering
- glossy hair highlights
- detailed fabric texture
- reflective metal jewelry/accessories
- subtle cyber tattoo or fine-line body graphic when suitable
- oversized asymmetric utility jacket, high-neck crop top, layered chains, rings, earrings, technical accessories when suitable
- textured ivory / off-white / controlled color background
- cyan, charcoal, black, silver, and deep red accent panels
- editorial typography, futuristic interface graphics, blueprint elements, abstract grids, barcode details
- flawless magazine layout, premium graphic design, collectible cover design

Do not overfill the cover. Editorial density should look intentional and designed.

## Magazine Cover Output Template

```text
【封面方向】
[角色定位 + 杂志气质 + 标题/主题]

【角色封面生成提示词】
生成一张高级前卫杂志封面构图，标题为「[主标题]」。画面中心是一位[角色描述或参考图角色]，保留[需要保留的角色特征]，整体呈现[情绪/姿态/气场]。角色拥有清晰精致的动漫线稿，同时融合真实电影级照明、细腻皮肤渲染、闪亮发丝反光、清晰面部情绪和高级时尚肖像质感。

服装为[服装设计]，包含[材质、廓形、配饰、纹身/图案/道具]，面料纹理清楚，金属配饰具有反光质感。封面背景为[背景色/材质]，加入精致的编辑排版文字、未来主义界面图形、日本风格设计图案、蓝图元素、抽象网格、条码细节和[强调色]强调面板。所有辅助文字和图形必须服从杂志封面版式，不要随机堆砌。

整体风格融合豪华街头服饰美学、下一代设计师广告能量、当代都市未来主义、反叛优雅、高端平面设计和收藏版封面设计。构图居中，主标题清晰可读，角色与标题/版式自然融合，具有专业色彩分级、清晰对比、无瑕杂志布局和高级编辑氛围。

【负面提示词】
低级杂志模板，普通头像插画，标题不可读，文字乱码，随机排版文字，过多无关装饰，廉价赛博风，塑料皮肤，过度磨皮，五官崩坏，手指畸形，配饰融化，服装纹理混乱，背景杂乱，电商海报，广告页感，水印，logo。
```

## Default Choices

If the user gives no title, choose one of:

- NEO VANGUARD
- FUTURE ISSUE
- SIGNAL
- OUTER MODE
- ICON / INDEX

If the user asks for Chinese magazine cover, generate a concise Chinese masthead instead of forcing English.

If the user wants Xiaohongshu cover, reduce small text density and keep the title more readable on mobile.
