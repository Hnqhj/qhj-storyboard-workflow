# Scene, Beat, And Dialogue

Use this for scene outlines, script pages, dialogue, subtext, and compression.

## Scene Function

A scene should do at least two:

- advance plot
- reveal character
- change relationship
- raise stakes
- introduce or pay off information
- force a choice
- change emotional temperature
- create a new question

If a scene only explains, compress it into action, image, or an insert.

## Scene Formula

```text
At the start, [character] wants [scene goal].
The obstacle is [person/object/rule/environment/emotion].
They try [strategy].
The scene turns when [reversal/reveal/choice].
By the end, [relationship/information/status/danger] has changed.
```

## Beat Types

- entrance beat: who arrives and with what energy
- ask/refusal beat: desire becomes explicit through action
- test beat: obstacle pushes back
- tactic shift: character changes approach
- reveal beat: hidden information appears
- reversal beat: advantage changes sides
- price beat: a cost appears
- button beat: final image, line, sound, or action that lands the scene

## Dialogue

Good dialogue is rarely just information. It can:

- hide motive
- attack or defend
- negotiate status
- dodge emotion
- seduce, threaten, joke, confess, or lie
- create rhythm against the image

Use subtext:

```text
what the character says != what the character wants
```

Avoid:

- explaining the theme directly
- saying what the audience already sees
- giving every character the same voice
- long lore monologues in short scenes

## Action Lines

Write visible behavior:

```text
weak: She feels trapped.
strong: She stops at the open door, hears the engine outside, and locks it from the inside.
```

For AI video prompts, convert emotions into filmable cues:

- shame -> avoids mirror, hides mark, removes badge
- anger -> stillness, jaw tension, controlled breath, broken object
- fear -> checks exits, keeps distance, grips object
- desire -> reaches, follows, lingers, disobeys

## Compression

For short video:

- enter late, leave early
- combine exposition with action
- let props carry backstory
- make the first image contain the conflict
- make the last image answer or invert the first image
