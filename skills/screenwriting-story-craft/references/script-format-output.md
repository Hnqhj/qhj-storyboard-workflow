# Script Format And Output Shapes

Use this when the user asks for a script, outline, beat sheet, treatment, or prompt-ready story block.

## Common Outputs

Logline:

```text
When [inciting event], [protagonist] must [goal] before [stakes], but [opposition] forces [choice/cost].
```

Short synopsis:

```text
[Protagonist] lives in [world]. When [disruption] happens, they pursue [goal]. As [opposition] intensifies, they must [choice]. The story ends with [new condition/final image].
```

Beat sheet:

```text
1. Opening image:
2. Setup:
3. Inciting incident:
4. First choice:
5. Complication:
6. Midpoint/reversal:
7. Crisis:
8. Climax:
9. Final image:
```

Scene card:

```text
Scene:
Purpose:
Location/time:
Characters:
Want:
Obstacle:
Turn:
Result:
Visual hook:
```

AI video story block:

```text
Story core:
Character want:
Obstacle:
Choice:
Consequence:
Final image:
```

## Screenplay Formatting Basics

Use standard script-like labels when helpful:

```text
INT./EXT. LOCATION - TIME

Action lines in present tense. Only visible and audible information.

CHARACTER
Dialogue.
```

For AI video, script format can be looser. Prioritize filmable action and clear beat-to-shot handoff.

## Treatment Style

Use treatment format when the user needs a readable story pitch rather than script pages:

- write in present tense
- focus on action, decisions, and turning points
- keep lore short
- include emotional change
- end on a strong final image

## Rewrite Modes

- Strengthen premise: clarify want, obstacle, stakes, hook.
- Strengthen character: add flaw, tactic, choice, cost.
- Strengthen scene: add scene goal, obstacle, reversal, result.
- Strengthen dialogue: add subtext, tactic, rhythm, conflict.
- Shorten for video: compress exposition into action and image.
- Prepare for shot design: convert beats into visual functions.
