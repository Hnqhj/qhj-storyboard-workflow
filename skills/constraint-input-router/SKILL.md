# 最低成本约束输入与混合制片路由

## R — 原文（Reading）

> “现在最大的问题就是景深的问题……图片模型很难去识别这个事情。有时候还得用深度贴图来完成背景虚焦。”
>
> — MokeLMa，视频 03，00:29:42–00:32:38

---

## I — 方法论骨架（Interpretation）

不要把所有生成失败都继续交给提示词解决；先判断尚未被可靠表达的是语义、构图、身份、空间、光学、动作还是实拍关系。
为该变量选择成本最低但足以消除歧义的证据：文字、参考图、标注图、草图/分镜、控制图、深度、layout、简单 3D、表演或实测数据。
把提示词中的焦段、光圈、传感器、胶片、景深和相机位置视为创作意图，不视为物理执行证明。
当透视、遮挡、景深、尺度、走位或合成精度重要时，必须用可见结果、深度、几何、表演或现场数据重新验证。
先用静帧、低清预演或 animatic 测试最危险变量；只有低成本层无法通过验收时才向更强约束升级。
每次只升级失败变量，避免把所有控制手段一次堆上，造成成本、冲突和虚假精确感。

当任务涉及多参考合并、真人身份与角色造型竞争、保真放大、反推提示词、区域颜色/材质回填或局部编辑承诺时，读取 `references/reference-sovereignty-and-fidelity.md`。它负责参考主权、未知项、工具路由和可见验收；本 Skill 仍负责选择最低充分输入。

## A1 — 课程中的应用（Past Application）

### 案例 1：简单 3D 交代空间与机位
- **问题**：语言无法明确场景布局、尺度和摄影机关系。
- **方法论的使用**：讲者用低成本三维资产搭出场景与机位，再让生成模型完成视觉设计，并根据结果回到布局修正。
- **结论**：当主要歧义属于空间，简模比继续叠加形容词更直接；Blender 只是可替换实现层。
- **结果**：形成“空间证据 → 生成 → 布局修正”的往返流程；课程没有展示受控前后对照。

### 案例 2：手绘分镜生成火星镜头
- **问题**：仅靠文字难以稳定传递具体构图。
- **方法论的使用**：讲者上传简单分镜，用成像、风格和渲染模块补充目标，再逐项观察生成结果是否对应草图。
- **结论**：把构图证据和风格规范分开输入，能减少模型自由补全的范围。
- **结果**：现场结果与草图大体对应；讲者的“约 70%”是主观估分，不是准确率测量。

### 案例 3：真人项目暴露摄影参数不遵从
- **问题**：提示词已经写入相机、焦段和景深信息，输出仍无法稳定复现真实焦深、背景虚化和镜头畸变。
- **方法论的使用**：讲者回到镜头数据、畸变参考、深度贴图和后期分层等传统手段补偿。
- **结论**：摄影数字只表达意图；对物理关系有要求时，必须升级为可验证输入和下游 camera match。
- **结果**：项目经验直接否定“参数写进提示词就必然准确”；课程没有给出误差量化。

### 案例 4：用真人打斗约束熊猫动作
- **问题**：复杂拳法的动作、节奏和身体关系难以用文字完整描述。
- **方法论的使用**：讲者上传真人打斗参考，让 AI 负责角色化渲染。
- **结论**：动作歧义应升级到表演、动捕、三维预演或手绘 timing，而不是继续写更多动作形容词。
- **结果**：熊猫完成了较复杂动作；课程未做逐帧保真验证。

## A2 — 触发场景（Future Trigger）

### 用户会在什么情境下需要这个 skill？

1. 多人走位、遮挡、尺度、机位或空间关系持续出错，不确定该继续改提示词还是搭 layout/3D。
2. 提示词写了焦段、光圈、景深或镜头运动，但透视、虚化、畸变和主体距离仍不可信。
3. 动作、打斗、舞蹈、口型或节奏无法被文字稳定表达，需要选择表演参考、animatic、动捕或三维预演。
4. 想从故事板、草图、照片标注或深度图生成镜头，并需要定义验收与升级条件。
5. AI 元素要与实拍合成，必须匹配相机、尺度、光照、遮挡和接触关系。
6. 反复写“色温分区、视觉中心、高反差、光影放弃区”等概念仍看不出差异，需要把光照意图升级为可见参考、首帧、灯位草图、分层或后期方案。

### 语言信号

- “继续改提示词，还是该上 3D / layout？”
- “人物绕桌走位总错，空间关系锁不住。”
- “我写了 35mm 和 f/2.8，为什么景深还是不对？”
- “Use storyboard/depth/performance reference to control this shot.”
- “Choose the minimum sufficient constraint input for camera match and blocking.”

### 与相邻 Skill 的区分

- `invariant-exploration-director` 先识别哪些变量风险高、必须锁定；本 Skill 与它组合，为这些变量选择最低充分的非文字证据。
- `modular-text-bible` 负责语言表达；当语言不足时，本 Skill 才升级到参考、草图、layout、3D、表演、深度或实测数据，而不是继续堆词。

## E — 可执行步骤（Execution）

激活后，按以下步骤执行：

### 形态重构与身份连续性升级门

当同一主体需要在镜头内大幅改变解剖、轮廓、肢体数量、部件拓扑或体型结构时，不得把“起始身份参考 + 文字描述终态”误判为充分输入：

- 起始参考只能可靠证明起点；若终态需要可复用、可连续或可验收，必须增加终态参考图、双状态设计板、轮廓草图、简模或其他可见终点证据。
- 更换主体名称、删除“怪物/伪人/机甲”等名词不能修复终态漂移；先检查是否是“文字要求改变轮廓，同时参考图要求保持身份”的结构冲突。
- 若生成出的意外终态被用户接受，从获批画面截取干净状态资产并登记为新版本；后续镜头只引用该状态，不再同时让旧形态竞争控制权。
- 若没有终态证据且用户要求身份稳定，则把变化限制在姿态、动作、损伤、表面材质、局部附着物和可逆特效，不改主体拓扑。
- 完成标准：每次重大形态变化都有明确起点证据、终点证据或“仅限一次探索、不可直接承担后续连续性”的书面分类。

1. **诊断失败变量与风险**
   - 将问题归入语义/风格、身份、构图、空间/尺度、光学/深度、动作/节奏、光照/实拍合成或物理/工程精度。
   - 为关键变量写出可观察验收项、失败代价、当前证据和允许误差。
   - 完成标准：每个失败能指向一个主变量；禁止用“整体不对、再电影感一点”作为诊断。

2. **选择最低充分约束层**
   - 按下列路由选择，不要默认从文字直跳高成本 3D：
     - 语义、气氛、材质倾向：文字 + 获批参考属性。
     - 光照层级、明暗归属、冷暖关系：先写可见光源位置、亮区范围、阴影形状与材质响应；若文本对照失败，升级到获批灯光参考、首帧/色键、灯位草图、分层合成或后期调色，不继续堆摄影黑话。
     - 构图、景别、角色位置：标注图、草图或故事板。
     - 前后景、遮挡、景深分层：分割、深度图、分层合成或带深度的 layout。
     - 多人走位、比例、透视、机位：块面预演、简单 3D、相机 blockout。
     - 复杂动作、表演、节奏：表演视频、animatic、动捕、rig 动画或手绘 timing。
     - 实拍合成：现场 plate、相机/镜头元数据、畸变参考、尺度物、光照参考和 camera match。
     - 物理/工程准确：实测、CAD、标定相机或仿真；生成图只能作概念提案。
   - 完成标准：所选输入能直接表达主风险变量，且比下一层更低成本。

3. **制作控制包并分离主权**
   - 列出必须遵从的不变量、允许 AI 探索的变量、参考来源/授权、坐标或时间基准、输入版本和目标工具的适配要求。
   - 完成标准：控制包能回答“什么必须准确、什么只表达意图、什么可以涌现”。
   - 判停条件：若没有可见验收标准，不开始生成；先返回 `creative-north-star`、`minimum-visual-bible` 或 `modular-text-bible` 补齐目标。

4. **执行低成本试片**
   - 先生成少量静帧、低清片段、接触表或 animatic；把输出与草图、深度、几何、表演或现场数据并排比较。
   - 不以提示词中“写过参数”判定通过，只以可见关系、叠合误差或测量结果判定。
   - 完成标准：主风险变量达到预设容差，或形成可复现的失败记录。

5. **只升级失败变量**
   - 若文字失败，升到参考/草图；若二维结构失败，升到深度/layout；若空间、透视和走位失败，升到简单 3D；若动作失败，升到表演/动捕；若物理精度失败，升到实测与专业管线。
   - 完成标准：每次升级都有上一层失败证据、预期减少的歧义和新增成本；不为“看起来更专业”堆叠控制手段。
   - 判停条件：达到容差后停止升级；若工具仍不遵从，保留约束源并更换实现层，或把该环节交回传统制作。

6. **交付路由与验证记录**
   - 输出风险诊断表、输入层选择、控制包、试片、验收结果、升级历史、最终适配器和传统工艺回退方案。
   - 完成标准：另一位成员能解释为何选择该输入层，并能用同一证据复核结果，而不是相信提示词或模型品牌。

## B — 边界（Boundary）

### 不要在以下情况单独使用此 skill

- 任务只是建立整体风格、世界观或情绪方向，没有具体构图、空间、光学、动作或合成风险；使用 `minimum-visual-bible` 或 `visual-calibration-loop`。
- 一张低风险图片用文字和简单参考已经通过验收；不要为了流程完整而强制搭 3D。
- 项目真正缺失的是角色身份、服装或道具状态数据；先使用 `entity-continuity-system`。

### 不可绕过的硬边界

- **摄影参数提示词不等于物理准确**：写入焦段、光圈、传感器、胶片、景深或镜头位置，只能证明表达了成像意图，不能证明透视、景深、畸变、曝光、色彩响应或空间关系被严格执行。
- 不得把生成提示词中的数字直接交给 3D、VFX 或实拍团队当作相机标定数据。必须使用可靠元数据、实测、消失点、主体距离、畸变参考、深度或叠合误差重新 camera match。
- JSON、精确小数和参数表提高沟通清晰度，不自动提高模型遵从度；最终只认可可见结果、测量和批准证据。

### 课程中的失败模式

- **模糊形容词替代证据**：只说“高级、宏大、电影感”，会让模型按高频关联自由补全。
- **无分镜便直接烧高成本视频**：上游未解决的构图、动作和节奏问题会在连续运动中成倍放大。
- **实拍与 AI 只对色调、不对真实光照**：同一 LUT 不能修复主光方向、接触阴影、遮挡、反射和空气层冲突。

### 讲者的盲点 / 时代局限

- 课程中的平台能力、时长、成本和速度判断会快速过时；只保留“按风险逐级升级证据”的路由，不绑定软件。
- 演示多数是可见案例或个人经验，不是相机、动作或效率的受控精度实验；不要沿用主观百分比和倍数。
- 参考、故事板、真人表演和资产必须记录来源、授权、隐私和允许用途。
- 更强约束会减少随机性，但不能保证所有模型遵从；要始终保留验证、替换实现层和传统工艺回退。

### 容易混淆的方法

- 参考图说明“像什么”；layout/3D 说明“东西在哪里”；深度说明“前后与分层”；表演说明“如何随时间运动”；实测数据说明“物理上是什么”。不要把它们压缩为同一种提示词附件。
- 简模的目标是降低结构性歧义，不是提前完成精美资产。
