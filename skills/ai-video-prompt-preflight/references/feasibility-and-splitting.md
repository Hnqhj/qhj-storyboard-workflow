# Feasibility And Splitting

Use this for complex or long AI video prompts.

## When To Split

Split the clip when it has:

- more than one location change
- complex character action plus complex camera move
- transformation plus combat/action
- many characters
- several props changing state
- story turn plus detailed action plus close-up emotion
- more than 6-7 clear beats in 15 seconds
- one clip needs both wide geography and stable face close-up

## Safe Clip Units

Good units:

- one entrance
- one chase beat
- one transformation stage
- one attack exchange
- one reveal
- one product action
- one emotional reaction

## 15-Second Feasibility

Usually safe:

```text
5-6 segments, one route, one character, one vehicle/prop, one environment, one major turn.
```

Risky:

```text
8+ detailed cuts, multiple environments, dialogue, transformation, fight, close-up emotion, and camera effects all together.
```

## Split Strategy

```text
Clip A: hook + orientation.
Clip B: action build + obstacle.
Clip C: turn + payoff.
```

For continuity:

- use tail frame of previous clip as next reference if tool supports it
- restate current form at frame 1
- keep world and color locks identical

## Simplification Rules

- reduce locations before reducing identity locks
- reduce camera moves before reducing action clarity
- reduce decorative effects before reducing story turn
- keep one strongest visual peak
