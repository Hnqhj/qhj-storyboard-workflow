# 不变量—探索变量的导演控制

## R — 原文（Reading）

> “人的控制可以占 50%，非控制可以占 50%，因为有时候出的确实比我做得好。”
>
> — MokeLMa，视频 02，01:23:12–01:23:23

---

## I — 方法论骨架（Interpretation）

可控与惊喜不是一个总强度滑杆，而是要先把不同变量分配到不同主权区。
一旦变化会破坏角色身份、叙事事实、品牌识别、连续性、权限或不可逆成本，该变量就是不变量，必须先通过硬门槛。
允许在有限范围变化、但越界需要人批准的，属于条件变量；应写清范围、选项和升级条件。
只有偏离不会破坏核心、且新组合可能改善情绪、构图、纹理、次要动作或环境细节时，才进入探索变量。
生成后先验收不变量，失败候选直接淘汰；通过后才评价惊喜是否服务作品，而不是只看新奇。
被选中的意外发现可以提议进入下一版 Bible，但必须经过具名人类批准和版本记录，不能静默改写项目标准。
课程中的“50/50”是鼓励保留涌现的经验比喻，不是所有项目都应采用的固定比例；约束比例必须随风险和返工成本变化。

---

## A1 — 课程中的应用（Past Application）

### 案例 1：用红黄块面锁比例，再让九宫格探索镜头

- **问题**：动画方案需要保持角色比例与空间关系，同时又希望快速看到多种镜头可能性，不值得先制作完整动态预演。
- **方法论的使用**：讲者用红黄块面标定角色比例和空间关系，把这些作为结构不变量；随后以九宫格生成多张画面，探索机位与镜头方案。
- **结论**：高风险结构可以用低精度证据锁定，非关键镜头表现仍可交给生成模型发散。
- **结果**：用很低的预演成本得到一组可判断方案；课程没有量化每张图对比例的严格遵从度。
- **出处**：视频 03，00:35:38–00:36:53；对应案例池 `c24`。

### 案例 2：用真人动作锁运动结构，让 AI 做角色化渲染

- **问题**：熊猫角色需要完成复杂拳法，纯文字难以表达动作时序、身体关系和节奏。
- **方法论的使用**：讲者上传真人打斗作为动作约束，把表演结构作为条件/不变量，再让 AI 将动作渲染到熊猫角色上。
- **结论**：当动作结构很重要时，应先锁证据，让模型探索角色化视觉，而不是把全部运动交给随机生成。
- **结果**：熊猫完成了相对复杂的拳法；动作准确率没有逐帧测量，因此只能证明该输入比纯文字更明确。
- **出处**：视频 02，01:24:43–01:25:24；对应案例池 `c20`。

## A2 — 触发场景（Future Trigger）

### 用户会在什么情境下需要这个 skill？

1. 梦境、奇观、概念广告或世界观镜头既要角色身份稳定，又希望模型提出意外环境、纹理或局部运动。
2. 提示词和 Bible 越写越长，候选都“正确但僵”，团队怀疑约束过多。
3. 生成结果很有惊喜，却经常改变服装、道具状态、叙事事实、品牌标识、轴线或空间关系。
4. 团队争论“导演应该控制多少、AI 应该自由多少”，需要针对变量而非笼统百分比做主权分配。
5. 要为一个镜头、角色、品牌系统或 Agent 任务建立 human approval gate 与允许探索清单。

### 语言信号

- “哪些必须锁死，哪些可以让 AI 自由发挥？”
- “角色不能变，但我想保留一点意外感。”
- “Design an invariant/exploration map for controllable generation.”
- “The output is consistent but dead / surprising but unusable.”
- “给我一个 MUST KEEP / MAY VARY / EXPLORE 的导演控制表。”

### 与相邻 Skill 的区分

- `creative-north-star` 决定项目级不可让渡价值；本 Skill 把它落实为具体任务的不变量、条件变量和探索变量。
- `bounded-explore-select` 执行候选批次的生成、评分和收敛；本 Skill 只定义变量边界和人类批准门。
- `constraint-input-router` 为高风险不变量选择更强证据；本 Skill 只识别哪里必须加强约束。
- `agent-harness-review-loop` 把变量控制权分配给运行时角色并做互审；本 Skill 本身不组织 Agent 团队。

## E — 可执行步骤（Execution）

激活后，agent 必须先输出变量主权表，再允许生成；不得用“50% 控制、50% 自由”替代逐项定义。

### 1. 定义任务、创作意图与失败代价

- 写清本次决策单元：一个镜头、场景、角色、海报、品牌资产或 Agent 任务；列出受众、叙事/业务目的和最终批准人。
- 对可能变化的结果评估两项：`偏离后果` 与 `返工成本`，各分低/中/高。
- **判停条件**：若作品要表达什么尚不明确，先转到 `creative-north-star`；没有批准人时不得自动把惊喜升级为新标准。
- **完成标准**：形成任务卡，包含目的、范围、批准人、偏离后果和返工成本。

### 2. 穷举变量，不要只列提示词字段

至少检查：

- 身份：脸、体型、年龄、物种、Logo、商品特征
- 叙事事实：人物关系、时间、地点、因果、道具状态、损伤与任务结果
- 连续性：服装、轴线、视线、出入口、尺度、动作承接
- 空间/物理：布局、接触、重力、关键光向、真实合成关系
- 表演：姿态、节奏、表情、动作结构、台词意图
- 视觉：构图、机位、景别、色彩、材质、纹理、天气、局部 VFX
- 生产：画幅、时长、品牌/法律限制、交付规格、权限与不可逆动作

- **完成标准**：每个相关变量都有名称、当前来源（Bible/资产/脚本/参考/人工决定）和可观察验收方式。

### 3. 按风险分成三类主权

| 类别 | 判定规则 | 必填字段 |
|---|---|---|
| **I—不变量** | 偏离会破坏身份、叙事、连续性、品牌/法律边界，或返工代价高 | 正确值、证据源、容差、硬验收方式、失败路由 |
| **C—条件变量** | 可在范围内变化，越界可能有价值但需批准 | 允许范围/选项、禁止区、越界触发、批准人 |
| **E—探索变量** | 偏离不伤核心，且可能改善情绪、构图、细节或新颖性 | 探索目的、可变范围、无效/冒犯边界、评价维度 |

- 高后果且高返工成本的变量必须进入 I；信息不足时先按 I 处理，待人确认后再放开。
- **完成标准**：每个变量只属于一个当前类别，I/C/E 无冲突；所有 I 都有可见或可靠数据证据。

### 4. 把主权表转成生成契约

- 按 `MUST KEEP / MAY VARY WITHIN / EXPLORE` 三段写输入，不把三类内容混成一个修辞段落。
- 一轮只选 1–2 个 E 变量作为探索焦点；其他 E 暂时固定，便于归因。
- 对高风险 I，调用 `constraint-input-router` 选择角色资产、状态表、草图、layout、3D、动作参考、实拍 plate 或可靠元数据；仅写摄影数字不能算物理约束。
- **完成标准**：生成契约中的每条要求都能映射回主权表，且不存在“既必须固定又要求自由变化”的矛盾。

### 5. 先过不变量门，再评价惊喜

- 生成有限小批次；对每个候选先逐项检查 I。任何硬不变量失败，直接标记无效，不参与“惊艳度”排名。
- I 全部通过后，再检查 C 是否在允许范围；越界候选单列为“待批准提案”，不能自动入选。
- 最后评价 E：新意是否增强叙事、情绪、可读性或品牌目的，是否只是随机复杂化。
- **完成标准**：每个候选都有 `I: PASS/FAIL`、`C: IN-RANGE/ESCALATE`、`E: 价值证据`，并由具名人类完成最终批准。

### 6. 按失败形态选择下一步

- 若同一 I 在批次中反复失败：停止扩量，升级资产、参考、layout/3D、动作或实拍证据。
- 若 I 全过但 E 没有价值：改探索变量或停止，不通过放松身份/叙事约束制造“惊喜”。
- 若所有结果正确但僵硬：检查是否把低风险变量误列为 I，将其中一项降级为 C/E，并记录批准理由。
- 若候选太多难以选：把通过门检的候选交给 `bounded-explore-select`，本 skill 不继续扩量。
- **完成标准**：输出明确的 `LOCK MORE / RELEASE ONE VARIABLE / CONVERGE / STOP` 决定和证据。

### 7. 把有价值的意外发现提议为新版本

- 对入选惊喜写清：改变了什么、为什么更好、会影响哪些镜头/资产、是否可重复、是否需要回归测试。
- 只有批准人确认后，才能更新 Bible、资产或后续镜头的不变量；保留旧版、变更理由和受影响范围。
- **完成标准**：标准变化有版本号、批准人、回归范围；未经批准的意外发现只保留为候选，不静默扩散。

### 最小输出契约

- 任务卡与失败代价
- I/C/E 变量主权表
- `MUST KEEP / MAY VARY WITHIN / EXPLORE` 生成契约
- 候选的 I/C/E 门检记录
- 人类批准日志
- `LOCK MORE / RELEASE ONE VARIABLE / CONVERGE / STOP` 决定
- 若标准变化：版本化变更提案与回归范围

## B — 边界（Boundary）

### 不要在以下情况使用此 skill

- 任务只有确定性事实答案、合规/安全/财务数据或不可逆操作；这些内容不应设置“惊喜区”。
- 高精度相机匹配、VFX 合成、工程尺寸或真实光照必须物理准确；应使用可靠元数据、测量、layout/3D 和专业验证，本 skill 只能分配风险，不能提供精度证明。
- 已经有几十个候选需要评分和淘汰：转到 `bounded-explore-select`。
- 已形成序列后要定位角色、色光和材质漂移：转到 `cross-shot-consistency-audit`。
- 极小、低风险、一次性任务不值得建立完整主权表时，可只写三行 MUST/MAY/EXPLORE，避免文档过度。

### 课程警告的失败模式

- **全面锁死**：所有候选只能复现参考，每个偏离都视为错误，生成模型退化为昂贵机械执行器。
- **全面放开**：角色、服装、叙事事实、空间和关键动作同时漂移，只剩表面新奇。
- **错误排序**：先被“惊艳”吸引，再忽略身份或连续性失败；正确顺序必须是 I → C → E。
- **静默升级**：一次偶然好结果未经批准就写回 Bible，导致后续镜头标准漂移。

### 讲者盲点与时代局限

- “控制 50%、非控制 50%”不是经过验证的通用配方。品牌法务、角色连续剧、梦境短片和概念探索的比例必然不同。
- AI 提出的局部方案“更好”是人的事后判断，不证明模型理解作品意图，也不保证同一发现可重复。
- 过细 Bible 可能制造文档负担和虚假精确；变量分类应按风险裁剪，而非为了齐全而齐全。
- 提示词中的镜头、焦距、景深和传感器数字只能表达成像意图，不能被当成真实物理不变量的证明。

### 容易混淆的邻近方法论

- “允许探索”不等于放弃导演；导演把主权分域，并负责最后批准。
- “不变量”不是永远不变，而是当前版本、当前范围内未经批准不得变。
- 条件变量不是模糊中间态，必须有允许范围、越界触发和批准人。
- 惊喜只有在服务叙事、情绪或业务目的时才有价值；随机复杂、奇观堆砌和风格偏移不是自动加分。
