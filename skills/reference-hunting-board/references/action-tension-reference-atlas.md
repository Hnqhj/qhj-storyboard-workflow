# Action Tension Reference Atlas

Use this before or alongside web hunting when the user asks for broad action, fight, camera, manga, animation, weapon, or “拉片” references. This is not a list to copy from. It is a routing board for finding reusable action grammar across many future projects.

## What to extract from every reference

For each useful clip, manga page, animation cut, trailer, or game showcase, record:

- `problem solved`: what failure it fixes, such as stiff action, unclear contact, weak scale, cheap effects, flat camera, or boring opening.
- `action structure`: entry, control point, receiver answer, force path, cost/recovery, state change.
- `camera structure`: shot-size sequence, angle logic, cut trigger, foreground obstruction, axis proof, wide/close placement.
- `tension source`: body danger, speed contrast, negative space, silhouette, environment rupture, impact frame, offscreen threat, vertical scale, or sound gap.
- `SD2 role`: identity, style, scene, motion/camera, key pose, first frame, end frame, effect, or mood.
- `do not copy`: identity, costume, IP design, UI, watermark, exact scene, or exact story beat.

## Broad lanes worth hunting

### Manga / panel tension

- **Dragon Ball / Toriyama clarity**: readable silhouettes, force-line clarity, simple geography, one clean state change per impact.
- **SAKAMOTO DAYS**: environment-driven choreography, object rebounds, weapon/prop routing, readable setup-payoff.
- **Kagurabachi**: dark sword silhouettes, negative space, ink-like impact shapes, restrained fantasy energy.
- **Dandadan**: wild supernatural body language, elastic but readable poses, comedic-to-violent rhythm shifts.
- **One Punch Man / Murata**: extreme scale contrast, speed-line perspective, large impact-panel hierarchy.
- **Solo Leveling / vertical webtoon action**: vertical momentum, air-chain escalation, hero entrance and finishing-pose readability.
- **Gachiakuta**: rough texture, aggressive silhouettes, gritty object/weapon personality.

### Animation / sakuga / stylized CG

- **Trigger / Imaishi**: explosive entry, impossible-but-readable momentum, graphic smears, large pose hierarchy.
- **Masami Obari**: heroic foreshortened impact poses, big weapon/limb perspective, decisive silhouette.
- **Fortiche / Arcane**: 3D thick-paint material, strong key light, hand-painted surface breakup, cinematic facial/body weight.
- **ufotable action compositing**: clean effects integration, controlled glow, readable body under energy.
- **Monty Oum / early RWBY grammar**: continuous combo routing, air juggling, weapon identity, readable camera chasing the move.

### Games / character-action showcases

- **Devil May Cry / Bayonetta**: launcher → air route → finisher, stylish cancel rhythm, weapon personality.
- **Sifu**: center-line pressure, parry/redirect clarity, environmental collision, readable exchange.
- **Sekiro / Ghost of Tsushima / Rurouni Kenshin live-action sword grammar**: blade-line intent, footwork, committed attacks, recovery cost.
- **Zenless Zone Zero / Punishing Gray Raven / Wuthering Waves showcases**: stylized character ability rhythm, hard pose accents, clean VFX ownership, air/ground alternation.

### Live-action combat logic

- **Jackie Chan / Hong Kong prop action**: geography clarity, object cause-effect, pain/recovery comedy, no fake contact.
- **The Raid / Ong-Bak / Muay Boran**: close-range pressure, knees/elbows/clinch, body cost, cramped environment stress.
- **John Wick**: wide readable body relation, weapon-control chain, reload/grapple consequences.
- **Bourne / shaky pressure**: use sparingly for panic and proximity, never when contact proof is more important.

## Prompt-routing rule

If the model keeps producing random variants, stop adding adjectives. Build a reference package instead:

1. identity reference;
2. visual style / material reference;
3. scene reference;
4. first frame or key pose reference;
5. motion/camera reference with a role and time range;
6. end frame or result-state reference.

Then keep the text prompt as glue: roles, forbidden copying, required state changes, and camera proof points.
