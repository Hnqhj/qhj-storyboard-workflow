# Exchange Response Logic

Read this reference when a close fight, weapon bind, clinch, or partner exchange suffers from repeated clean dodges, instant guard resets, random limb motion, stalled control, or turn-taking. It owns response escalation and short-exchange role clarity. Rhythm density remains with `$action-rhythm-editing`; recurring character style remains with `$character-continuity-bible`.

## 1. Escalate The Answer With Pressure

Choose a response from the current distance, attack line, available space, prior guard state, and character grammar. Do not rotate through defenses by quota.

```text
open space / first readable threat
-> evade, step off line, deflect, or intercept may remain credible

pressure closes / follow-up occupies the exit
-> use a contact answer: frame, jam, parry, bind, brace, redirect, body angle, or supported disengagement

guard or support is disrupted
-> show a compromised answer or recovery cost before a clean guard returns

space is recovered
-> reframe, regrip, regain support, disengage, or counter from the recovered state
```

The rule is not “the first action must be dodged” or “the second must be blocked.” The rule is that continued pressure removes options. A receiver cannot repeat the same effortless evasion when the route, distance, or support no longer allows it.

### Guard-State Memory

Track only the state that constrains the next answer:

```text
organized: support and defensive line are available
opened: a line, grip, weapon position, or base has been displaced
scrambling: only a partial answer is available while support or guard is rebuilt
recovered: a visible step, brace, regrip, frame, or disengagement restores options
```

Do not assign universal recovery seconds. Show the recovery source. If the guard was opened, the next beat must use that opening, show a compromised response, or visibly restore the guard; it must not silently reset.

## 2. Assign Active And Support Roles

For a dense exchange, give visible channels temporary jobs:

```text
active channel: attacks, intercepts, presses, or changes the line
support channel: guards, frames, controls, balances, regrips, or prepares the next action
base: feet, planted limb, wall, floor, partner, or weapon contact that carries load
route: where pressure and both centers are traveling
```

The active and support jobs may switch after contact. This creates readable alternation without forcing a fixed left-right recipe. Name left/right, lead/rear, weapon/off-hand, or upper/lower only when that distinction prevents ambiguity and the framing can prove it.

Bad compression:

```text
both fighters exchange rapid hand attacks
```

Better causal compression:

```text
Her lead hand redirects the incoming line while the rear hand stays between both bodies; as the first hand pins the forearm outward, the guarded hand becomes the short counter and the former attacking hand returns to cover.
```

For two-handed weapons, shields, grappling, or floor support, translate the same principle into grip, frame, anchor, balance, or regrip roles rather than inventing extra strikes.

## 3. Convert Control Instead Of Parking On It

A grip, bind, frame, pin, catch, or support point is a temporary state-change tool. It should do at least one visible job:

- remove or redirect an attack line;
- change angle, balance, support, grip, route, or initiative;
- create a safe fictional opening for the next choreographed action;
- enable a release, throw-like displacement, disengagement, objective action, or recovery.

Then convert or release it:

```text
control becomes visible
-> receiver or route changes
-> next action uses that change
-> grip/frame releases, transfers, or becomes a new constraint
```

Do not prescribe a universal micro-duration. Reject a control only when nothing changes, both performers freeze around it, or the next action ignores it.

## 4. Prompt Translation

Keep the analysis internal. Write a natural action chain:

```text
The first threat passes as he steps off its line, but the follow-up closes the exit. He catches it on his forearm instead of slipping again; the impact opens his guard and forces a short recovery step. His free hand frames the space while the loaded foot settles, then that frame becomes the counter that restores distance.
```

Prompt-facing checklist:

```text
current distance and available exit:
receiver's prior guard/support state:
active channel and support channel:
contact answer or credible evasion:
state cost:
control conversion or visible recovery:
new distance / line / balance / initiative:
```

## Quality Gate

- The response is possible from the current range, line, space, and support.
- Continued pressure removes or changes options instead of permitting repeated clean resets.
- A disrupted guard remains disrupted until a visible action restores it.
- Active and support channels have legible jobs; they may switch without becoming random motion.
- Every control point changes a relation and is converted, transferred, or released.
- The final prompt contains natural action causality, not internal state labels or fixed quotas.
