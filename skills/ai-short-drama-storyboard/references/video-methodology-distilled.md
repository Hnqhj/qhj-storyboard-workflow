## 1. 九模块映射

不要机械输出九个标题；把信息映射到现有字段：

| 方法论模块 | 当前技能字段 | 必要内容 |
|---|---|---|
| 场景 | 场景/构图/视觉调性 | 时间、空间、前中后景、可重复背景物、天气、主光 |
| 人物 | 角色艾特/角色状态 | 角色ID、当前表情、视线、姿态；固定外观由参考图锁定 |
| 站位 | 构图/内容描述/人物动作 | 左右、前后、朝向、距离、移动路径和落点 |
| 光线 | 视觉调性/内容描述 | 光源方向、冷暖、对比和跨镜连续性 |
| 镜头 | 景别/镜头运动/摄影机 | 一个主景别和一个主运镜；动态动作可拆相邻镜头 |
| 时长 | 时长 | 按动作、信息、台词和结尾停留独立判断，不强制15秒 |
| 镜头序列 | 分镜时间轴 | 起始状态、动作过程、末帧和下一镜承接 |
| 核心情绪 | 内容描述/人物动作 | 2—4个可见情绪词及其行为证据 |
| 负面约束 | NEGATIVE_PROMPT | 只保留本镜特有失败风险 |

## 2. 场景与参考图

- 场景卡先锁：时间、空间布局、前景/中景/背景纵深、两件可重复物、天气和主光方向。颜色可用自然语言；只有需要严格统一时才附色号。
- 参考图必须标注作用：场景图只锁空间/灯光，人物图只锁脸/发型/服装，道具图只锁材质/状态。没有提供的参考项不得假设为已锁定。
- 用户说不使用某张参考图时，完全停止从该图提取站位和人物；可以继续使用文字设定或其他被允许的参考图。
- 画面文字、标牌和屏幕默认不可读；用户明确要求的日期、台词牌或剧情道具文字属于画内信息，单独锁定字面内容。

## 3. 情绪与动作

### 情绪链

```text
触发事件 → 第一反应 → 压抑/升级 → 可见爆点 → 余波/新状态
```

每镜最多一个主情绪和一个次情绪。用视线、呼吸、停顿、下颌、肩背、手指、重心、距离或已有道具表达，不用“非常震惊/很悲伤”代替表演。

### 动作链

```text
首帧状态 → 触发 → 发力部位 → 路径 → 接触/位移 → 受力与环境反馈 → 末帧
```

动作提示词必须让模型知道动作如何发生，不把“冲过去、打倒、瞬移、快速结印”当作完整动作。跨镜时下一镜首帧应处于前镜动作中段或即时后果。

### 高速与特效动作

把高速动作至少拆成：启动、持续路径、接触/减速、结果。特效用以下句式编译：

```text
特效来源 → 可见形态 → 运动方向/速度 → 对人物与环境的影响 → 衰减或结束
```

例如：灵力从脚底和肩背汇聚 → 形成贴体金色光丝与粒子 → 沿运动方向拉伸 → 掀动衣摆、产生空气折射和地面反光 → 光丝断裂为粒子消散。避免只写“高级特效、电影级金光、漂亮拖尾”。若用户不想要人形残影，禁止复制完整脸、手、腿，只保留局部轮廓、光带或粒子。

## 4. 摄影与节奏

- 一镜只选一个主运镜。固定机位适合事实、对话和压迫；跟拍、甩镜、环绕、拉远和速度变化只在用户需要动态或动作时使用。
- 改变机位、景别或主体优先级就拆成相邻镜头；连续推近/跟随/环绕可保持同一镜，但必须写清触发时间和结束状态。
- 短片前1—2秒给可见钩子；建立空间、位置变化和调度时优先使用全景/中景，常规对白优先中景或近景（腰部以上）；特写只在强烈动作/能力展示、决定性眼神、关键受力或不可替代的道具证据处使用。所有推镜头尽量停在上半身、手部、道具或双人关系构图，不直接推到人脸；动作路径必须回到能看清接触关系的中景或全景。
- 不用规律化时长填满分组。时长由唯一信息、动作路径、台词净时长、反馈和停留决定；分组上限是生产约束，不是节奏模板。

## 5. 对话表演与镜头承接

- 中文台词语速约束：普通对白控制在2.8—3.2字/秒，平均按3字/秒估算；低声、克制或停顿多控制在2—3字/秒，平均按2.5字/秒估算。急促争执或短促命令可短暂提高到3.5—4字/秒，但不得连续长句使用。台词净时长与动作缓冲分开估算，快节奏通过剪辑和动作密度实现，不抢读。
- VO/OS 标注“嘴唇紧闭”或“嘴唇不动”，并写声音速度、情绪和是否混响。后期配音不等于必须逐字口型同步；超过镜头承载时，明确跨镜延续或改为VO，不抢读原文。
- 先锁定对话关系资产：说话者/倾听者、屏幕左右、共同朝向、相互距离、共享支撑物或正在共同进行的活动。安静聊天不必让人物面对面；同向看景、并肩行走或共同操作道具都可成立。
- 把台词按语义停顿拆成表演节拍；每段只绑定一个可见信号，例如吸气后开口、说到关键词时停手、句尾弹落烟灰。倾听者使用延迟吸气、停住的手、视线变化、重心交换或一次轻微点头回应，不要让双方动作镜像同步。
- 每镜后台记录：`首帧承接 → 台词/动作变化 → 结束状态 → 承接信号`。承接信号从动作/手部、视线、道具、同方向背景运动、声音、遮挡或光线中选一项；下一镜第一句必须接住该信号。
- 硬切不是承接失败。只要前镜末帧与后镜首帧在姿态、朝向、道具和环境状态上连续，并有明确的动作、视线、声音或背景运动触发，就可以硬切。没有新信息、反应或状态变化时不要切镜。

## 6. 材质、声音与稳定约束

- 视觉调性写成可验证的材质响应：粗糙混凝土如何反光、锈蚀金属如何受侧逆光、潮湿衣料如何贴合和起褶、薄烟如何被横风拉开。不要只写“克制都市电影感”。
- 环境也维护状态账本：天气、湿度、主光方向、风向、烟雾/尘土路径、水迹、远处移动灯光及其方向。它们既提供空间连续性，也可以成为切镜承接信号。
- 声音按对白/呼吸、动作细声、场景环境、音乐四层排列；先保证对白和现场声清楚。需要声音承接时写明声源从上一镜延续到下一镜；音乐标明进入点和退出点，默认在对白后或情绪落点处轻微出现。
- 正向稳定约束先写必须保持的事实，例如“同一段护栏、左侧说话者、右侧倾听者、两人共同面向城市、风向向左”。负面提示只补充最可能的失败，例如身份漂移、换手、换位或烟雾逆风。
- 内部可以维护完整资产卡、状态账本和承接链；前台提示词按用户要求合并重复信息。紧凑输出不是删除状态，而是把组级不变项写一次，把镜头级变化写在对应时间段。

### 精细导演稿五段式（按需）

当用户要“完整、精细、电影化”而未锁定 Seedance V1.1 前台格式时，可按以下顺序组织：

```text
角色/资产锁定：角色外观、屏幕关系、共同活动、道具和禁变项。
视觉材质总控：时间天气、前中后景、主光、风向，以及皮肤/衣料/金属/烟雾等材质响应。
事件节拍：按时间窗写每个镜头的首帧、唯一变化、台词/微表演、末帧和承接信号。
声音：对白与呼吸、动作细声、环境层、音乐进入/退出点。
正向稳定约束：用肯定句锁定关系、站位、道具、光线、风向和背景运动；负面词只列当前失败风险。
```

每个事件节拍至少包含“结束状态”；下一节拍必须复现该状态或明确从动作中段接入。若用户要求紧凑输出，把前两段合并为组级前置，把声音和正向约束压缩到每组末尾。

## 7. 负面词与质量检查

按风险选择8—18个词：

- 身份/服装：`face morphing, identity drift, age change, wardrobe change`
- 人体/动作：`extra fingers, fused hands, extra limbs, broken hands`
- 摄影/生成：`flicker, focus pumping, duplicate frames, abrupt scene change`
- 画面/文字：`subtitles, watermark, logo, readable text`
- 风格：仅在模型跑偏时加入 `anime, cartoon, 3d render, illustration`

交付前检查：参考图作用是否越界；人物关系资产、人物/道具/环境状态是否首末帧连续；动作是否写出过程和后果；台词是否与表演节拍对齐；每次切镜是否有承接信号；特效是否说明来源、路径、互动和衰减；声音层级是否清楚；是否把不必要的元数据或重复负面词塞进最终提示词。

## 8. 创意对齐与偏好账本

新剧本开始时，先把剧情事实与可选择的导演决策分开。剧情事实不可作为选项改写；只让用户选择会影响视觉结果的内容。

### 选择题生成规则

- 先在后台形成一个推荐方案，再生成两个真正不同的替代方案。差异必须能在成片中被看见，例如镜头信息顺序、主体优先级、摄影机路径、特效强度或节奏落点。
- 镜头结构选项必须写到“先看什么 → 再看什么 → 最后停在哪里”，不要只写“方案A电影感、方案B高级感”。
- 摄影策略选项写清主要运镜及代价，例如固定剪辑稳定但空间冲击较弱；环绕能突出规模但对人物和背景一致性要求更高。
- 特效选项必须说明来源、覆盖范围和强度；现实题材默认推荐无特效或克制特效，修仙/奇幻题材可推荐影视级特效。
- 已由剧本、参考图或用户历史选择确定的内容不再询问。每轮最多3题，避免把时长、画幅、参考图、音频、景别、运镜、色调和特效全部同时抛给用户。

### 偏好账本

在当前任务中维护以下后台记录：

```text
模型/平台：
画幅与默认时长：
输出长度：紧凑 / 完整工程格式
镜头节奏与景别倾向：
运镜偏好：
特效强度、颜色和禁用项：
参考图及各自作用：
对白：原生口型 / 后期配音 / VO/OS
已确认的本场方案：
```

用户说“沿用上一段”时直接读取账本；用户只修改一项时更新该项，不清空其他选择。新选择与旧偏好冲突时，只询问冲突项。

### 何时直接执行

用户说“按推荐执行”时，采用每题第一项并生成正式提示词；用户说“直接生成”时，根据剧本选择推荐方案并在最终提示词内落实，不再展示选择题。精确修改单镜、补负面词、改时长或改参考图用途时直接修订，不重新启动整套选择流程。
