# QHJ 拆分镜工作流

这是一个带确认门的剧本转镜头组工作流。目标是把剧本片段转换为可执行、可复制、可生成的视频镜头组，同时让用户清楚知道将消耗哪些技能和处理步骤。

## 1. 双轴输入

每次收到新的剧本、剧本片段、续写片段或重复输入时，先读取或确认两个运行参数：

- **工作流完整度**：快速 / 标准 / 完整
- **提示词复杂度**：低 / 中 / 高

工作流完整度控制后台技能范围；提示词复杂度控制镜头描述、时间轴、`T=`微节拍和约束的详细程度。两者不可混为一个参数。

## 2. 强制确认门

完成初步路由后，必须暂停执行，向用户展示一份执行方案，至少包含：

- 判定的工作流完整度和提示词复杂度；
- 复杂度、动作、VFX、人数、对白、连续性等判定依据；
- 将实际加载或调用的全部技能；
- 唯一平台编译器和预检工具；
- 预计输出内容；
- 明确排除的技能及排除理由。

必须等待用户确认后，才能加载后续技能、调用编译器、运行预检或生成最终镜头组提示词。用户修改任一参数时，重新计算方案并再次确认。顶部技能活动必须与确认后的实际调用清单一致；没有实际调用的技能不得声称已调用。

## 3. 深度路由

### 快速

仅用于单一地点、低风险、最多两名主要表演者、简单对白或非接触动作，且无复杂连续性、战斗、追逐、武器接触、VFX、变身、破坏或输出复盘。

### 标准

用于普通完整剧本、多人对白、情绪戏、中等连续性要求，或风险尚未证明足够低的任务。重点处理故事信息、空间关系、镜头组和对白可执行性。

### 完整

只要出现以下任一项就升级：

- 打斗、追逐、武器或身体接触；
- 三名以上有意义的同时表演者或复杂群体调度；
- 能量、法术、变身、破坏、飞行、击飞等 VFX；
- 高强度情绪、关系对白或表演方向；
- 多组参考、角色身份风险、跨镜头连续性；
- 生成结果复盘、重试、平台限制或正式交付要求。

完整流程只调用被风险触发的专业技能，不盲目加载所有技能。

## 4. 技能组职责

### 路由与治理

`script-camera-group-router`、`ai-video-production-governance`、`entity-continuity-system`、`character-continuity-bible`。

负责深度选择、权限边界、实体锁定和连续性状态。

### 叙事与镜头结构

`shot-information-progression`、`master-shot-camera-planning`、`cinematic-audiovisual-language`、`narrative-camera-groups`。

其中 `narrative-camera-groups` 是唯一的镜头组边界和最终提示词结构 Owner。

### 动作与节奏

`action-choreography-reference`、`action-rhythm-editing`、`seedance-fight-director`、`seedance-motion`、`seedance-camera`。

负责起势、接触、受力、结果、重心、惯性、收势、动作节拍和切镜触发。

### VFX、材质与表演

`cinematic-vfx-director`、`vfx-effect-construction-engine`、`seedance-vfx`、`ai-material-realism`、`emotional-performance-direction`。

只输出对应字段、约束或补丁，不重写另一份完整提示词。

### 平台编译与预检

选择一个平台编译器，例如 `seedance-20` 或 `jimeng-sd2-prompting`，并选择匹配的预检技能。平台编译器只调用一次；预检只返回问题或字段补丁，不重写全文。

## 5. 镜头组规则

- 同一地点、同一时间、同一空间布局和连续动作线默认归为一个镜头组。
- 对白换人、景别变化、反应镜头和动作峰值属于组内镜头，不自动新建镜头组。
- 只有换场、明确时间跳跃、封闭交接或平台时长限制才拆分。
- 每组先输出人类可读镜头表，再输出一份独立完整的六段式提示词。
- 六段固定为：角色/资产锁定、视觉材质总控、镜头语言总控、事件节拍、声音、正向稳定约束。
- 高复杂度提示词的事件节拍必须使用 `镜头01｜起始-结束s` 和连续的 `T=起始-结束s` 微节拍。

## 6. 唯一 Owner 与状态传递

专业技能只提供结构化字段、约束、风险说明或补丁。`narrative-camera-groups` 汇总最终 CameraGroupPlan；平台编译器将其转换为唯一模型可用文本；预检不得创作第二份完整提示词。向下游传递 ShotLedger、CameraGroupPlan、连续性和资产增量，不重复传递整段历史。

## 7. 完成条件

只有在以下条件全部满足后，才报告完成：

- 用户已确认执行方案；
- 每个镜头组有连续时长、镜头表和独立六段式提示词；
- 台词完整，动作因果清楚，角色与空间连续；
- 每组有唯一平台编译结果；
- 匹配的预检已通过，或已明确列出问题和字段补丁；
- 顶部技能活动与实际调用清单一致。
