# Capability Map

## Full-strength lanes inside this package

- short-form directing and beat design;
- storyboard, shot function, camera grammar, tension, and coverage;
- action choreography, rhythm, weapon/body physics, and fight prompting;
- VFX construction, magic/energy/destruction logic, and Seedance VFX compilation;
- visual style, named anchors, materials, lighting, texture, and clean rendering;
- character/entity continuity and cross-shot audit;
- world/production design and visual-world exploration;
- performance direction, sound design, Seedance audio, 即梦 SD2 and Seedance prompting;
- output review, mechanism-level failure diagnosis, and targeted iteration.

## Intentionally omitted from the portable 70-percent profile

- private Sophia memory, casebook, ledger, capsule, semantic recall, and automations;
- browser/desktop control, accounts, credentials, and local machine configuration;
- generation/download archive watchers and project-specific file routing;
- Blender, mocap, whitebox previs, and editing-software control;
- full writers-room development, novel transcription, commercial conversion strategy, and niche emotional micro-directors;
- one-project style packs and machine-specific personal presets.

The package keeps the main director-to-prompt chain complete while removing private infrastructure and heavy execution adapters.
