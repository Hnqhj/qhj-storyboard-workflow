# Mandatory Stack

Use this file only when selecting the stack for a substantial film or AI-video task.

First let `script-camera-group-router` create `ExecutionPlan`, then apply
`adaptive-depth-routing.md`. A low-risk `fast` task is not required
to load every separate baseline owner: one fused planning pass may apply the
same camera, material, sound, packaging, and mechanical-QC contracts. `standard`
uses `camera-group-director-standard` for one fused planning pass; only `full`
loads the separate baseline owners below. Processing depth never reduces the
visible camera-group or prompt specification.

## Always Covered

1. Governance: authority, input scope, delivery contract, capacity, asset state,
   and current handoff through `$ai-video-production-governance`.
2. Directorial job and one dominant goal.
3. Story/beat structure when more than one event occurs.
4. Shot function, geography, camera proof, and edit reason.
5. Material/light/grounding behavior.
6. Sound events and hierarchy.
7. One selected platform compiler with `compile_count=1`.
8. One matching preflight profile: fast, standard, or full. It returns findings
   or field patches and never rewrites the complete prompt.

## Conditional Layers

- Continuity: recurring identities, assets, transformations, sequences.
- Action: contact, force, rhythm, weapon/body mechanics.
- VFX: effect lifecycle, ownership, response, decay.
- Performance: readable emotion and micro-performance.
- Worldbuilding: culture, architecture, production design, spatial perspective.
- Review: generated output exists and needs diagnosis.

Use one owner per layer. Compress duplicate advice before drafting the final artifact.
When research is triggered, use one `creative-research-first` run and reuse its
`ResearchReceipt` across every downstream layer.
