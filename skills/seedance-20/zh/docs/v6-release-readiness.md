# V6 发布就绪度

在合并前检查有效首页时使用本文档。

## 当前发布表面

- README 徽章、更新行、变更日志指针、eval 元数据、验证器期望值、范例和有效技能元数据都必须显示 `6.1.0`。
- 有效文档应描述 v6 序列状态架构、提示词编译器行为和多语言读者路径。
- 历史版本细节应归入较旧的 `CHANGELOG.md` 条目、`references/migrated/` 或 Git 历史，而非有效的 README 表面。

## 首页检查

- README 有一个面向英语、中文、日文和韩文读者的可见母语起步章节。
- README 链接到完整的母语读者指南：`docs/README.zh.md`、`docs/README.ja.md` 和 `docs/README.ko.md`。
- 中文、日文和韩文行链接到有效的技能文件和有效的词汇参考。
- 日文和韩文拥有有效的范例技能，而不仅仅是词汇技能。
- 旧的规划文档不再属于有效文档目录的一部分。
- 设计文档描述当前的 v6 首页要求。

## 验证

在发布一个版本或合并一次首页更新之前，从 README 运行仓库验证套件。
