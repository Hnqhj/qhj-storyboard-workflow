# seedance-troubleshoot

若这一条镜头是部分可用而非彻底失败，先路由到 `[ref:retake-protocol]` 分诊——大多数镜头应得到一个裁决，而非一次重写。先诊断失败再重写。不要只是堆更多形容词。识别失败是来自模式不匹配、过载、含糊、脆弱身份、不安全措辞、不受支持的平台行为，还是缺失的保留约束。

当诊断树中没有对应该失败的行时，加载 `[ref:model-mechanics]` 并按机制诊断：注意力稀释、先验冲突、被召唤的否定、轨迹断裂、误差累积、条件冲突、容量饥饿，或过载的音视频联合约束。当失败涉及续接、剪辑/延展、源片段、音频参考或平台特有错误时，加载 `[ref:field-observed-tips]`、`[ref:reference-workflow]` 和 `[ref:api-workflow]`。多镜头漂移加载 `[ref:shot-list-continuity]`，终端客户或交付失败加载 `[ref:delivery-qc]`。当存在序列状态时，加载 `[ref:failure-atlas]`、`[ref:continuation-handoff]` 和 `[ref:continuity-qc]`；对照连续性锁定项、已完成节拍、精确的引用标签和预留的未来节拍进行诊断。

## 意图

一次失败的生成让人感到很私人——用户把自己的想法展示给机器，机器却返回了某个坏掉的东西。本技能的灵魂，是不带指责的救援：点名机制，绝不点名用户；拯救想法，而不只是提示词。他们应当带着一个修复方案和完好无损的信心离开。

## 诊断树

| 症状 | 可能原因 | 首要修复 |
|---|---|---|
| 产品或面孔改变 | I2V 提示词重述了可见身份或运动过载。 | 添加保留约束；移除重复的静态细节。 |
| 相机跳变 | 多个不兼容的运动或没有终点。 | 选择一个有起点和终点的运动。 |
| 输出泛泛 | 空洞的风格词和软弱的动作。 | 替换为物理动作、源光、材质和声音。 |
| 运动被忽略 | 静态提示词或没有可见后果。 | 添加施动者、动词、定时和改变后的末态。 |
| 对口型差 | 移动的头/相机、过长的对白、未分配的说话者。 | 锁定取景，缩短台词，分配说话者。 |
| 视效嘈杂 | 效果没有来源、物理或消散。 | 添加来源、材质、路径、相互作用和终点。 |
| 提示词被拦截 | 受保护 IP、真实人物、露骨内容或类绕过的措辞。 | 用安全的制作语言重写意图，不要规避。 |
| 延展质量退化 | 没有末帧锚点，或续接间引入太多新变量。 | 用返回的末帧作首帧，并只改变一个变量。 |
| 音频参考被忽略 | 相互竞争的视频声音、没有视觉节拍映射，或不受支持的组合。 | 静音相互竞争的视频，并把一个可见事件映射到节拍。 |
| 文字/徽标损坏 | 要求小文字移动或被重绘。 | 让文字保持静态、居中、受保护；在其周围动态打光。 |
| 客户 QC 失败 | 把提示词输出当作最终交付，未经后期/QC。 | 路由到交付预检、后期修复，或只重新生成出问题的那个镜头。 |
| 续接假定了计划中的结尾 | 前一段镜头未被审阅，或 observed_end_state 被忽略。 | 用实际已观察到的末态替换开场。 |
| 前一动作被重启 | 已完成节拍未被标记 already_happened。 | 添加已完成节拍的排除项。 |
| 未来节拍泄露 | 预留节拍进入了当前提示词。 | 移除未来节拍并更早收尾。 |
| 身份参考与连续性来源冲突 | 源片段同时控制了瞬时状态和身份。 | 从正典参考重新锚定身份。 |
| 画面方向重置 | 轴线关系未被锁定或被有意重置。 | 保留画面方向或声明新镜头的轴线重置。 |
| 未完成的运动丢失 | 主体或相机矢量未被继承。 | 把运动矢量带入开场句。 |
| 相机阶段被重启 | 父镜头的相机终点未被记录。 | 从已观察到的相机阶段起始。 |
| 道具状态矛盾 | 缺失所有者、位置或状态。 | 添加道具状态交接。 |
| 音频阶段被重启 | 已完成的对白或音乐阶段未被记录。 | 续接或有意改变音频阶段。 |

## 修复流程

首先引用出问题的短语或缺失的元素。然后点名根因。接着，移除冲突而非增加复杂度。推荐一个主要修复变量，而非添加更多形容词。最后，产出一条保守的重试提示词，仅当用户想要探索时再产出一条可选的创意变体。

## 保守重试范式

`[Reference role if any]. Preserve [identity/product/environment] exactly. One visible action: [specific verb and consequence]. Camera: [single move]. Lighting: [physical source]. Sound: [ambient/SFX/dialogue]. Constraints: [what must not change].`

## 升级规则

若同一错误反复出现，把场景拆成更短的镜头、减少角色、简化手或面部运动、使用更强的参考角色映射，或更换模式。对于不稳定的文字/徽标，让它们保持静态、居中、受保护；不要要求模型在运动中重绘小文字。

对于剪辑/延展失败，先保留源片段，只改变出问题的那一层。若某界面支持返回末帧，在延展前先把那一静帧用作下一个首帧锚点。

## 输出契约

返回根因、来自提示词或结果的证据、修复后的提示词，以及一条保守的重试变体。
