# 摄影镜头语言

当用户需要导演/摄影指导级的镜头设计，而非泛泛的电影形容词时，使用本参考。

## 镜头契约

每个专业镜头都应声明：

| 字段 | 提示词决策 |
|---|---|
| 景别 | 大远景、远景、中远景、中景、中近景、近景、特写、微距 |
| 角度 | 平视、仰角、俯角、顶拍、侧面、过肩、插入镜头、产品四分之三 |
| 镜头感 | 广角空间张力、自然 35mm 透视、人像压缩、微距材质细节 |
| 相机支撑 | 锁定机位、手持、滑轨、推轨、摇臂、无人机、稳定器、虚拟产品台 |
| 运动 | 推进、拉远、横向跟踪、环绕、横摇、俯仰、升降、摇臂上升、揭示、变焦对焦 |
| 主体关系 | 相机跟随、引领、发现、保持、观察主体，或与主体形成阻挡 |
| 起始帧 | 第一个可读构图 |
| 结束帧 | 改变后的状态、姿势、揭示、产品英雄镜头，或连续性交接 |
| 脆弱锚点 | 面孔、手、徽标、文字、产品形状、服装、道具位置 |

提示词范式：

`Shot: [size/angle/lens feel]. Camera starts [composition], [one movement] at [speed] while [subject action], ending on [clear endpoint]. Preserve [fragile anchors].`

## 景别用法

| 景别 | 用于 | Seedance 注意 |
|---|---|---|
| 大远景 | 规模、到达、环境 | 小面孔/徽标会漂移；不要要求面部表演 |
| 远景 | 走位、舞蹈、运动、环境中的产品 | 让动作保持简单可读 |
| 中景 | 对白、产品使用、交接 | 角色商业广告的好默认值 |
| 近景 | 情绪、质感、对口型、产品细节 | 让相机稳定、动作小 |
| 微距 | 材质、食物、珠宝、机械 | 避免大幅运动和文字重绘 |

## 相机运动语法

- **锁定机位：** 用于对口型、产品身份、文字、徽标、精确视效和连续性锚点。
- **推轨/推进：** 用于发现、领悟、亲密感、产品揭示。
- **横向跟踪：** 用于行进、队列、编排、掠过的前景层。
- **环绕：** 用于产品英雄镜头和雕塑般的主体；若身份必须仅从一个角度保持稳定则避免。
- **摇臂/无人机：** 用于规模、到达、地理、揭示；对白或微小产品文字时避免。
- **手持：** 用于真实感或紧张；当身份重要时让运动保持细微。
- **变焦对焦：** 用于在两个锚定物体间转移注意力；避免与复杂相机运动叠加。

## 走位与覆盖镜头

对于多镜头场景，让相机语法保持有动机：

1. 确立地理和画面方向。
2. 转向角色/产品动作。
3. 仅当细节改变故事时才使用近景细节。
4. 让每段片段以一个能成为下一个首帧参考的画框结束。

覆盖镜头范式：

`Shot 1 wide establishes [space/screen direction]. Shot 2 medium follows [action]. Shot 3 close-up reveals [consequence]. Continuity: same wardrobe, prop, light direction, and eyeline.`

## 专业回避清单

避免：`cinematic camera`、`dynamic shot`、`epic zoom`、`film look`、`Hollywood style`、`beautiful composition`——在没有物理镜头选择的情况下。

替换为：景别、支撑、运动、主体关系、有动机的光线、终点和脆弱锚点。
