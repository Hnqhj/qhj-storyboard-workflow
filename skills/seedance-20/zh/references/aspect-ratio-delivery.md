# 画幅比与交付界面

在规划专业取景、社交剪短版、广播/网页交付物、DCP/院线取景或营销活动版本时，使用本参考。

## 把创意画框与交付容器分开

| 层 | 决策 |
|---|---|
| 创意画幅比 | 镜头为之设计的构图：16:9、9:16、1:1、4:5、1.85、2.39 |
| 平台或容器 | 网页、广播、DCP、IMF、社交、演示、路演稿 |
| 安全区 | 面孔、产品、字幕和徽标必须保持可读之处 |
| 重构图计划 | 裁切、上下黑边、左右黑边、备选渲染，或剪辑专属版本 |
| 文字政策 | 画面内文字通常应在后期添加，而非生成进运动中 |

## 常见画幅比

| 画幅比 | 用途 | 提示词建议 |
|---|---|---|
| 16:9 | 网页、广播、演示、横向营销活动 | 电影化场景工作的最强默认值 |
| 9:16 | 竖屏社交、移动广告 | 让核心主体居中；避免边缘关键动作 |
| 1:1 | 社交宫格、产品循环 | 对称的产品取景效果好 |
| 4:5 | 社交信息流广告 | 留出头顶空间和字幕空间 |
| 1.85 | 院线/叙事现代画框 | 为横向叙事构图，而非竖直的产品文字 |
| 2.39 | 宽银幕剧情、高端广告 | 保护面孔/产品不至于太小 |

## 营销活动版本矩阵

| 版本 | 用途 | 规划说明 |
|---|---|---|
| 30 秒主版 | 完整故事 | 更多镜头、完整弧线、最强的品牌/产品佐证 |
| 15 秒剪短版 | 付费社交/广播 | 保留钩子、产品佐证、末态 |
| 10 秒插播 | 唤起记忆 | 一个动作节拍和最终产品或标题卡 |
| 6 秒插播 | 快速投放 | 一个视觉笑点/揭示/产品节拍 |
| 9:16 竖屏 | 移动 | 居中动作、避免大范围地理、字幕置于下三分之一 |
| 1:1 或 4:5 | 信息流 | 产品和面孔无须边缘细节即可读 |
| 无字版 | 本地化/视效 | 无烧入文案、无字幕、无尾卡文字 |

## 提示词取景规则

- 尽早陈述目标画幅比和构图目标。
- 当需要多种裁切时，让面孔、产品和徽标远离画框边缘。
- 对于竖屏版本，简化相机运动并避免快速横向动作出框。
- 对于 2.39 或非常宽的画框，让核心主体足够大以经受生成和审阅。
- 对于标题卡、产品图、字幕和法律文字，优先用干净的视觉版面加后期添加的排版。

## 交付注意事项

在最终导出前始终验证当前的平台、买方、广播商、电影节或广告网络规格。本技能可以规划画幅比与裁切策略，但合同规格才是母版的决定者。
