# 交付与质检（Delivery And QC）

当输出需要审核、交付给客户、准备平台上传、本地化、归档，或作为专业商业活动的一部分交付时，使用本参考文档。

## 交付前检查（Delivery Preflight）

| 领域 | 检查项 |
|---|---|
| 画面 | 帧率、分辨率、宽高比、裁切、安全区、防抖、闪烁、条带（banding） |
| 色彩 | 工作色彩空间、调色说明、HDR/SDR 目标、产品/品牌色、必要时的合法范围 |
| 音频 | 同步、响度、真峰值、对白清晰度、分轨（stems）、M&E（音乐与效果轨）、需保留处的静音 |
| 文字 | 字幕、外挂字幕、强制叙事字幕、屏幕文案、标题安全区摆放 |
| 连续性 | 服装、道具、画面运动方向、产品朝向、光线方向、尾帧衔接 |
| 版权 | 参考素材、音乐、配音、肖像权、产品/品牌授权、素材库授权 |
| 元数据 | 任务 ID、模型/平台、提示词版本、可用时的种子/设置、来源 URL、审批负责人 |
| 版本管理 | 主版本、剪短版、竖版、方版、无字版、本地化版、归档版 |
| 人工质检 | 以正常速度观看全部输出，并在脆弱帧处暂停检查 |

## 命名规则（Naming Pattern）

使用一致的命名：

`PROJECT_CAMPAIGN_VERSION_RATIO_LANG_DATE_STATUS`

示例：

`LUMA_BOTTLE_HERO_15S_9x16_TEXTLESS_2026-05-30_REVIEW01`

## 客户审核包（Client Review Packet）

包含：

- 概念/创意阐述；
- 镜头表与已采纳的提示词；
- 参考素材角色映射与版权说明；
- 导出的审核链接/文件；
- 已知问题与建议修复方案；
- 待审批的问题；
- 交付规格假设。

## 质检失败处理路由（QC Failure Routing）

| 失败类型 | 处理路由 |
|---|---|
| 人脸/产品/文字漂移 | I2V 锁定、剪辑修正、后期合成，或从稳定帧重新生成 |
| 连续性不匹配 | 更新连续性台账，仅重新生成受影响的镜头 |
| 色彩不匹配 | 先调色/转换；仅当布光意图本身错误时才重新生成 |
| 字幕/文字问题 | 移除生成的文字，在后期用排版工具添加 |
| 响度/同步问题 | 修正混音或剪辑时间；不要仅依赖提示词修补 |
| 不安全或版权问题 | 改写为原创/已授权素材，并记录版权 |

## 完成定义（Done Definition）

只有当创意负责人批准了该镜头、版权映射干净、连续性已被追踪、后期交接明确、且交付目标已通过人工质检时，一份专业的 Seedance 素材才算完成。
