# 失败图谱（Failure Atlas）

当序列或延续输出失败时，使用本参考文档。

| 症状 | 可能原因 | 主要修复变量 |
|---|---|---|
| 延续从计划中的结尾开始 | 未审核父片段的观察状态。 | 用观察到的结束状态替换开场。 |
| 动作重新开始 | 已完成的节拍未被标记为已发生。 | 添加已完成节拍排除项。 |
| 未来事件过早出现 | 预留节拍泄漏进了提示词。 | 从提示词和终点中移除未来节拍。 |
| 身份在多次扩展中漂移 | 连续性来源取代了规范身份参考。 | 从规范图像重新锚定身份。 |
| 画面方向翻转 | 轴线未被锁定或未被刻意重置。 | 陈述画面方向，或声明轴线重置。 |
| 开放运动停止 | 未继承运动矢量。 | 沿用主体/摄影机的速度与方向。 |
| 摄影机阶段重新开始 | 缺少来自父片段的摄影机终点。 | 从观察到的摄影机阶段开始。 |
| 道具与前一片段矛盾 | 未追踪道具的归属/位置/状态。 | 添加道具状态交接。 |
| 对白重复 | 未记录已完成的对白。 | 标记台词已完成，并继续音频阶段。 |
| 扩展质量下降 | 忽略了扩展深度与漂移。 | 重新锚定，或刻意创建下一个镜头。 |
| 参考角色相互污染 | 缺少转移/忽略条款。 | 拆分参考角色与排除项。 |
| 事件密度过高 | 多个节拍被编译进了一条提示词。 | 把未来节拍重新分配到后续片段。 |
