# 社区来源方法论

last_verified: 2026-05-30

在挖掘提示词语料、论坛、Reddit 帖子、中文指南、俄文指南或封装文档时，使用本参考。

## 允许的提取

- 提示词结构。
- 定时语法。
- 相机、光线、运动、音频、视效和约束词汇。
- 参考角色语言。
- 失败模式和安全修复。
- 来源元数据：URL、作者账号、语言、日期和界面。

## 不允许的提取

- 把受保护角色、系列、确切场景、工作室或歌曲作为可复用的范例。
- 名人、公众人物、私人或嗓音模仿提示词。
- 滤镜绕过或规避指令。
- 把封装定价当作通用的 Seedance 定价。
- 无法重新核实的私有渠道主张。

## 语料标签

| 标签 | 含义 |
|---|---|
| `safe-example-candidate` | 经少量清理可改写进活跃文档。 |
| `safe-structure-only` | 仅挖掘结构/词汇；不要复制提示词内容。 |
| `ip-risk` | 含有受保护角色、系列、工作室、确切场景或歌曲。 |
| `real-person-risk` | 含有真实人脸、公众人物、名人或嗓音模仿风险。 |
| `brand-risk` | 含有需授权的品牌/徽标/产品身份。 |
| `violence-risk` | 需要非露骨的摆拍动作改写或排除。 |
| `low-quality` | 太泛泛、不连贯或套话过多，不值得挖掘。 |

## 转化规则

原始的社区提示词应变成原创的安全范例。把受保护名称替换为原型，把具名品牌替换为用户自有/产品占位符，把真实人物参考替换为以授权为门槛的语言。

## 序列范例规则

不要把商业创作者的续接提示词当作黄金范例复制。仅提取可复用的结构：实际结尾、已完成动作、当前镜头任务、预留的未来动作、参考迁移边界，以及终点。改写成带合成项目 ID 和明显合成夹具的原创序列范例。
