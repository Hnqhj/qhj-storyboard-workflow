# API 工作流

last_verified: 2026-06-20

在火山引擎、BytePlus、Runway、fal、provider/router 界面或封装上进行 Seedance 2.0 操作规划时，使用本参考。它不是一个静态的 API 契约。在实现前始终重新核实当前的 provider 文档或控制台。

## 界面闸门

| 界面 | 使用时机 | 必须重新核实 |
|---|---|---|
| 火山引擎 Ark | 面向中国的官方 Ark 工作流、模型 ID、任务生命周期、首/末帧角色、`return_last_frame`、网页搜索工具，以及虚拟人像资产。 | 模型 ID、区域、权益、schema、定价、时长、分辨率、人脸/参考政策 |
| BytePlus ModelArk | 国际 BytePlus 文档或控制台工作流。 | JS 渲染的定价/模型页、账号访问、区域、确切模型 ID、上传/文件规则 |
| Runway | 带 `seedance2` 的 Runway 网页/API/MCP 工作流、托管上传，以及 Runway 套餐/区域约束。 | 时长、画幅比、套餐、区域、SDK 字段支持、音频参考组合规则 |
| Provider/router API | EvoLink、OpenRouter、Kie.ai、PiAPI、LaoZhang、Runware、ModelsLab、AI/ML API、MuAPI、SeeGen、Segmind 或类似界面。 | base URL、模型 ID、任务端点、轮询端点、callback/webhook 支持、计费单位、文件托管、参考 schema、人脸政策、输出 URL 有效期、版权条款 |
| 面向中国的官方界面 | ByteDance Seed、火山引擎 Ark、BytePlus ModelArk、豆包、即梦/剪映、CapCut/剪映。 | 语言/区域、账号层级、企业或个人访问、身份验证、人像/虚拟形象流程、控制台权益、确切文档日期 |
| 封装 API | 通过第三方提供方快速原型。 | 名称、价格、审核、时长或人脸支持是否为封装特有 |

## 异步任务生命周期

1. 用带来源日期的模型 ID、提示词、时长、画幅比/尺寸、分辨率和参考文件创建任务。
2. 存储任务 ID、provider、请求日期、模型 ID 和提示词版本。
3. 轮询或使用 SDK 等待助手，直到完成或失败。
4. 检索输出 URL、可选的末帧、日志/错误，以及提供时的审核/失败原因。
5. 保存输出加元数据以实现可重复性。
6. 仅通过当前 provider 的最新文档来取消、删除或列出任务。

## 请求清单

- 提示词陈述一个可见节拍、一个相机运动、物理光线、声音意图和约束。
- 模式明确：T2V、I2V、V2V、R2V、FLF2V、edit 或 extend。
- 参考角色明确且合法：首帧、末帧、身份、产品、运动、相机、定时、音频或风格。
- 当界面要求该组合时，音频参考与文本提示词及有效的图像/视频参考配对。
- 首/末帧请求不会在未经当前文档允许的情况下，悄然混入不兼容的视频/音频参考模式。
- 真实人物、人脸、人像和嗓音输入具备授权和界面支持。
- 定价、时长、分辨率、区域、配额和模型 ID 都有一个核实日期。

## Provider 说明

火山引擎文档是 `doubao-seedance-2-0-260128`、`doubao-seedance-2-0-fast-260128`、`doubao-seedance-2-0-mini-260615`、首/末帧角色和 Ark 任务流程的当前来源。在 6 月 20 日核实的官方通知中，Mini ID 直到 2026 年 6 月 22 日仍处于试用门控。引用价格时只可附带日期和注意事项。

BytePlus 文档是 `dreamina-seedance-2-0-mini-260615` 和 `dreamina-seedance-2.0-mini` 定价行标签的当前来源。把它们视为 BytePlus 特有；在实现前重新核实 Model Playground/API 访问、时长、分辨率和价格。

Runway 文档是 Runway 的 `seedance2` API 界面、`runway://` 上传、时长、参考数量规则和 SDK 注意事项的当前来源。不要把 Runway 字段名复制进火山引擎示例，反之亦然。

provider/router 界面是集成便利，而非权威的模型规格来源。截至 2026-06-20，本仓库把 EvoLink、OpenRouter、Kie.ai、PiAPI、LaoZhang、Runware、ModelsLab、AI/ML API、MuAPI、SeeGen 和 Segmind 跟踪为提及 Seedance 2.0 访问的公开页面或文档。模型 ID 和字段使用当前界面自有的文档，绝不跨 provider 合并 schema。

中文搜索结果在使用前需要分类。官方的字节跳动/火山引擎/BytePlus/豆包/即梦/剪映页面可支持面向中国的界面指引。托管工作流、中文博客、价格对比和商业伙伴新闻可提供背景，但它们不是公开的 API 契约，除非它们链接到 provider 自有的 API 文档。

BytePlus 页面可能是 JavaScript 渲染的。不要从不完整的静态抓取推断实时定价或模型 ID。

## 错误与风险手册

| 症状 | 可能原因 | 首要修复 |
|---|---|---|
| 403 或模型不可用 | 区域、套餐、权益、厂商授权或 provider 门控 | 检查界面特有的访问文档和账号控制台 |
| 纯音频请求失败 | 当前界面要求图像/视频加上带音频的提示词 | 添加有效的视觉参考并陈述音频角色 |
| 首/末帧被拒 | 不兼容的模式混用或错误的角色字段 | 使用 provider 的首/末帧字段名，必要时移除视频/音频参考 |
| 人脸/人像上传被拦截 | 真实人物政策、验证或资产库要求 | 使用授权的虚拟人像路径或原创角色改写 |
| 延展后输出漂移 | 末帧连续性弱或改变的变量过多 | 用返回的末帧作下一个首帧，并只改变一个变量 |
| 价格估算错误 | 过时的定价页或封装特有的计费 | 报价前重新核实 provider 定价页/控制台 |

## 生产就绪度

保留一份运行台账，包含：provider、模型 ID、提示词、模式、参考、时长、分辨率、生成音频标志、任务 ID、输出 URL、末帧、核实日期和失败说明。这使提示词修复成为可能，并防止过时的来源主张泄漏进面向用户的指引。
