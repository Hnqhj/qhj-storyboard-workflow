# Seedance 研究快照

last_verified: 2026-05-30

本快照记录了当前 v6 来源层、多语言层、视觉资产层、专业电影人层、视觉压力测试层与平台刷新层所使用的证据。它是一份带日期的工作层，而非对平台访问权限、定价、限额或区域可用性的永久保证。

## 来源优先级

1. ByteDance Seed 官方页面与发布文章。
2. Volcengine 或 BytePlus ModelArk 官方文档。
3. 官方或合作伙伴工作流文档，如 ComfyUI 合作伙伴节点。
4. 由提供方发布的学术/模型卡材料。
5. 专业电影、后期制作、调色、字幕、音频与交付标准。
6. 用于仓库结构的 Agent-skill 打包文档。
7. 社区提示词指南、论坛、提示词语料库与封装层文档。

## 已确认的官方信号

- ByteDance Seed 将 Seedance 2.0 描述为一个统一的多模态音视频生成模型，支持文本、图像、音频与视频输入。
- 官方发布文章称用户最多可提供 9 张图像、3 段视频片段、3 段音频片段，外加自然语言指令。
- 官方材料强调将参考用于构图、镜头语言、运动节奏、视觉效果与声音特征。
- 官方材料将视频延展与编辑描述为核心能力，而不仅仅是全新的文生视频生成。
- Volcengine 的 Seedance 2.0 教程在 2026-05-29 被观察到更新，并列出了 `doubao-seedance-2-0-260128` 与 `doubao-seedance-2-0-fast-260128`。
- Volcengine 5 月 29 日的视频生成教程现已成为重新核查首帧与尾帧角色、返回尾帧、网络搜索工具及输入组合规则的活跃第一方位置。
- Volcengine 的 Seedance 2.0 提示词指南在 2026-05-15 被观察到更新，并强化了角色绑定的多模态参考提示。
- Volcengine 5 月 28 日的定价页面只能在标注来源日期、平台、模型、货币及重新核查告诫的前提下引用。BytePlus 由 JavaScript 渲染的页面在引用价格前仍需实时验证。
- Runway 记录了一个独立的官方 Seedance 2 平台，使用模型 ID `seedance2`、5-15 秒时长、托管的 `runway://` 上传以及音频参考组合规则。
- Runway MCP 于 2026-05-27 作为 agent 连接器平台上线。将其视为 Runway 访问/工作流证据，而非 ByteDance API 能力声明。
- 真人肖像或声音工作流需要授权、平台支持及平台特定验证。
- ByteDance 自身的发布材料列出了仍存在的弱点：细节稳定性、超写实、动态活力、多主体一致性、文字渲染、复杂编辑以及偶发的音频失真。
- OpenAI 当前的 Codex Agent Skills 文档将 skill 描述为一个目录，其中包含必需的 `ZH_REFERENCE.md` 加上可选的 `scripts/`、`references/`、`assets/` 与 `agents/` 文件夹。本仓库遵循该形态。
- 近期的音视频基准工作（如 AVBench 与 VABench）强化了围绕跨模态一致性、同步、唇音一致性及音视频 QA 的评估词汇，但不应将其视为 Seedance 的访问或性能保证。
- 专业工作流参考强化了这样一个观点：AI 视频提示应将创意镜头意图与交付义务分开——镜头合同、连续性账本、ACES/调色交接、字幕/本地化规划、音频分轨/M&E/响度、画幅变体及 QC 都属于工作流元数据，除非某个活跃平台明确实现了它们。

## 现场观察信号

将这些作为从业者指引，而非平台保证：

- 在投入 10-15 秒渲染之前，先生成简短的草稿片段很有用。
- 每个镜头一次主要运镜仍是可靠的稳定性规则。
- 参考资产需要明确的角色：身份、背景、运动、运镜节奏、音频节拍或尾帧目标。
- 首/尾帧工作流在中文创作者指引与合作伙伴工作流文档中很常见。
- 音频参考失败往往是角色冲突：如果某个视频参考同时包含声音，在 `[Audio1]` 应控制时序时，将其静音或将其角色降级为运镜/运动。
- 本地化的日语、韩语、西班牙语、俄语及多语言指南强化了相同的核心结构：明确的参考角色、一次运镜、清晰的动作、声音提示及约束。
- 中英混合提示词对于安全的角色绑定加技术性运镜术语很有用，但仅作为清晰度手段。它们不是官方过滤行为，且绝不能用于掩盖不安全意图。
- 当活跃平台支持时，延展链受益于返回的尾帧锚点。
- 编辑或延展一个失败的片段，往往比重新生成整段片段更便宜且更可控。
- 产品标志、面孔、可读文字、手部、快速手势及多角色站位，受益于锁定的取景与更强的约束。
- 当 README 在人类层面解释工作流、而脚本强制执行文件、来源与元数据完整性时，Agent-skill 仓库会更可用。
- 专业用户需要角色特定的产物：导演需要镜头目的与表演节拍，DP 需要镜头合同，制片需要权利/审批关卡，剪辑需要连续性交接，调色与声音团队需要后期元数据，本地化团队需要无字版/字幕/配音方案，QC 团队需要交付预检。

## 排除于活跃指引之外

- 过滤绕过或审核规避建议。
- 名人、公众人物或私人个人的模仿。
- 受保护角色、特许经营、工作室、歌曲或声音的精确复制。
- 来自封装站点的定价承诺，除非答案清楚标注了封装层、日期与来源。
- 来自私密群组、封闭频道或无法重新核查的截图的声明。
- 用基准排行榜或论文声明替代当前官方平台行为。

## 更新规则

每当 README、平台状态文档、API 指引或模型名称映射发生变化时，刷新本快照。如果某个声明未与来源和日期挂钩，将其移至现场观察备注或删除。
