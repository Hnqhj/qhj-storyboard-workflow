# 能力地图 —— 围绕强项设计，绕开限制

*Seedance 2.0 最擅长什么、如何提取每项强项，以及该绕开什么来设计。在提示词规划前加载。标签：[official] = 字节跳动/fal/Ark 文档 · [field] = 从业者反馈 · [heuristic] = 待测试的默认值。最后核实于 2026-06-09。这些行背后的机制存于 `model-mechanics.md`。*

## 围绕这些设计（利用强项）

| 能力 | 提取动作 |
|---|---|
| 单次调用多镜头 [official] | `Shot 1:/2:/3:` 标签 · 每镜头一个动作 + 一个相机 · 标准档位 · 10–15 秒/`auto` · 镜头数×秒数预算 |
| 原生同步音频 [official] | 点名具体声音；对白作为画面内自然的引号台词；短台词；干净的正面参考；SFX>music>dialogue——先测试对白 |
| 角色分离的参考 [official] | 逐素材角色 **+ 排除**（"motion only, no appearance"，仅运动、不要外观） |
| 通过 @Video 的运动迁移 [official/field] | 用于编排/相机节奏的来源片段 + 身份 @Image |
| 通过 @Audio 的音频作时钟 [field] | "cut on the beat of @Audio1; the turn lands on the drop" |
| 首/末帧 [official] | 锁定端点；提示词 initiate→travel→resolve；变换与匹配剪辑 |
| 字面相机动词 [official] | 每镜头一个有动机的运动 |
| 物理 [official 主张] | 物理动词与后果，而非姿势形容词 |
| 慢动作 [official] | 标准档位；用在那个单一的关键动作上 |
| 变换 [field] | 端点状态 + 持续的载体；困难情形 → FLF 分解 |
| 2D/动漫 [field] | 媒介语法：赛璐珞叠绘景背景、作画与保持帧、冲击帧/速度线/拖影；不谈镜头/景深——完整语法见 `[ref:2d-anime-grammar]` |
| 格式与 `auto` [official] | 21:9 用于影院；`auto` 按复杂度调整时长 |
| 多语言 [official/field] | 用中文锚定质感/情绪；保持引用标签精确 |

## 绕开这些设计（避开限制）

对于相连的生成，通过让每段片段保持小、记录被采用的已观察状态、保留精确的参考角色，并在延展深度或可见漂移增加时重新锚定，来绕开连续性漂移。这是工作流指引，而非确定性的平台保证。

界面时长上限是当前界面的事实，而非通用的 Seedance 事实；音频跨独立调用不连续，所以需要时在后期配乐 [official] · 画面内文字 → 后期 [official] · 否定会召唤——以构图方式排除 [field] · 微小细节（远处面孔、手、徽标）会退化 [field] · 面部微表演最弱——把情绪安排在身体/调度，定量配给特写 [heuristic] · 重复链式生成后出现可见漂移——用原始参考重新锚定 [field] · 多人镜头中角色↔道具物理脆弱——让接触保持简单或移至画外，使用三层动作层级 [field] · Fast 档位行为是界面特有的 [field] · seed = 稳定器，而非锁定 [official]。

## 竞争背景 *(2026-06-14)*

原生音频不再是 Seedance 独有的差异化优势——截至 2026 年中，Veo 3.1、Sora 2、Kling 3.0、Runway Gen-4.5、Hailuo 2.3 和 Vidu Q3 都搭载了它 [tech-press]。以组合中仍具独特性的能力打头阵——单次多模态参考（文本+图像+视频+音频一起）、单条提示词多镜头，以及多语言对口型——而非把原生音频当作头条卖点。官方原生分辨率是 480p/720p；1080p 是界面特有的（见 `api-status.md`）。
