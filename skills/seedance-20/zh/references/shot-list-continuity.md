# 镜头清单与连续性

当用户要求电影场景、广告序列、多镜头方案、故事板、处理稿转镜头清单或连续性修复时，使用本参考。

## 前期制作简报

只收集会改变制作决策的内容：

- 目标：电影场景、产品广告、音乐视频、预告片、社交剪辑版、内部提案、测试渲染；
- 受众与地区；
- 时长与目标平台；
- 主角、产品、角色或品牌；
- 参考及每个参考所控制的内容；
- 权利/授权状态；
- 对白/音频需求；
- 画幅与交付平台；
- 截止日期、审批负责人及风险约束。

## 镜头清单字段

| 字段 | 示例 |
|---|---|
| 镜头 ID | `S01_SH03` |
| 时长 | `5s` |
| 模式 | T2V、I2V、R2V、FLF2V、edit、extend |
| 目的 | 建立、揭示、演示、情绪转折、片尾卡 |
| 主体/动作 | 产品旋转一圈；角色放下信件 |
| 镜头合同 | 中近景、固定机位、50mm 人像压缩 |
| 参考 | `[Image1] 产品身份`、`[Video1] 运镜节奏`、`[Audio1] 节拍` |
| 连续性锚点 | 服装、道具、画面方向、光照状态、背景布局 |
| 起始帧 | 镜头从哪里开始 |
| 结束帧 | 下一镜头交接或最终目标 |
| 音频 | 对白、环境声、SFX、音乐提示、静音 |
| 风险 | 面孔漂移、标志文字、手部复杂度、不安全的相似性、提示词被拦 |
| 评审备注 | 接受、重试、编辑、延展、替换 |

## 连续性账本

在各镜头间追踪这些锚点：

| 锚点 | 记录内容 |
|---|---|
| 角色 | 标签、服装、发型、剪影、道具、情绪状态 |
| 产品 | 标签、标志、几何形态、材质、颜色、产品照角度 |
| 场景 | 布局、左/右地理关系、门/窗位置 |
| 画面方向 | 主体从左向右还是从右向左移动 |
| 视线 | 每个角色看向何处，以及是否与反打镜头匹配 |
| 光照 | 主光方向、实景光源、时间段、氛围 |
| 镜头 | 镜头质感、机位高度、稳定性、运动家族 |
| 动作状态 | 上一个端点发生了什么 |
| 声音状态 | 音乐、环境声、对白、同步提示 |

## 处理稿转镜头清单

1. 提取戏剧或商业节拍。
2. 为每个节拍分配一个 Seedance 片段，除非该节拍极小且稳定。
3. 为每个片段选择脆弱锚点：面孔、产品、文字、编排或端点。
4. 选择最安全的模式：I2V 用于身份/产品保持，FLF2V 用于精确端点，R2V 用于角色绑定的运动或运镜，edit 用于单层变更，extend 用于延续。
5. 为每个镜头创建镜头合同与连续性锚点。
6. 仅在镜头清单稳定后再写提示词。

## 三镜头商业模式

| 镜头 | 目的 | 提示词主干 |
|---|---|---|
| 1 | 问题或世界 | 广角或中景环境、简单动作、建立产品语境 |
| 2 | 产品/材质佐证 | 近景或微距、锁定或缓推、材质细节加一个 SFX |
| 3 | 主角产品照/最终状态 | 产品四分之三角度、干净光线、保留标志、标语在后期处理 |

## 交接规则

- 当连续性重要时，将接受的尾帧作为下一镜头的首帧参考。
- 保持服装、产品朝向、画面方向与光照方向稳定，除非剧情明确改变它们。
- 如果某个提示词产生了好的表演但糟糕的产品/标志，编辑或合成产品层，而非重新生成整个镜头。
- 如果某个镜头失败三次，简化镜头合同或将动作拆分为两个片段。

## 序列状态交接

对于有状态的序列，用片段血缘替代松散的连续性账本：

- `project_id`、`clip_id` 与 `parent_clip_id`；
- 计划起始与计划结束状态；
- 评审后观察到的起始与结束状态；
- 已完成节拍、当前片段节拍与预留的未来节拍；
- 连续性锁定与允许的变更；
- 转入、转出、开放的运动矢量及交接需求。

只敲定当前未解决的片段提示词。后续镜头卡在前一个已接受的镜头被评审之前保持暂定状态。
