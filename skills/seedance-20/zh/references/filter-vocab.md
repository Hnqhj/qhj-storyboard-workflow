# 过滤器安全词汇（Filter-Safe Vocabulary）

使用专业、非血腥、制作语境的语言。不要用本参考文档来绕过安全系统。

| 有风险的表述 | 更安全的制作措辞 |
|---|---|
| violent impact（暴力冲击） | high-energy collision, non-graphic action beat |
| weapon close-up（武器特写） | prop object held safely, action-scene staging |
| blood（血） | red fabric accent, colored liquid, non-graphic aftermath |
| injury（伤害） | visible fatigue, dramatic tension, character distress |
| fight（打斗） | choreographed action sequence, staged confrontation |
| celebrity face（名人面孔） | original character with broad archetype traits |
| brand logo（品牌标识） | generic product mark or blank label |
| named franchise（具名 IP） | original world with similar genre function |

保留意图。改变有风险的表述措辞。

## 减少误报（False-Positive Reduction）

仅将其用于被误解的安全提示词。修复方式是清晰，而非规避。

| 含糊措辞 | 更安全的澄清 |
|---|---|
| dark fight scene | staged confrontation, choreographed action beat, no graphic injury |
| knife on table | safe prop object on a table, not used for harm |
| intense hostage mood | locked-door suspense scene with no restraints and no harm |
| blood-red light | deep red practical light, red fabric accent, no injury |
| copy this person | original authorized character reference, preserve only user-owned identity |
| make it like this movie | original scene with similar camera function, palette, pacing, and genre mood |
| scary childlike doll | antique toy prop in an eerie room, no real child |

## 多语言清晰度（Multilingual Clarity）

当语言混用能让一条安全提示词更清晰时，允许混用：

- 当技术摄影术语更精确时，保留英文：`locked medium shot`、`35mm lens`、`slow dolly-in`。
- 当中文角色绑定更简短时，保留中文：`@图1锁定主体身份`、`@视频1仅参考运镜`。
- 对白保留为说话者的语言，并明确写出安全/归属约束。
- 不要把不安全内容翻译成另一种语言来作为变通手段。
- 如果一条提示词仍然失败，改变有风险的创意表述，而不是只改变语言。
