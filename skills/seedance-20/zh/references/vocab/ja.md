## 废话陷阱

社区共识：抽象的形容词会让模型无法判断该强调哪个元素，从而使输出不稳定。把感觉词拆解成制造这种感觉的物理元素（运镜动词+速度+视角，光源+方向+行为）。

| 套话 | 改写为 |
|---|---|
| `映画のような / 映画的` | 用景别、运镜、光源、色调来写：`広い導入ショット、ゆっくりドリーイン、低い夕陽、ティール＆オレンジ` |
| `エモい` | 用制造情绪的物理元素来写：`夕暮れの逆光、長い影、遠くの電車の音` |
| `雰囲気のある` | 指明制造氛围的元素：`薄い霧、濡れた路面の反射、低い環境音` |
| `美しい` | 用色彩、质感、构图、光的行为来写 |
| `壮大な` | 用物理规模来写：人群数量、镜头距离、建筑高度 |
| `高品質 / 高画質 / 8K` | 删除。分辨率是设置，不是文章 |
| `圧倒的な` | 写出造成压倒感的那一个对比或揭示 |
| `幻想的な`（单独使用） | 写出制造梦幻的元素：`漂う塵、ボリューム光、ゆっくりした浮遊` |
| `神作画` | 用动作来写：`滑らかなフルアニメーションの一連の動き、そのあと静止` |
| `かっこいい` | 用具体的姿态、动作、运镜来写 |
| `ダイナミック` | 用动作的种类、速度、终点来写 |
