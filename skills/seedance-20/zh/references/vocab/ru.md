## 俄语对白备注

来自俄语社区测试的现场观察（Habr、vc.ru）；按平台测试，绝不承诺结果。俄语报道称支持包括俄语在内的多语言对白，但来源登记表中的官方 ByteDance 页面并未枚举对白语言——将俄语对白视为现场观察，并将长俄语短语视为被报告的弱点。

| 规则 | 实践 |
|---|---|
| Короткие реплики | 将独白拆分为几个词的台词：`Она тихо говорит: «Я нашла его»` —— 长短语会漂移成噪声 |
| Кириллица vs транслит | 社区测试了纯西里尔文、音译（`Ya nashla yego`）及混合——结果因平台而异；先试西里尔文，当其退化时以音译作为现场报告的回退方案 |
| Один говорящий | 每次生成一个说话人以获得可靠唇音同步；台词期间用锁定的中近景 |
| Полная озвучка | 完全配音的俄语作品在模型内无法可靠实现：用室内底噪或短台词生成，然后在后期配音并对口型（见 `audio-post-delivery.md`） |
| Доступ из РФ | 从俄罗斯访问通常通过第三方封装层——将其模型名称、价格与限额视为封装层特定，绝非官方 |

## 废话陷阱

社区总体结论：抽象的评价词会使生成不稳定——模型不理解该强调哪个元素。把每个感觉词拆解成制造它的物理元素（运镜动词 + 速度 + 视角，光源 + 方向 + 行为）。

| 套话 | 改写为 |
|---|---|
| `кинематографичный` | 景别、运镜、光源与调色：`широкий общий план, медленный наезд, низкое тёплое солнце, тил-энд-оранж` |
| `эпичный` | 物理规模：人群规模、镜头距离、结构高度 |
| `потрясающий / захватывающий` | 那一个为之加分的对比或揭示瞬间 |
| `красивый` | 颜色、纹理、材质、光的行为 |
| `шедевр / высокое качество / 8K` | 删除；质量不是请求出来的，分辨率是设置 |
| `атмосферный` | 制造氛围的物理元素：`тонкий туман, отражения на мокром асфальте, тихий фон` |
| `драматичный` | 调度、阴影、静默或镜头压迫 |
| `волшебный` | 粒子行为、辉光来源、轨迹 |
| `невероятно детализированный` | 两个真正重要、直接命名的细节 |
| `динамичный` | 具体的运动、其速度与其终点 |
| `профессиональный` | 受控的产品照明、干净背景、稳定镜头 |
