## 废话陷阱

社区共识：抽象的质量词会让模型无法判断该强调哪个元素，从而使输出不稳定。把感觉词拆解成制造这种感觉的物理元素（运镜动词+速度+视角，光源+方向+行为）。

| 套话 | 改写为 |
|---|---|
| `영화같은 / 시네마틱한` | 用景别、运镜、光源、色调来写：`넓은 설정 샷, 느린 돌리 인, 낮은 노을빛, 틸앤오렌지` |
| `감성적인 / 감성` | 用制造情绪的物理元素来写：`해질녘 역광, 긴 그림자, 멀리서 들리는 기차 소리` |
| `분위기 있는` | 指明制造氛围的元素：`얇은 안개, 젖은 노면 반사, 낮은 환경음` |
| `아름다운` | 用色彩、质感、构图、光的运动来写 |
| `웅장한` | 用物理规模来写：人群数量、镜头距离、建筑高度 |
| `고퀄리티 / 고화질 / 8K` | 删除。分辨率是设置，不是文章 |
| `압도적인` | 写出造成压倒感的那一个对比或揭示 |
| `몽환적인`（单独使用） | 写出制造梦幻的元素：`떠다니는 먼지, 볼류메트릭 라이트, 느린 부유` |
| `미친 퀄리티` | 删除。质量不是请求出来的 |
| `멋있는` | 用具体的姿态、动作、运镜来写 |
| `다이내믹한` | 用动作的种类、速度、终点来写 |
