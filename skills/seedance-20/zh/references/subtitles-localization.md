# 字幕与本地化

当某个 Seedance 项目需要全球发行、字幕、隐藏字幕、强制旁白、配音、多语言提示词或市场特定文案时，使用本参考。

## 本地化方案

| 交付物 | 目的 | 提示词/后期边界 |
|---|---|---|
| 字幕 | 翻译口语对白 | 在后期依据批准的脚本创建，而非生成为运动文字 |
| SDH 隐藏字幕 | 对白加重要声音提示 | 规划声音提示与说话人 ID；在后期编写字幕 |
| 强制旁白 | 翻译标识、文字或非本语言台词 | 避免烧录的 AI 文字；保留干净底板 |
| 配音 | 本地化配音表演 | 使用简短的说话人轮次、稳定取景及后期同步评审 |
| M&E | 不含对白的音乐与效果 | 单独规划音频层 |
| 无字版 | 无标题/字幕条的画面 | 生成干净的背景/动作底板 |
| 市场文案 | 本地标语或法律声明 | 在法律批准后于设计/剪辑工具中添加 |

## 为字幕友好型素材编写提示

- 保持对白简短并分配给某个说话人。
- 对重要口语台词使用稳定的中景或中近景。
- 需要时为字幕留出负空间。
- 避免生成的字幕或细小的运动文字，除非任务明确是粗略概念预览。
- 为文案会变化的市场保留干净底板。
- 对于多语言对白，指明说哪种语言、后期为哪种语言加字幕。

## 阅读与放置检查

对于专业产出，检查：

- 字幕不遮挡面孔、产品声明、标志、法律免责声明或关键动作；
- 字幕为目标语言提供了足够的阅读时间；
- 说话人切换清晰；
- SDH 声音提示仅描述与故事相关的声音；
- 仅在需要时使用强制旁白；
- 换行保留语义；
- 正式/非正式称呼与区域及角色关系相匹配。

## 全球提示词交接

| 语言需求 | 安全措辞 |
|---|---|
| 中文提示词加英文运镜术语 | 用中文做角色绑定，若更清晰则用英文表达运镜/镜头术语；绝不用于规避 |
| 日本市场文案 | 保持生成镜头无字版；在后期添加日文文案 |
| 韩语对白 | 简短的引号台词、稳定的面部取景、不转头 |
| 西班牙语字幕 | 规划字幕安全的字幕条并避免烧录的源文字 |
| 俄语本地化 | 交付无字版底板加单独的俄语字幕/文案文件 |

## 文化本地化

询问必须本地化的内容：对白、产品声明、节日/季节、手势、标识、食物、服装、法律文字或音乐提示。不要假定逐字翻译就是面向市场的本地化。

## 安全的误报修复

混合语言措辞可以澄清良性的制作语境与参考角色，但绝不能掩盖不安全内容。如果一个被拦截的提示词包含暴力、真人相似性、受保护 IP、性内容或类似规避的措辞，在每种语言中修复底层问题。
