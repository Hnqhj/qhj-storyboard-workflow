# 叙事框架

当一个简短的 Seedance 片段拥有一个可见的决定或一个可见的转变时，效果最好。模型不需要完整的情节；它需要清晰的起始状态、动作及改变后的最终状态。

## 有用的片段节拍

| 节拍 | 改变了什么 | 示例 |
|---|---|---|
| 到达 | 主体进入一个新空间。 | 快递员抵达一扇上锁的屋顶门。 |
| 揭示 | 隐藏信息变得可见。 | 条形灯揭示出产品标签。 |
| 决定 | 角色通过手势作出选择。 | 角色放下一个信封并看向门。 |
| 转变 | 材料或环境发生变化。 | 霜在玻璃上蔓延，并在标志处停下。 |
| 反转 | 预期动作改变方向。 | 一架纸飞机转回飞向它的发出者。 |
| 追逐 | 一个主体拉近距离。 | 无人机在雨中追踪一名跑者。 |
| 接触 | 两个元素相遇。 | 钥匙触碰锁，一道蓝色火花溃散。 |
| 消失 | 主体退出、溶解或藏匿。 | 列车灯光淡入雾中。 |

## 节拍公式

`起始状态 -> 可见动作 -> 改变后的最终状态。`

镜头、光照与音频应支持该节拍，而非与之竞争。如果提示词包含多个节拍，将其拆分为单独的片段，或编写一个有意的时间分段序列。

## 微型故事检查清单

主体被命名或标记。动作是一个动词，而非一种情绪。场景有一个有用的环境细节。镜头有起点与终点。光源是有动机的。声音层要么支持节拍，要么保持静音。最终帧与首帧不同。

## 序列工作的三个尺度

故事层：初始条件 -> 目标 -> 升级 -> 最终结果。这一层解释了项目为何存在，但它不授权每个事件都出现在当前提示词中。

序列层：片段 01 任务 -> 片段 02 任务 -> 片段 03 任务 -> 解决。每个片段有一个叙事任务和一个完成的端点。

片段层：已经发生 -> 实际开场状态 -> 当前动作 -> 物理后果 -> 完成的端点 -> 预留的未来动作。

## 范围防火墙

故事语境告知动机、表演、氛围与节奏。故事语境不让当前片段表演未来事件、跳过物理交接状态、揭示预留信息，或假定一个已接受素材尚未到达的计划结局。
