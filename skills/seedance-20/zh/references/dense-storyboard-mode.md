# 密集分镜模式（Dense Storyboard Mode）

当请求包含大量分镜画格、故事板节拍、动画分镜板或多镜头描述时，使用本参考文档。

## 分类器（Classifier）

仅当用户明确希望在一次生成内部进行切镜、且当前活动的平台/配置支持该结构时，才选择 `dense_multishot`。当动作应保持连续时，选择 `phased_single_take`。不要将"单一连续镜头"与硬性镜头标签组合在一起。

## 密集多镜头规则（Dense Multishot Rules）

- 使用镜头标签。
- 给每个镜头一个动作和一个终点状态。
- 在镜头边界之间保持连续性锁定可见。
- 不要在一次短生成中堆砌过多地点、大幅动作或角色变化。
- 后续的生成提示词在前一个采纳的片段被审核之前都保持临时状态。

## 连续镜头规则（Continuous Take Rules）

使用 Beginning / Then / Finally（开始 / 然后 / 最后）。不要使用镜头标签或硬切。描述同一条摄影机路径、同一地理空间、同一条物理动作链的各个阶段。

## 2D 动画（2D Animation）

对于 2D、动漫或赛璐璐（cel）作品，使用动画版面术语：图层、视差、保持帧（holds）、拖影帧（smear frames）、冲击帧（impact frames）、赛璐璐阴影（cel shadow）、线条沸腾（line boil）、背景横移（background pan）以及合成。除非用户明确要求混合的模拟摄影机风格，否则避免使用摄影传感器、镜头、散景、ISO 和浅景深等语言。

## 终点纪律（Endpoint Discipline）

每个密集分镜节拍都必须以一个完成的视觉状态结束。如果终点不可见，下一个片段就无法安全地继承它。
