# 音频后期与交付

当 Seedance 工作涉及对白、声音设计、音乐、分轨、M&E、配音、同步或最终交付检查时，使用本参考。

## 提示词级音频

用提示词音频来执导故事的定时和情绪：

- 对白：简短、引号、分配给一个说话者；
- 环境音：环境底噪、车流、雨、人群底噪、机器嗡鸣；
- 音效：一两个与可见动作绑定的、与故事相关的声音；
- 音乐：宽泛的节奏、能量、配器，或静默；
- 同步提示：终点处的关门声、末帧的产品咔哒声、强拍上的光脉冲。

除非版权和平台支持明确，否则避免对受保护歌曲、真实嗓音或获许可的表演做确切复现的主张。

## 后期级音频交付物

| 交付物 | 用途 |
|---|---|
| 完整混音 | 最终立体声/5.1/Atmos 或平台要求的混音 |
| 对白分轨 | 用于剪辑、配音和清理的口语台词 |
| 音乐分轨 | 仅音乐层 |
| 效果分轨 | 音效和设计音 |
| M&E | 不含原始对白的音乐与效果，用于本地化 |
| 印片母版 | 已批准的最终母版混音 |
| 配音指南 | 说话者定时、音色、发音、停顿 |
| 响度报告 | 交付目标合规证据 |

## 音频规划模板

`Dialogue: [speaker/line/language]. Ambience: [bed]. SFX: [visible sync cue]. Music: [tempo/mood or none]. Reference: [Audio1 role]. Post: [stems/M&E/loudness/sync notes].`

## 同步与响度检查

对于专业交付，检查：

- 对照最终画面的对口型；
- 帧率转换后的音乐/音效同步；
- 没有对白被音乐或效果掩盖；
- R2V 工作流中没有意外的来源视频音频；
- 按买方/平台规格的响度目标和真峰值；
- 若需要本地化，则 M&E 或分轨存在。

## 常见修复

| 失败 | 修复 |
|---|---|
| 对白失同步 | 更短的台词、锁定取景、更少头部运动、一个说话者 |
| 说话者错误 | 标记说话者并拆分轮次 |
| 音乐压过台词 | 对白期间移除音乐，保留环境底噪 |
| 音频参考被忽略 | 把 `[Audio1]` 映射到节奏或情绪并绑定一个可见事件 |
| 视频与音频参考冲突 | 对视频参考静音，或把视频仅指派给相机 |
| 无法本地化 | 在最终剪辑前规划 M&E/分轨和无字画面 |
